# 언덕 타일 변경 — 앞으로 1~6칸 직접 선택 (2026-10-12)

## 승인된 동작

- 사용자 결정: **언덕의 기존 전역 마물 정찰 대신, 현재 언덕 위치 기준으로 앞으로 1~6칸 중 하나를 선택해 이동**.
- 일반 주사위·보유 주사위 제어 카드를 사용하지 않는다. 이전 주사위 눈금, 이전 카드, 난수, 보유 카드에 영향 없음.
- 언덕 화면에 6개 목적지(거리, 실제 지도 번호, 타일 종류) 표시 → 하나 선택하여 지도 임시 강조 → '이동 확정'에서만 저장/애니메이션을 실행; '돌아가기'는 선택을 취소.
- 기존 24칸 일방향 경로에서 집 타일을 통과하지 못하는 규칙 유지. 집이 1~6칸 안에 있으면 해당 집 거리까지만 활성화, 이후 항목 비활성화. 집에 정식 도착하면 귀환 가능 상태 유지.
- 도착지는 일반 맵의 보상/전투/사건/워프/늪 처리에 따름. 전이문 스토리가 언덕에 나타나는 경우에는 기존 사건 우선순위 유지.
- 한 번 선택한 언덕 이동은 시작 전 단일 원자적 저장, `pending_move.source = hill`과 기존 `path/landed/face` 구조 사용. 완료 전에 종료되어도 해당 목적지를 중복 소비 없이 복원. 파일 저장 실패면 위치·보유·난수·영수증 모두 원상 복원.
- 이전 구버전 세이브의 `scout` 구조와 이미 획득한 과거 정보는 읽기 호환을 위해 그대로 둔다. **새 언덕 UI에서는 정보 생성/정찰 버튼 자체가 사라짐**.
- 별도 새 마물·원화·이벤트·보스 기능은 추가하지 않는다.

## 게임 기본원칙 5개

1. **Trigger:** 언덕에 실제 도착 후 '이동 위치 선택' → 앞으로 1~6 중 하나 → '이동 확정'. 임의 보드 타일 미리보기로 무료 이동 금지.
2. **Information:** 출발 지도 인덱스, 목적지 인덱스/타일 종류, 집까지 남은 거리, 현재 활동 중인 전투/보상/이동과 저장 성공 여부.
3. **Interaction:** 사용자가 하나를 선택하고 명시 확정·취소, 공통 RunSession 저장/맵 캐릭터 이동/도착 사건과 기존 링크 재활용.
4. **Visual:** 언덕 이벤트 배경 아래 6개 경로 버튼, 선택 목적지 강조, 이동 확정 후 맵 말이 실제 지나간 칸을 이동. 주사위 결과는 임의 변경 없음.
5. **Persistence:** 경로·출발·착지·선택 원천 및 1회 영수증을 함께 저장하고, 이동 완료를 별도 저장. 종료/재개·저장 실패·중복클릭에서 보상/HP/맵/난수 변경 중복 없음.
