# 일반 사건 보상 공개·수령 연출 (2026-10-25)

일반 사건 6종에서 수락하면 사건 카드 뒤의 보상이 오른쪽으로 빠져나와 앞면으로 돌아온다. 완전히 공개된 다음 화면 클릭·터치 또는 확인 키 한 번으로 실제 수령하고, 주사위 제어 카드는 실제 오른쪽 카드 더미로 이동한다. 회복과 정화는 가운데 아래로 내려가며 수치와 작은 도착 파동을 표시한다.

## 연결과 저장

- Trigger: 기존 일반 사건의 수락 선택. 기존 거절 선택은 바로 사건을 닫는다.
- Information: 실제로 저장 준비된 주사위 카드 원화, 회복 +1 HP, 오염도 -1. 공개가 끝나면 한 번 눌러 수령하는 안내를 표시한다.
- Interaction: 공개 중 입력과 수령 후 연타는 지급을 반복하지 않는다. 수령 실패 시 같은 보상으로 다시 누를 수 있다.
- Visual: 카드 뒤 → 오른쪽 곡선 → 앞면 뒤집기 → 수령 대기 → 목적지 이동. 기존 사건 크기와 원화는 유지한다. 원본 텍스처 최소 크기를 먼저 해제하고 줄바꿈을 켠 뒤 폭을 설정하여 GPU 화면의 크기·글 넘침을 방지한다.
- State: 새 저장 필드 없이 기존 pending_reward/receipt와 complete_routine_choice/claim_reward를 재사용한다. 연출 자체는 난수·보상·저장 구조를 바꾸지 않는다.

수령 전 종료하면 같은 미수령 사건 선택으로 복귀한다. 수령 뒤 이동 중 종료해도 저장된 보상은 한 번만 남는다. 주사위 10장이 가득 차면 기존 교체/포기 창을 사용하고 보관이 확정된 새 카드만 이동한다. 교체 이어하기에서는 모달 깊이를 유지하고, 스크롤에 가려진 카드 위치 대신 화면 안의 시작점을 사용한다. 오른쪽 더미는 비행 중 표시하되 클릭을 차단하고 종료 시 기존 상태로 복구한다.

## 검증

- test_routine_reward_reveal.gd: 79개 통과. 실제 사건/수령 클릭, 지급 전 대기, 저장 실패, 중복 입력, 중단·재실행, 10장 교체·포기·이어하기, 이미지·텍스트 크기, 더미 목적지를 확인한다.
- test_six_routine_cards.gd: 276개 통과. 6종 수락·거절과 기존 원자적 지급/저장 실패/난수 동작을 확인한다.
- test_routine_side_choices.gd: 86개 통과. 한국어·영어 선택 버튼과 기존 발견 카드 배치를 확인한다.
- Godot 4.7.2 편집기 import 오류 없음. Windows Compatibility GPU에서 주사위/회복/영어 정화의 뒤쪽 공개·앞면·이동 화면을 캡처했고 오류와 종료 누수가 없었다.

전체 게임 자동 플레이나 배포 CI 통과를 의미하지 않는다. 범위는 일반 사건 보상 연출이며 메인 스토리 책과 다른 보상 창의 디자인은 바꾸지 않는다.
