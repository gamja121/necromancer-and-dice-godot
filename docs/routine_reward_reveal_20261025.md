# 일반 사건 보상 연출 (2026-10-25)

## 사용자 수정 반영: 보상 종류별 표현

- **주사위 제어 카드만** 사건 원화 카드 뒤에서 오른쪽으로 돌아 나와 앞면으로 덮는다. 공개 뒤 한 번 클릭·터치·확인 키로 수령하고 실제 오른쪽 카드 더미로 이동한다.
- **회복**은 원래 숙영지/귀환에서 쓰는 `MapPresentation.full_heal()`을 그대로 재사용한다. 화면 전체의 녹색 섬광과 18개 녹색 십자가가 2.2초 동안 나타난다. 추가 회복 카드나 두 번째 수령 클릭은 없다. 실제 회복량은 기존 아군 마물당 HP +1이다.
- **타일**은 실제 타일 이미지 하나만 화면 중앙에 뜬 뒤 자동으로 사라진다. 고정 216×162, 약 1.25초, 배경 80% 어둡게, 종이/설명/회전/크기 확대/수령 버튼 없음. 장소 발견 5종에 적용하며, 깨진 봉인의 기존 늪 아이콘도 카드 대신 같은 표현을 쓴다. 깨진 봉인의 지급 결과는 기존 오염도 -1로 유지한다.

## 저장·입력

Trigger는 기존 실제 사건 도착과 수락이다. Information은 이미 준비된 주사위 보상, 기존 회복값/타일 텍스처와 저장된 해금 결과다. Interaction은 주사위만 공개 후 수령, 회복/타일은 자동 효과다. Visual은 위 세 갈래로 분리했다. State는 기존 pending_reward/receipt·해금 플래그만 재사용한다.

주사위는 추가 수령 클릭 때 저장하며, 회복/정화는 원래 선택 시 저장 성공한 경우만 효과를 재생한다. 실패하면 같은 선택을 다시 누른다. 발견은 기존 해금 저장 이후 화면만 표시하며, 종료 후 현재 보드/집 NEW 표시를 유지한다. 연출 중 입력을 차단하고 종료 시 버튼 상태를 복구한다. 주사위 10장 교체·포기·이어하기와 중복 지급 방지는 보존했다. 새 저장 형식, 보상 수치, 확률, 메인 스토리 책은 변경하지 않았다.
