# 오염도 80 최종 보스: 종언의 고룡 (2026-10-22 수정)

사용자 확정 설계. 게임의 기존 패시브를 그대로 사용하며, 새로운 공격·상태이상·광역기·전용 페이즈 등의 **추가 보스 기믹은 만들지 않는다.**

## 보스
- 이름: 종언의 고룡 / slug `dragon`
- HP: **70**, 공격력: **5**, 속도: **4**
- 단독 보스 (적 1마리), **현재 오염도 80 이상**에서 보스 타일이 개방되면 등장. 바퀴수에 따른 보스 기준은 사용하지 않는다.
- 기본 패시브: `bone` / **뼈 덧대기** (일반 공격·반격 피해 -1, 최소 피해 1)
- 추가 패시브: `undying` / **불사귀** (전투당 1회 죽을 피해에서 1HP로 생존)
- 두 효과는 한 보스에게 동시에 적용. 고룡 이외의 적·아군에는 기존 단일 패시브 규칙 유지.
- 특수 낙인/기믹은 추가하지 않음: 본래 전투 시스템의 주사위 및 타겟팅 규칙 사용.
- 이전 코드의 오염도 20 보스 타일 생성은 기존 합의(2026-10-07: 오염도 80 이상으로 변경)에 반하므로 수정. 오염도가 80 미만으로 낮아지면 해당 보스 타일은 일반 마물 타일로 전환하며, 오래된 20~79 저장도 불러올 때 보정한다.

## 획득형 드래곤
- 기존 보스 시체 영입 시스템과 충돌하지 않게 **HP 20, 공격력 4, 속도 3**으로 보유 카드 규격을 분리.
- 보유형 드래곤 패시브는 **뼈 덧대기 1개**, 불사귀 동시 적용은 불가.
- 영입 성공 여부와 시도 규칙은 기존 포획 룰 그대로.

## 범위 외 / 후속 자료
- 이번 요청은 **스탯과 기존 패시브 연결**. 이전 대화에서 생성한 드래곤 일러스트의 리포지토리 반영, 카드 그림, 캐릭터 초상화, 공격·피격·사망 애니메이션은 이번 코드 작업에 포함하지 않는다. 리소스 미제공 상태에서 보스 일러스트·애니메이션 적용 완료라고 주장하지 않는다.
- 데이터: `data/units.json`. 46마리 기존 web V2 마물/랜덤 적·상점/보물 등장 목록은 변경하지 않고 전용 추가 정의로 등록.
- 진입: `systems/run_session.gd`; 전투: `systems/battle_rules.gd`; UI: `systems/unit_info.gd`; 영입: `systems/run_session.gd#create_item`.

## 5가지 기본 원칙
1. **Trigger**: 바퀴 수와 무관하게 현재 오염도 80 이상에서 기존 보스 타일을 열고 전투를 시작.
2. **Information**: 종언의 고룡 HP70/ATK5/SPD4 및 뼈 덧대기+불사귀 설명.
3. **Interaction**: 현재의 4마리 전투 편성·주사위·피격·전투 UI 그대로.
4. **Visual**: 정보창에 기존 두 패시브를 모두 표시. 전용 애니메이션 제작은 별도.
5. **Memory**: 고룡 원본 인카운터·패시브 플래그와 불사귀 1회 사용 여부의 체크포인트 저장·복원.

## 기존 보스 등장 합의 복원 확인

2026-10-07에 20/40/60바퀴 보스 등장 기준을 폐지하고 오염도 기준으로 전환했다. 이번 수정은 이 결정을 우선 적용한다. 오염도에 따른 추가 일반 마물(40/80), 늪지대 타일(15/30), 마물 전투의 오염도 감소 등의 다른 동작은 유지된다.
