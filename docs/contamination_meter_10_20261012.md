# 2026-10-12 오염도 HUD 교체 — 사용자가 선택한 10칸 원화

## 사용자 의도
- 웹/이전 Godot에서 쓰던 흐릿한 `assets/map/ui/contamination_hud.png`를 새로 선택한 프레임으로 교체한다.
- 사용자가 직접 선택한 **까마귀, 촛불, 깨진 석판, 해골 장식**의 고딕 프레임을 유지한다.
- 왼쪽 석판에서 기존 그림의 고정 문자는 제거한 상태다. 게임에서 "오염도"와 `값 / 100`을 렌더링한다.
- 투명한 내부에 게임 효과가 차오른다. **0~100을 정확히 10 논리구간**으로 나누며 각 구간은 10이다.
- 한 칸의 일부도 채운다. 예: 12는 1칸 + 다음 칸의 20%; 99는 9칸 + 마지막의 90%.
- 색은 짙은 녹색→황색→붉은색→탁한 자주색의 순서. 투명한 내부를 프레임 뒤에서 채우고 프레임의 원래 금속/석재 경계는 보존한다.

## 실제 자료
- **직접 승인받은 원본 PNG**: 2172 × 724 픽셀, RGBA, SHA256 `6f7c490b184cf65858d714c900f698ed6318a10581669bec843c5ec679f67c84`. 사용자의 대화 원본은 유지하며 원본 파일 삭제/덮어쓰기 금지.
- **Godot용 새로운 실물 이미지**: `assets/map/ui/contamination_frame_10.webp` 1440 × 480, 투명도 유지, SHA256 `4fc221b0d9639302b3b4585a1a08226000bcb230b06763e35e46478b8ce3fc8d`, 검증된 Git blob `788b46317309e04a00cb684dd263cd05e892cef6`.
- GitHub의 문자 파일 연결만으로 바이너리 전송할 수 없는 제약은 Git Blob base64 생성 → SHA 검사 → 비파괴 브랜치 커밋으로 해결함. 실행 시 base64 디코딩하지 않으며 Godot가 정상 WebP 텍스처로 읽는다.
- 기존 저해상도 파일도 **백업 겸 실패 시 대체 용도**로 저장소에서 보존한다.
- 출력 위치: 기본 Godot 논리 해상도 1280×720, 새 HUD 크기 576×192, 위치 (352,379). 게임 화면 내부 실제 구성(오염도 숫자, 바)은 10칸.
- 원화에는 실제 너비가 조금 다른 첫/마지막 구간이 포함되어 있으므로 시각적 경계 `EDGES`에 맞춰 채운다. 게임상 한 칸의 의미는 항상 10이며, 물리 폭이 정확한 10등분을 뜻하지는 않는다.

## 기본원칙 5가지
1. **Trigger**: 기존 맵의 저장된 오염도 값이 갱신되면 `MapPresentation.refresh()`로 HUD 값 갱신.
2. **Information**: `world.contamination`의 0~100, 각 10구간의 분수, 기존 지역·스토리 상태를 참조.
3. **Interaction**: HUD는 입력을 가로채지 않으며 기존 전투/이벤트/책/주사위 버튼 우선. 맵 모달의 가시성 규칙 유지.
4. **Visual**: 사용자 승인 고해상도 원화, 투명 창 안쪽만 순서대로 색이 채워지고 0.28초 안에 애니메이션으로 이동. 숫자 `n / 100` 실시간 표시.
5. **Persistence**: HUD 코드에서 저장하지 않는다. 게임의 기존 스냅샷, 보상 영수증, 마물/주사위 RNG와 관련 없는 순수 표현. 화면 닫기·로드 후 재생성되어도 값은 세이브 기준.
