# 순찰 편성판·다국어 대응 — 2026-10-26

승인된 가로형 양피지 시안을 실제 HOME 순찰 편집기에 적용한다. 세 종류 타일의 추가 수량을 직접 조절하고, 다음 지도 예상 수량과 발견 장소를 함께 표시한다.

## 표현과 번역 경계

- 배경 원화는 `assets/map/ui/patrol_planning_board_v1.png` 한 장이며 글자·숫자·구분선·타일·버튼을 포함하지 않는다. [원화 프롬프트](patrol_planning_board_art_20261026.md).
- 제목, 부제, 수량, 잠금·한도·저장 오류 안내, 툴팁, 기본값·돌아가기·확정은 모두 실제 번역 가능한 UI다. 완전한 문장을 번역한 뒤 값을 채워 언어별 어순을 분리한다.
- 컨테이너와 줄바꿈, 필요한 경우 본문 스크롤로 문장 확장에 대응한다. 하단 동작은 본문과 분리하여 긴 번역문에서도 접근할 수 있게 한다.
- 수량 조절과 언어 변경은 컨트롤을 새로 만들지 않으므로 편집 중 수량과 키보드 포커스를 유지한다. RTL은 애플리케이션 방향을 상속한다.
- 한국어/영어만 현재 정식 언어 선택지다. 긴 임시 번역과 RTL 임시 번역은 검사 전용이며 새 언어를 제공한다고 표시하지 않는다. 추가 언어를 배포할 때는 번역뿐 아니라 대상 플랫폼의 실제 글꼴 포함 범위도 확인해야 한다. 시스템 글꼴 대체가 모든 플랫폼의 모든 문자를 보장하지 않는다.

## 지도 배치·저장

Trigger는 기존 HOME 순찰 진입과 명시적 확정이다. Information은 다음 집 출발 오염도·기본 장소·발견 장소·늪·보스와 추가 수량이다. Interaction은 종류별 +/- 조절, 해금, 기본값, 돌아가기, 확정이다. Visual은 세 받침과 다음 지도/발견 장소 표다. State는 기존 종류별 수량·해금 플래그·방문 영수증만 저장한다.

다음 지도 예상과 실제 생성을 같은 순수 수량 계산으로 연결한다. 최대 추가 6칸은 상한이며, 고정 타일·영구 발견 장소·늪 예약과 오염도 변환을 보존할 실제 공간이 더 적으면 그만큼만 편성한다. 미리보기는 난수나 현재 지도를 변경하지 않는다.

이전 저장에 공간을 초과하는 편성이 있으면 조용히 발견 장소를 버리지 않는다. 안전한 수량으로 조정할 수 있게 다시 진입시키고, 수정 확정 시 같은 방문 영수증을 중복 추가하지 않는다. 실제 집 출발은 유효한 편성만 사용한다. 저장 형식과 기존 해금·회복·보스 조건은 보존한다.
