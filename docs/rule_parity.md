기준: 웹 저장소 e945ba2, GAME_DESIGN_RULES.md 및 실제 V2 전투 화면 호출.
원본 작업물은 수정하지 않는다. 본편 game.js의 원정 전체는 아직 이식하지 않았다.

| 낙인 10종 | v2-rules.js brand/roll/attack | 눈금 생성·중복 축복/저주·지원 효과·충돌 처리 |

V2SummonRules의 6눈금 소환·피격 기반 씨앗 변신은 이번 코어에 혼합하지 않았다. 현재 V2 화면은 V2Rules.begin 및 bloomPlans를 호출한다.

## 다섯 질문 적용

| 시스템 | 트리거 | 필요한 정보 | 상호작용 | 화면 변화 | 지속 상태 |

| 편성 | 카드 선택·출발 | 개체·스탯·군단·낙인 | 플레이어/군단 | 선택 표시·상세 | 편성 개체 ID |
| 이동 | 굴리기 | 위치·눈금·사건 | 원정 시스템 | 현재 타일 표시 | 위치·난수·진행 |
| 전투 | 타일 진입·라운드 | 고정 군단·마물·주사위 | 전투 코어/표시 | 체력·사망·로그 | 라운드·독 출처·불사귀·난수 |

전투 지원 효과·일반 피해 계산은 기존 V2 코드를 기준으로 이식했다. 원본 코드와 확정 문서 사이의 추가 차이는 전체 대조 테스트 단계에서 확인한다.
