# 사용한 양피지 버튼: 장소 복귀 시 낙하 — 2026-10-25

## 사용자 확인 문제와 수정

- 낙인 계승·예언은 상세 기능 화면에서 입구 양피지를 복제해 즉시 떨어뜨렸다. 성공 저장 뒤 정확한 방문 receipt에 대한 화면용 예약만 남기고, 돌아가기 전환이 끝나 집 실내/장소 배경이 복구된 다음 실제 입구 버튼을 한 번 떨어뜨리도록 수정했다.
- 제단 의식·세계수 기도·묘지 발굴·순찰도 같은 예약/복귀 규약으로 연결했다. 이동을 확정하며 장소를 떠나는 언덕의 기존 별도 연출 경로는 보존했다.
- 숙영은 버튼 생성 콜백이 아직 할당되지 않은 `heal` 지역변수를 캡처해 null을 전달했다. 클릭 시 기존 `RestHealAction` 노드를 조회해 바로 낙하하고, 회복 후 장소 화면을 다시 생성하던 코드를 제거했다. 회복 피드백 동안 출구를 잠그고 끝나면 다시 활성화한다.

## 수명과 데이터

- 보상/HP/계승·예언 결과와 방문 receipt가 성공적으로 저장된 후에만 예약/낙하한다. 저장 실패·사용하지 않고 돌아가기는 낙하하지 않는다.
- 예약은 map 인스턴스의 메모리 상태이며 저장 파일 형식은 바꾸지 않는다. 정확한 방문 ID, World 약한 참조와 재생 기록으로 다른 방문/과거 저장의 오재생과 같은 방문의 중복 재생을 막는다.
- 복귀한 실제 양피지는 부모 창의 열림 위치 Tween에서 제외하고 열림이 끝난 뒤 낙하를 시작한다. 기존 원화·양피지 비트맵·버튼 위치/크기·낙하 모션을 사용하며 상세 화면 위에 복제 버튼을 만들지 않는다.
- 같은 방문의 결과를 다시 열어 보는 기존 예언 기능은 유지한다. 이미 끝난 방문/과거 저장을 화면으로 재구성하는 것만으로 낙하를 재생하지 않는다. 새 방문에서 새로 성공한 작업은 다시 연출할 수 있다.
