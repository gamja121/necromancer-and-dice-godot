## 남은 순서와 완료 기준

1. 검증한 PC 원본을 공개 main과 병합·동기화한다. 미완성 후보와 개인 파일은 제외한다.
2. 고정 HTML 기준의 실제 게임 진입 경로, 전투, 타일·장소 행동, 보상, 사건·퀘스트, 새 원정·이어하기, 저장·복원을 기능별로 대조한다.
3. 남은 사건·대화·추가 장소와 아직 대응하지 않은 기능을 구현한다. 준비되지 않은 원고는 임의로 완성했다고 표시하지 않는다.
4. PC Godot에서 시작 → 원정 → 장소 행동 → 전투 → 보상 → 저장 → 재실행·복원까지 확인하고 원본 규칙 및 시각 대응을 기록한다.
5. 타이틀·인트로와 게임 진입 흐름, 폰트와 승인된 모션·소리를 함께 검증한다.
6. 모든 플레이 기능의 대응과 남은 차이를 기록한 뒤 완전 이식 여부를 판정한다. 현재는 완전 이식 완료 상태가 아니다.

프로젝트에 새 테스트용 UI나 임의 콘텐츠를 추가하지 않는다. 기존 검증 방법과 원본 게임 행동을 사용해 확인한다.
