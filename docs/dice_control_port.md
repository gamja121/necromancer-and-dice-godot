# 주사위 제어 카드 이식 (2026-10-08)

## 사용
맵 오른쪽 카드더미에서 보유 카드를 선택하면 1장을 소비하고 자동으로 이동 주사위를 굴린다.
중앙 전투에서는 오른쪽 위 '주사위 카드' 버튼을 사용한다. 행동 진행 중이나 영혼 수확 중에는 사용할 수 없다.
보유 카드가 없으면 빈 보관함 안내가 나온다. 확인용 카드나 버튼은 게임에 추가하지 않았다.

## 원본 대응
GitHub gamja121/necromancer-dice-board의 v2-dice-control.js, v2-map-practice.js, v2-auto-battle-practice.js를 비교했다.
2026-10-08 확인한 main의 새 변경은 UI 이미지/CSS 중심이며 위 판정 JS는 689e5064eb0e211beb03a932b3618b9f3a54c97b와 같았다.
18종: 고정 1~6, 낮음 1/2/3, 높음 4/5/6, 홀수, 짝수, 제외 1~6, 직전 눈금 반복, 직전 카드 효과 재발동.
맵과 전투의 이전 눈금/카드 기록은 서로 독립적이다. 재발동은 실제 적용된 카드 종류를 기억하므로 연속 재발동도 가능하다.
선행 기록이 없는 반복/재발동 카드는 회색으로 비활성화하고 이유를 툴팁에 표시한다.
선택한 고유 개체 ID의 카드 1장만 소비한다. 일반 굴림도 기존 흐름대로 사용할 수 있다.

## 저장과 복원
기존 version 1 저장과 호환되는 선택 필드 previous_map_roll, previous_map_card, pending_move, active_encounter를 추가했다.
이동은 카드 소비/판정/목적지/워프 및 늪지 효과를 먼저 한 번 저장하고 연출한다.
중단된 이동은 저장된 도착 지점에서 이어 가므로 이동이나 타일 효과가 중복 적용되지 않는다.
전투는 ready / rolled / actions 단계와 판정 난수, 이전 카드, 전장 상태, 남은 행동 큐를 저장한다.
행동 큐는 개체 ID로 저장한 뒤 복원된 개체 참조로 연결한다.
카드 소비와 눈금 결정은 굴림 연출 전에, 행동 결과는 타격 연출 전에 저장한다.
재시작 시 아직 실행하지 않은 행동만 이어 간다. 승패 확정 후 기존 영혼 수확/보상 저장으로 전환한다.
저장 실패 시 카드/상태/난수를 복원하며 같은 단계에서 다시 시도할 수 있다.

## 구조
- systems/dice_control.gd: 카드 판정 및 사용 조건. 시각 난수를 판정에 사용하지 않는다.
- systems/dice_control_hand.gd: 맵/전투 공용 카드 선택창.
- systems/map_state.gd, systems/run_session.gd: 사용/소비/저장 트랜잭션과 복원.
- systems/battlefield_rules.gd: 전장 상태와 행동 큐 snapshot/restore.
- map.gd, battlefield.gd: 기존 주사위 연출 및 UI 연결.

Trigger: 카드더미/전투 버튼, 카드 선택, 일반 굴림, 재실행.
Information: 보유 개체 ID, 맵/전투별 직전 눈금과 효과, 진행 단계, 행동 큐, 저장 성공 여부.
Interaction: Map/Battlefield ↔ RunSession ↔ MapState/BattlefieldRules, 공용 카드 UI.
Visual Change: 원본 카드 선택창과 사용 불가 표시, 기존 주사위 연출, 남은 장수 즉시 갱신.
Memory: 소비·판정·난수·이전 효과·중단 지점 저장. 선택창 상태와 시각 연출은 런타임에서만 관리한다.

## 확인
실제 OpenGL 실행에서 18종 판정, 사용 조건, 자동 굴림과 소비, 저장 실패 복구, JSON 복원, 중단된 이동/전투의 재개,
중단 없이 진행한 전투와 결과 동일성, 승리 후 영혼 수확/맵 복귀, 독립 전장 일반 굴림을 포함해 469개 조건을 확인했다.
최종 선택창에서는 카드 5장 중앙 배치, 반복/재발동 비활성화, 사용 직후 4/5 표시를 추가 확인했다.
확인용 스크립트는 작업 폴더에서만 실행 후 제거했으며 개인 원정 저장을 복원했다.
모바일 실기기 입력은 미확인이다. 기존 Button 입력과 보드/타일/전장 크기는 유지했다.
이번 변경은 로컬이며 commit/push하지 않았다.
