# 원본 전투 효과 이식

GitHub main의 v2-combat-effects.js, v2-hit-effects.js, v2-damage-digits.js, v2-summon-effect.js, v2-heal-effect.js를 직접 확인했다. 원본 JPG/PNG는 변경하지 않고 런타임에 프레임을 잘라 셰이더로 배경을 제거한다. 프레임 좌표, 독 용액 6번째 프레임 제외, 베기 마지막 프레임의 다른 줄, 음표의 서로 다른 폭과 배경색을 원본대로 유지한다.

도입:
- 물리, 손톱, 베기, 마법, 독가스, 바람, 음표, 깨물기, 독 용액의 9종 타격 효과. 원본 마물별 배정표 적용.
- 원본 피해/회복 숫자와 치명타/빗나감/중독/방어 차단 표시.
- 회복량에 따른 4/6/7개 십자가 입자.
- 8프레임 소환 마법진. 네 번째 프레임 시점에 소환체 등장.
- 일반/강한/특수 공격의 짧은 충돌 정지 시간 22/54/76ms를 전투 시간으로 적용.
- 실제 피해·회복·차단 발생 기록을 기존 계산 메서드의 결과에서 추출. 중독 선행 피해, 반격, 연속 타격, 흡혈/회복이 순체력 변화로 상쇄되지 않도록 각각 숫자를 표시. 소환 체력 비용도 표시한다.

기존 Godot 대기 호흡·접지 그림자·화살·약한 화면 흔들림은 유지한다. 원본 타격 시트를 쓰는 공격에는 임시 공통 불꽃을 중복 표시하지 않는다.

트리거는 실제 전투 계산 결과와 라운드 소환/변신이다. 표시 정보는 피해 종류, 개체 ID, 각 피해/회복량, 차단·치명타·상태 변화이다. 전투 수치 계산과 RNG, 원정 보유 목록은 바꾸지 않는다. 연출 기록과 일시적인 노드는 저장하지 않는다.

독립 전장 기본 편성은 해골 병사·거미 기사·역병 의사·세이렌으로 바꿔 여러 원본 효과를 직접 볼 수 있게 했다. 맵 전투는 사용자가 선택한 보유 개체 그대로 출전한다.

Godot import와 전장 시작에 오류 없음. 실제 OpenGL 렌더러로 첫 라운드를 녹화하고 소환 마법진/베기/원본 숫자 중간 프레임을 확인했다. 새 테스트 파일·버튼·패널은 추가하지 않았다. 효과음은 기존 소리를 사용하며 원본 WebAudio 합성 변형까지 모두 동일하지는 않다.
