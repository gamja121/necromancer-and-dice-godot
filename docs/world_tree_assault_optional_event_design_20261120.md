# 세계수 습격과 3가지 세계 지도 분기 — 선택형 사건 설계서
> 작성: 2026-11-20 | 대상: Codex / 게임 구현 협업 | 상태: **3단계 세계 전환·메인 진행 연결 구현**
>
> **필독:** 이 문서는 사용자가 대화에서 정한 게임 기획과 1차 밸런스 제안을 구분한다. `docs/SCENARIO_MASTER.md` 및 `AGENTS.md`의 기존 설정, 선택형 서사 원칙, 보스 규칙과 충돌시키지 말 것. **이 문서를 올렸다는 이유만으로 구현·에셋 교체·메인 스토리 수정 승인으로 해석하지 말 것.** 코덱스에게 구현 요청이 들어오면 이 문서를 먼저 읽는다.

## 현재 구현 상태

- 세계수 착지를 기존 이동 저장과 함께 기록한다. 기존 세이브에는 추정 방문을 추가하지 않으므로, 다음 실제 착지부터 기록된다.
- 일반 원정에서 기존 메인 사건과 보장 발견을 먼저 처리한 뒤 습격을 추첨한다. 적격 착지·벌목/방화·선택 대기와 확정 결과를 저장해 재접속 때 각각 이어간다.
- 기존 책에서 벌목대와 방화단의 원화로 선택을 보여 준다. 겨울·지옥 폐허 원화는 습격 결과, 세계수 방문, 왕 추적에서 사용한다. 확실한 저지는 보유 카드 중 직접 고른 한 장을 소모하고 오염도를 최대 8 올린다. 위험한 저지는 카드 소모 없는 6면 주사위 판정이다. 결과 지역은 저장 즉시 반영하고, 확인하면 기존 지역 지도 위에서 원정을 계속한다.
- 세계수가 쓰러진 겨울과 불탄 지옥에서는 세계수의 정화 기도가 중단된다. 폐허에서 전이문의 단서를 따라 마물의 왕을 추적할 수 있으며, 일반 세계에서는 기존 정화 기도를 이용할 수 있다.
- 전환 후에도 타일·말 위치, 집과 주민, 퀘스트와 보스 진행을 이어간다. 겨울·지옥 보드 배경은 현행 기본 지도 기반으로 교체했다. 전장 배경은 일반·겨울·지옥 각 3장씩 사용한다. 세계수 타일은 기존 돌 테두리와 갈색 바탕을 기준으로 벌목 뒤 잘린 단면, 방화 뒤 갈라진 윗부분과 불씨를 새긴 나무 문양을 보여 준다. 언덕 이동 미리보기에도 같은 그림을 쓴다. 전환 연출과 Steam 데모 편입은 후속 작업이다.

## 0. 목적과 최상위 원칙 — 사용자 확정

게임에는 `default` / `winter` / `hell` **서로 독립적인 3가지 세계 루트**가 존재한다.

- **일반 세계(`default`)에서도 처음부터 끝까지 원정, 기존 메인 이야기, 최종 보스까지 정상 플레이할 수 있다.** 겨울이나 지옥을 반드시 경험해야 하는 진행 조건은 없다.
- 세계 변화는 **메인 스토리가 아닌 선택형 특수 사건** `세계수 습격`의 실제 결과로만 발생한다. 오염도나 바퀴 수가 일정 기준에 도달했다고 자동 변환하지 않는다.
- **세계수를 광신도로부터 지키면 일반 지도 유지**; **광신도가 세계수를 베면 겨울**; **광신도가 세계수에 불을 지르면 지옥의 불바다**가 된다.
- 세계수는 세계의 오염 확산을 억제하는 존재다. 벌목은 생명력/온기의 단절로 겨울을, 방화는 오염된 뿌리를 타는 불길로 지옥화를 유발한다. 기존 오염도 수치·보스/스토리 진행은 임의로 초기화하지 않는다.
- 겨울에서 지옥으로 자동 진행하거나 그 역순으로 전환하지 않는다. 하나의 원정에서 습격 사건의 최종 결과는 **한 번** 확정된다.
- 사건을 만나지 못하거나 습격을 저지하면 일반 세계를 유지할 수 있으며, 이 선택형 사건을 무조건 출현시키는 보정(pity)/강제 트리거는 없다.
- 이 사건은 기존 광신도 메인 퀘스트나 마물 왕 부활/추적 사건을 대체하지 않으며, 기존 엔딩을 특정 하나로 강제하지 않는다.

## 1. 언제 사건이 등장하는가 — 대화에서 정리한 트리거

**아래 조건을 모두 충족해야 '추첨 가능한 상태'가 된다. 추첨 가능해지는 순간에는 사건을 띄우지 않는다.**

1. **세계수 해금 + 실제 세계수 타일 방문 1회 이상:** `unknown` 타일 발견 카드만 보았거나 해금만 된 것으로는 부족하다. 실제 도착/방문 확인을 별도 영속 플래그로 기록한다. *기도의 주사위 결과나 성공 여부까지 요구하지 않는다.*
2. **광신도 실제 등장 및 관련 소문 사건 완료:** 기존 `cultist_rumor_01` 완료 기록 (`event:cultist_rumor_01:complete`)을 사용한다. '광신도 의심 단서/소문만 해금'이나 `seen`만으로는 부족하다. 기존 진행 경로(아이 구조/방치와 예언가 등) 모두 호환해야 한다. **광신도 제단(`cultist_altar_encounter_01`) 완료는 필수 조건이 아니다.**
3. **원정 완료 바퀴 수 2 이상 (`world.laps >= 2`).**
4. **현재 오염도 30 이상 (`world.contamination >= 30`).** 과거 최고 오염도가 아니라 **현재 수치**를 검사한다. 기도로 낮아지면 출현이 다시 비활성화될 수 있으나 이미 등장한 사건은 취소/재추첨하지 않는다.
5. **세계 `world.region == "default"`**. 아직 이 원정에서 세계수 습격 최종 결과를 확정하지 않았어야 한다.
6. **기존 메인 사건이 없는 실제 `event` 타일 착지.** 다른 타일 원격 클릭/지도 미리보기/화면 다시 열기/로드에서는 추첨하지 않는다.
7. **전이문 부활 의식 완료 전.** 개입 결과와 관계없이 전이문 완료 기록이 저장되면 신규 습격 추첨을 닫는다. 이미 저장된 습격은 같은 공격 유형으로 이어진다.

조건 충족 후 **유효한 일반 사건 방문마다 출현 확률 30%** (독립 추첨, 누적 확률/보장 없음). 기회가 모두 빗나가면 그 원정은 습격을 만나지 않고 이어진다. 광신도 소문의 마지막 장면에서 같은 문양이 세계수 근처에서도 목격됐다는 이야기를 짧게 전한다.
출현 시 공격 유형은 **벌목 50%, 방화 50%**. **한 번 추첨한 유형은 즉시 기록·저장**, 저장/재접속/화면 전환에 다시 굴리지 않는다.

**사건 우선순위:**
- 기존 메인/필수 사건과 저장된 미완료 사건 우선.
- 현재 구현의 필수 장소 발견 (`unknown` 세계수, `altar` 제단, `forest` 언덕의 보장 발견)도 막거나 밀어내지 않는다.
- 그 다음 **선택형 세계수 습격 출현 여부**를 판단하고, 미당첨일 때만 기존 선택적 장소 발견/반복 사건 로직으로 넘어간다.
- 실제 삽입 지점·기존 플래그 호환성은 코덱스가 최신 `map.gd`, `RunSession.begin_story_free_event()`, `LocationDiscoveries`를 다시 확인해 확정한다. 현재 기존 루틴/발견 추첨을 이 문서의 30%로 대체해서는 안 된다.

### 정상/차단 사례

| 상황 | 세계수 습격 출현 |
| --- | --- |
| 오염도 60이지만 세계수 미방문 | 금지 |
| 세계수만 방문, 광신도 사건 미완료 | 금지 |
| 광신도 소문 `seen`만 있고 완료되지 않음 | 금지 |
| 두 등장 조건 만족하지만 `world.laps == 1` | 금지 |
| 두 등장 조건 만족, 3바퀴, 현재 오염도 20 | 금지 |
| 전 조건 충족, 새 일반 사건 타일 도착, 기존 선행 사건 없음 | 30% 추첨 |
| 전이문 부활 의식 완료 후의 새 착지 | 신규 추첨 종료 |
| 이미 습격을 저지했거나 겨울/지옥으로 확정 | 다시 등장 금지 |

## 2. 특수 사건의 내용과 즉시 개입 — 사용자 선택 A안

특수 사건은 **별도 세계수 타일로 찾아가는 시간제 레이스가 아니라, 사건 내부에서 즉시 저지 여부를 결정**한다. 게임이 주사위 이동 기반이어서 우연히 세계수 타일을 밟지 못했다는 이유만으로 실패하게 하지 않는다.

1. 일반 사건 타일에 실제 도착한 뒤, 위 조건/30% 판정이 통과한다.
2. `cut`(세계수 벌목대) 또는 `burn`(세계수 방화 의식) 중 하나를 50:50으로 **확정 저장**한다.
3. 원화와 대사로 광신도들이 실제로 세계수를 파괴하려 한다는 사실 및 방치·실패의 결과(겨울/지옥)를 미리 알려 준다.
4. **'확실하게 저지' / '위험하게 저지' / '개입하지 않는다'**의 세 선택지를 제공한다. 저지 판정은 사건 내부에서 즉시 처리한다.
5. 방어 성공 시 세계수는 생존하며 `default` 유지. 방어 실패/개입하지 않음은 사건 종류에 따라 `winter` 또는 `hell` 확정.
6. 결과 저장이 성공한 뒤에만 재앙 연출을 보여 주고 일반 지도/겨울 지도/지옥 지도로 되돌아간다. 원정은 계속된다.

**중요:** 기존 게임은 일반 전투에서 패하면 원정이 끝난다. 이 사건의 '저지 실패'는 **전투 패배가 아니라 이벤트 판정 실패**여야 한다. 아군 마물 영구사망, 게임오버, 기존 보스 격파 처리를 잘못 호출하지 말 것.

### 1차 비용/확률안 — *수치 최종 확정 전 조정 가능*

이전에 사용자와 검토한 구체적 초안이다. 트리거/세 결과 자체와 달리 비용·성공 확률은 밸런스 테스트 및 Codex 작업 지시에 따라 조정할 수 있다.

| 선택지 | 비용 및 판정 제안 | 결과 |
| --- | --- | --- |
| **확실하게 저지** | 보유 주사위 제어 카드 **1장 영구 소모 + 오염도 +8**, 성공률 100%. 카드가 0장이면 선택 불가. 카드 종류 선택 UX/소모 시점은 구현 전 확정 | 반드시 `default` |
| **무리하게/위험하게 저지** | 사전 카드 소모 없음. **6면 주사위 1~3 실패 / 4~6 성공 (50%)** | 성공 `default`, 실패 공격 종류에 따라 `winter`/`hell` |
| **개입하지 않는다** | 직접 자원 소모 없음 | 공격 종류에 따라 `winter`/`hell` |

- 오염도 +8이 현행 최대값 100과 상호작용하는 방식, 사용 가능한 제어 카드의 선택/소모 우선순위, 주사위 조작 카드 사용 가능 여부는 **구현 전 검토 대상**이다.
- 확실한 저지가 일반 세계 보존의 유일한 안전한 방법이며, 위험한 저지는 무료지만 세계 변화 위험을 수반한다.
- 이 사건을 보기만 했는데 게임이 자동으로 겨울/지옥이 되는 구조는 금지한다. 플레이어가 **무엇을 막을지 알 수 있어야 한다**.

## 3. 지도와 전장의 변화 — 별개의 이미지 계층

**절대 혼동 금지:** 지도 보드판의 **24칸 타일 뒤에 깔리는 지도 그림**과 전투 씬의 **전장 배경**은 별개의 자산이다.

### 보드판 뒷배경 (핵심)

- 기존 코드: `map.gd`가 `res://assets/map/maps/%s-map.jpg` % `world.region` 를 사용한다.
- 현재 파일: `assets/map/maps/default-map.jpg`, `winter-map.jpg`, `hell-map.jpg`는 존재함.
- 사용자는 **기본 지도 원화의 구도와 지형 좌표를 유지**하면서 겨울(눈/얼음), 지옥(화재/용암)으로 변환된 새 보드판 뒷배경을 원한다. **전투용 넓은 공터 배경을 만들라는 뜻이 아니다.**
- 지도 원본의 중앙 성, 상단 마을, 왼쪽 늪지와 숲, 오른쪽 묘지와 용골, 하단 의식 제단 및 천막, 길과 양피지 문양을 같은 위치에 유지해야 한다. UI 타일 24칸, 숫자, 버튼, 패널은 배경 그림에 굽지(bake) 않는다.
- 2026-11-22에 현행 기본 지도를 직접 편집한 겨울·지옥 원화로 두 파일을 교체했다. 기본 지도에서 성·마을·집·늪지·묘지·제단·천막과 길의 위치를 기준으로 삼았다.
- `region` 변경 뒤 보드판의 타일 배열, 각 타일 의미, 플레이어 위치, 순찰, 집, 보스 진행, 이벤트·저장 상태는 보존한다. 타일 재생성 금지.

### 전장 배경 (부가 연동)

- 원화 총 **9장 = 3장소 × 일반/겨울/지옥 3환경**이 사용자 목표.
- 일반: 기존 숲 + 성벽 숲 + 묘지 숲 **3장 중 전투마다 랜덤**. 현재 `systems/battle_backgrounds.gd`에서 연결됨.
- 겨울: 위 3장소의 눈 버전 3장 중 랜덤. 지옥: 같은 3장소의 화염 버전 3장 중 랜덤.
- 2026-11-22에 겨울·지옥 성벽 숲과 묘지 숲 4장을 추가했다. 실제 사용 중 워터마크가 있던 전장 5장은 같은 구도의 깨끗한 원화로 교체했고, 미사용 워터마크 전장 2장은 제거했다.
- 전장 1회에 선택된 배경은 저장·재접속해도 유지하고, 전투용 RNG·주사위 결과에 영향을 미치지 않아야 한다.

### 변화 연출

- 벌목 시 생명력/온기가 사라지는 서리→겨울 지도 전환, 방화 시 오염된 뿌리를 타는 불길→지옥 지도 전환을 **최초 확정 시 1회만** 표시하는 방향.
- 결과 기록을 성공적으로 저장한 후 연출. 로드/재접속 시 기존 결과를 재생성·재추첨하지 않는다.
- 현재 연출 길이, 효과음·컷신 상세와 최종 원화 채택은 사용자 승인 전 *제안 단계*.

## 4. 영속 상태 설계

현재 `systems/map_state.gd`는 `world.region`, `world.event_flags`, `world.story_events`, `world.pending_reward`, RNG 상태 등을 저장한다. 실제 착지와 선택 결과는 같은 v1 저장의 영수증으로 추적한다.

- `event:world_tree_assault_01:tree_visited` — 실제 세계수 방문 성공(해금만으로 세팅 금지).
- 기존 `event:cultist_rumor_01:complete` — 완료 여부 참조, 임의로 써서 이야기 진행을 건너뛰지 말 것.
- `event:world_tree_assault_01:complete` — 결과가 확정된 원정에서 재출현 금지.
- 적격 착지를 `world_tree_assault_landing`에 임시 저장해, 이동 직후 종료되어도 같은 착지에서 추첨을 이어간다.
- `world.pending_reward`에 `kind = "world_tree_assault"`, 실제 방문 ID, 공격 유형 `cut|burn`, `phase = "choice|result"`, 선택 결과, 주사위와 카드·오염도 소모 내역을 기록한다.
- 기존 `world.region`: `default|winter|hell`. 새 세이브 필드/포맷 변경을 되도록 피하고 v1 저장 복원 호환을 보장한다.
- 사용자에게 표시할 '재앙 발생 연출 확인' 상태는 별도 한 번 기록해 저장하면 재생 반복을 피할 수 있다.

**원자성:** 첫 출현 및 공격 유형 저장 → 플레이어 선택 판정 → 카드 소모/오염도 변화/세계 상태/완료 플래그 반영을 각각 필요한 원자적 저장 경계로 다룬다. 저장 실패 시 결과와 RNG를 이전 상태로 복원, 중복 보상/중복 소모/재추첨 금지. 불완료 사건은 재접속 시 같은 종류·같은 선택창으로 돌아온다.

**사용자 확정:** 벌목·방화 뒤 겨울과 지옥에서 세계수 정화 기도를 중단한다. 세계수 타일을 폐허로 방문할 수 있으며 마물의 왕 추적도 그대로 이어진다. 대체 정화 수단은 미결이다.

## 6. 구현 검증 체크리스트

- [ ] 세계수 미발견 / 해금만 / 실제 방문 상태를 구분한다.
- [ ] 광신도 `seen`만 있는 경우 차단, `complete`인 경우만 허용한다. 구조/방치·예언가 분기도 확인한다.
- [ ] 1바퀴 / 현재 오염도 29 / 이미 겨울·지옥 / 완료 후 재방문은 출현하지 않는다.
- [ ] 모든 조건 충족 후 **실제 일반 사건 착지**만 30% 추첨하며 메인 사건과 보장 발견을 가로채지 않는다.
- [ ] 당첨 시 벌목/방화 50:50; 현행 RNG와 저장·재시작, 방문 영수증이 일치한다.
- [ ] 카드 비용형 / 주사위 판정형 / 방관형 결과와 저장 실패 복구를 검사한다.
- [ ] 벌목=`winter`, 방화=`hell`, 저지=`default` 정확히 1회 적용한다.
- [ ] 일반 루트도 마지막 보스 및 기존 모든 필수 사건까지 진행할 수 있다.
- [ ] 전환 후 24타일·이동 위치·보스·주민/집 상태·기존 퀘스트·오염도를 유지한다.
- [ ] 지도를 바꿔도 기존 저장 재로드와 전장 환경이 일치하며 일반 3장 랜덤은 회귀하지 않는다.
- [ ] 겨울/지옥의 추가 전장 4장이 실제 연결되었는지, 새로운 보드판 지도 **기본 지도 원형 구도**가 맞는지 따로 확인한다.
- [ ] Windows Godot 실기 시각/조작/오디오, 모바일/Web 미리보기, 자동 회귀 모두 나눠 보고한다.
