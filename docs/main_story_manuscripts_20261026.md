## 기존 사건의 단계와 상태

진입·재개·대사·선택·저장·전투 결과의 소유권은 기존 Entry/RunSession에 그대로 둔다. 이 변경은 원화 표시만 다룬다.

- 마을은 빈 배경 → 주민 → 주인공 순서다. 같은 주민 그림을 가리키는 기존 whisper/turn 요청은 한 번만 그려 가장자리 중첩을 피한다.
- 기사단장은 이미 오른쪽으로 배치된 새 인물을 뒤집지 않는다. 주인공 답변에는 새 망토 인물을 왼쪽으로 대칭 배치한다.
- 사냥꾼 조사와 왕 추적은 서로 다른 승인 원화와 배경을 사용한다. 대화/조사 전경은 같은 사건 안에서만 재사용한다.
- 제단은 준비 의식과 개입 후 소환을 별도 전경으로 유지한다. 소환은 기존 구원화에 있던 보랏빛 형체를 새 화풍으로 옮겼으며 새로운 적/전투 규칙을 추가하지 않는다.
- 전이문은 빈 폐허 → 에너지 → 에너지+광신도 → 에너지+광신도+드래곤 암시 순서다. 기존 단일 전경 교체 방식과 타이밍을 유지하는 누적 전경을 사용한다.
- 제단/전이문 전투 후 결과와 후속/재개 화면도 새 경로를 사용한다.

기존 책 크기·클리핑·타자 표시·다음/마치기·선택 콜백과 저장 형식은 유지한다. 그림을 보여주는 것만으로 RNG·퀘스트·보상·진행을 변경하지 않는다.
