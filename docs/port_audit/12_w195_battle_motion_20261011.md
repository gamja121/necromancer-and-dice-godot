## 실제 복원

- `scripts/port_guardian_seed_frames.py`: 원본 JPEG 크기와 Git blob SHA를 강제로 검사하고 웹 `v2-seed-frames.js`의 프레임 분리·마젠타 투명처리·알파 바운딩박스·280×260 캔버스 가운데/하단 배치 규칙을 재현하는 **재실행 가능한 제작 도구**. Godot 실행 중에는 Python/웹 저장소가 필요 없다.
- `assets/battle/frames/guardian-seed`: 원본 공격 5장, 피격 3장, 사망 4장, 총 12개 PNG를 Godot 프로젝트에 직접 이관. 별도 임시 GitHub Actions 이관 작업은 원본 SHA 검증과 복원 및 커밋 완료 후 제거.
- `data/battle_visual_metrics.json`: 씨앗 메트릭 `width=280`, `height=260`, `attack=[1..5]`, `hit=[1..3]`, `death=[1..4]`와 공격 적중 프레임 지정.
- 신규 이미지까지 포함해 **전체 47종에 733개 공격·피격·사망 PNG**가 실제 파일로 존재하고 엔진에서 디코딩된다. 웹 원본 46종 및 Godot 전용 추가 1종을 모두 포함한다.
- 기존 개선 모션은 보존: `goblin-commoner` 공격 10/피격 7/사망 8 = 25장, `soul-reaper` 공격 10/피격 4/사망 11 = 25장. 과거 웹 참조 프레임 수(각각 15/16)를 기준으로 개선본을 축소하거나 재설정하지 않았다.

## 실행 경로 검증

`scripts/test_battle_motion_parity.gd`는 Godot 4.7.2 headless 엔진 내에서 다음을 검증한다.

1. 47종 모두 메트릭이 있고, 각 모션 프레임 번호가 1부터 연속되며, `res://assets/battle/frames/{slug}/{motion}-{NN}.png`를 **실제 Godot ResourceLoader**로 읽고 유효한 Texture2D로 디코딩하는지 확인.
2. 씨앗·고블린 평민·리치의 모든 갱신 프레임이 완전 투명하지 않고 모션 카운트가 정확한지 검증.
3. 실제 `battlefield.tscn`을 생성하여 씨앗·고블린 평민·리치를 전장과 카드에 표시하고, `Battlefield.animate_unit()`의 공격·피격·사망 프레임이 실제 게임 프레임 간격으로 진행되어 최종 텍스처를 적용하는지 확인.
4. `BattleVisuals.play_strike()`로 실제 전투 공격 모션을 실행해 정상 종료하는지, `BattleVisuals.play_deaths()`에서 소환물 사망 프레임 최종 표시 및 제거가 이뤄지는지 확인.
5. `.github/workflows/story-state-regression.yml`의 전체 회귀검사에 추가하여 다른 전투·스토리 기능을 깨뜨리지 않는지 확인.
