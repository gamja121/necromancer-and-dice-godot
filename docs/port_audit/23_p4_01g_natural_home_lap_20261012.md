# P4-01G — 자연 주사위 이동으로 집 귀환·다음 바퀴 연결 (2026-10-12)

## 새로운 검사 범위

기존 P4-01E 단일 원정 통합검사는 마물·전투·영혼 수확·보물·집 귀환·다음 바퀴를 연결해 이미 검증했지만, 지도 돌기 시간을 줄이려고 **집 앞 위치를 테스트상 단축**했다. P4-02E-A는 원형 24칸 지도를 조작하지 않고 공동묘지와 구조 소문까지 가지만 **집 한 바퀴를 반드시 완료하지는 않았다**.

새 `scripts/test_p4_natural_home_lap.gd`는 이 사이의 별도 공백을 검증한다.

- 최초 24칸 맵은 원본 `MapState.new(..., seed, ...)`가 그대로 생성한다. 안전한 첫 바퀴 경로를 찾기 위한 **초기 랜덤 시드 선택만** 수행한다. 이동 중 타일 교환·주인공 순간이동·주사위 강제값·스토리 완료 비트 주입·새 보상 생성이 없다.
- 5번 이상 실제 `Map.roll_move()`를 순서대로 실행한다. 각 눈금은 실제 RNG 상태를 소비하지 않고 별도 RNG로 미리 계산해 검증한다. 착지 1회 처리, 지도 배열 불변, UI 버튼 복원, 카드 미선택 상태 전투 미시작, 늪 HP 1회 감소를 검사한다.
- 마물 출전 선택창과 일반 장소 모달은 기존 UI의 닫기 경로만 사용한다. 잠긴 사건을 건드리거나 보상을 부여하지 않는다. 세 종류 이상의 자연 착지 타입을 반드시 통과한다.
- 최소 한 번 원정 중간의 `user://` 저장 파일을 재로드하고 전체 월드 스냅샷, 주사위 조작 가능 상태를 재검사한다.
- 진짜 주사위 이동으로 **15번 집 칸에 돌아온 후**, 집 들어가기→보유 마물 전원 회복→집 나가기→돌 모이기/회전/흩어지기→바퀴 수·오염도 증가·고정 타일 유지·한 번만 저장을 확인한다.
- 집을 나온 새 지도를 다시 저장 파일에서 열어 **다음 바퀴 첫 실제 주사위**까지 움직이고 이중 카운트 및 막힘을 확인한다.
- 게임 코드·실제 그림을 변경하지 않는다. 별도 PID 임시 저장 파일만 사용하며 삭제한다. `P4-01` 상위 항목은 Windows GUI/가청 오디오/원본 전체 장소 체험 전까지 TODO.
