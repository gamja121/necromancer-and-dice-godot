# 맵 설정 UI — 손으로 붓칠한 화면 (2026-10-21)

## 요청 반영
- 기존 맵 설정(오디오) 버튼을 실제 우측 상단 1192×14 / 58×58 위치로 이동했다.
- 장식적인 원본 이미지 대신 불규칙한 붓자국 톱니 아이콘을 적용했다.
- 기존 단색 직사각형 설정 팝업을 불규칙한 붓 획과 어두운 종이색의 9-slice SVG 배경으로 교체했다.
- 음악·효과음 ON/OFF와 닫기·고급 설정 버튼에도 동일한 수채/먹선 느낌을 적용하고 제목을 ‘설정’으로 표기했다.
- 제작물은 SVG 3개로 유지해 이미지 용량을 작게 하고 해상도 변경 시 깨짐을 줄였다. 레이어/클릭 위치와 Godot UI 트리 계층은 유지했다.

## 기존 기능의 유지
- Music/SFX 개별 오디오 버스 음소거, OS 기본 출력, 마스터 볼륨 조절, ConfigFile 영구 저장은 변경하지 않았다.
- 전면 장소/이벤트 창 진입 시 아이콘·팝업 숨김, 복귀 후 아이콘만 복원하는 모달 입력 차단도 유지했다.
- 맵 타일·주사위·전투·원정 세계 상태·난수·보상·저장 데이터에는 손대지 않는다.
- 이전 `map_audio_options.webp` 자산은 삭제하지 않고 둔다. 원본 자산/롤백 가능성 보존.

## 게임 변경 5원칙
1. Trigger: 우측 상단 붓그림 톱니 클릭 → 설정창 열기/닫기.
2. Information: Music/SFX 현재 음소거, 마스터 음량 및 기존 저장 설정.
3. Interaction: 설정 열기/닫기, 음악·효과음 독립 ON/OFF, 고급 설정 토글.
4. Visual: 불규칙 붓터치 아이콘/패널/버튼, 한글 제목, 상단 오른쪽.
5. Persistence: 음향 설정은 기존 ConfigFile에 저장, 붓그림·팝업 노출은 일시 UI 상태.
