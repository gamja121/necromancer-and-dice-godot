## 🟡 부분 이식
- **W002 새 원정 시작** — 새 원정 생성과 인트로 진입은 동작하지만 웹은 기존 저장이 있을 때 확인창을 거친다. Godot는 즉시 새 저장으로 덮어쓴다. → **조치:** 기존 저장이 있을 때 새 원정 확인 단계 추가.
- **W003 이어하기 노출/진입** — 이어하기 저장 검사와 맵 진입은 동작하나 웹은 저장이 없으면 숨김, Godot는 비활성 노출. → **조치:** UI 정책 확정.
- **W005 타이틀 BGM/영상 및 사운드 토글** — Godot 타이틀은 패럴랙스 연출로 바뀌었지만 웹의 타이틀 BGM/영상 오디오/타이틀 사운드 토글 대응이 없음. → **조치:** 새 타이틀 유지 여부와 타이틀 오디오 정책 확정.
- **W075 일반 이벤트 타일 기본 표시** — event 타일은 존재하지만 map.gd EVENT_IMAGES에 event 키가 없어 일반 이벤트 타일 장소 표시가 완전하지 않음. → **조치:** event 타일 배경/행동 정의 추가 또는 제거 결정.
- **W080 마물 데이터 46종** — 웹 46종은 Godot에 필드 단위로 모두 동일하나 Godot에 hero Dracula 1종이 추가되어 총 47종이며 실제 조우/보물 풀에도 포함. → **조치:** Dracula 정식 콘텐츠 승인 또는 메인 풀 제외.
- **W117 오염 기반 적 등급/편성** — 오염 단계별 수/등급 가중치는 동일하지만 Godot encounter roster에 Dracula가 추가되어 적 종류 확률 풀이 다름. → **조치:** W080 결정에 따라 encounter roster 확정.
- **W154 operationId 멱등성** — 보상/장소는 reward_receipts와 pending 상태로 중복 방지하지만 웹의 범용 operationId 공통 계층은 없음. → **조치:** 모든 변경 경로 중복 적용 불가 테스트 또는 공통 receipt 계약 추가.
- **W195 공격/피격/사망 모션** — 공격/피격/사망 모션 런타임은 있으나 일부 마물 프레임 완전성은 자산 감사 전. → **조치:** 1-5에서 마물별 프레임 누락 확인.
