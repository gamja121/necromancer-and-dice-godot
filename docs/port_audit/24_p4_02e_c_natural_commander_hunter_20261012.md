# P4-02E-C — 자연 이동으로 기사단장→마물사냥꾼 사건 이어가기 (2026-10-12)

## 기존 검사와 달라지는 점

P4-02D는 최초 공동묘지 구출→마을 소문→기사단장→마물사냥꾼→광신도/전이문/마물왕 추적 전체 사건 체인을 검사했지만, **사건 사이에서 주인공을 집에 위치시키고 착지 타일을 바꾸어 이동만 단축**했다. P4-02E-A는 원본 지도와 실제 주사위로 구출·마을 소문까지만 검증했다.

이번 신규 테스트 `scripts/test_p4_natural_commander_hunter.gd`는 기존 P4-02E-A 자연 도착 테스트를 **동일 원정/세이브 상태에서 상속 실행**하고 마을 소문 이후 실제 주사위로 다음 두 단계까지 진행한다.

- 시작은 원본 `MapState`가 생성한 24칸 타일 배열과 원본 주사위 상태. 공동묘지 구출 시 실제 전장 주사위/행동을 거치되, 예측 가능한 종료를 위해 테스트용 전투 체크포인트 능력치만 P4-02E-A와 동일하게 수정.
- 구조 마을 소문 **실제 저장 완료 후**, 기사단장을 자연 `village/event` 타일 도착으로만 발견하며, 그의 마지막 7번째 대사 확인까지 의뢰를 지급하지 않는지 확인.
- 기사단장 의뢰를 실제로 받은 뒤 마물 사냥꾼을 자연 `unknown/event` 타일 도착으로만 발견한다. 11개 원본 대사를 끝내기 전 오염 단서가 유입되지 않는지 확인.
- 각 7/11장면 중간에 **실제 맵 씬 종료→월드 JSON 재읽기→같은 대사 비트 화면 복원**을 검사한다. 이동 5회마다 저장 재실행도 별도로 확인.
- 모든 이동은 원본 `map.roll_move()` 주사위, 지나치는 장소는 기존 나가기/미선택 출전 덱 닫기/보물 정상 수령 처리. 집 방문과 타일 셔플은 실제 `session.leave_home()`·원본 연출 그대로 실행한다.
- 사건 완료 비트, 주사위 결과, 주인공 위치, 타일 순서와 수량을 **테스트에서 임의 수정하지 않는다**. 최초 무작위 지도 시드 선택과 구출 전투 능력치 고정은 앞선 P4-02E-A와 동일한 한정된 시험 조건.

이 검사는 무단축 **공동묘지→구조 마을 소문→기사단장→마물사냥꾼** 사건 연쇄의 자동검사이며, **이후 광신도·제단·전이문·마물왕까지 전 경로를 자연 이동한 증거는 아니다.** PC Windows GUI/오디오/게임 화면 및 원본 미술 승인은 `P4-02E-B`의 별도 TODO. 기존 HTML 웹 저장소와 사용자 자료를 수정하거나 삭제하지 않는다.
