# 장소 기능 화면 전장 프레임 유지 (2026-10-13)

## 적용 원칙
- **원화 복원**: `village.jpg`, `graveyard.jpg`, `altar.jpg`, `home.jpg`, `fortune-teller.jpg` 다섯 장의 Git Blob SHA가 사용자가 승인한 직전 교체용 ZIP과 모두 정확히 동일하므로 이미지 파일은 변경하지 않는다. 신규 프레임 합성 그림은 사용하지 않는다.
- **동일 화면 규격**: 위치 장면과 해당 기능 화면 모두 기존 `map.location_scene_image()`를 사용한다. 원화 영역 `(150,148) 980×406`, 프레임 `(128,126) 1024×450`, 동일 `battle_frame.png`, 동일 `NinePatchRect` 설정, `STRETCH_KEEP_ASPECT_COVERED`.
- **전환 후 유지**: 마을 상점, 제단 의식, 예언, 공동묘지/언덕/세계수 기능, 집 순찰 및 낙인 계승에서 공통 배경·프레임을 표시. 기능을 종료하면 기존 일반 장소 원화·프레임으로 복귀.
- **예외**: 각 기능의 카드·두루마리·의식용 판·보상 UI는 기존대로 그림 위에 놓인다. 서사 전용 컷신/전투 장면은 변경하지 않는다.
- **무변경**: 보드 타일 아이콘, 전장, 집 실내 원화, 게임 보상·저장/RNG/행동 제약 및 함수 콜백.

## 핵심 5원칙
1. **Trigger**: 장소에서 기능 버튼을 누르거나 집의 계승/순찰 기능을 열 때.
2. **Information**: 장소 타입과 그에 대응하는 이미지만 구별하며 추가 데이터 수집 없음.
3. **Interaction**: 종전 기능별 버튼 이벤트 유지; 패널이 열려도 하부 보드의 터치 차단 유지.
4. **Visual**: 화면 간 크기·원화 비율·전장 프레임을 통일하고 기능용 카드/선택 UI만 그 위에 표시.
5. **Persistence**: 시각 요소는 세션 상태를 저장하거나 바꾸지 않고 기존 기능의 저장만 유지.
