# 사건 화면 시각 이식 4B — 나머지 7개 사건군
4단계의 공동묘지·구울·시체 추출 기능 및 기존 P4 사건/전투 처리의 **후속 시각 배치 단계**.

웹 원본 `v2-event-lab.html/css`의 좌측 사건 장면 + 우측 양피지형 제목·효과·대화·선택 버튼 레이아웃을 Godot의 나머지 사건 단계에도 공통 적용.

대상: 마을 소문, 기사단장, 마물 사냥꾼, 광신도 소문, 마물 왕의 흔적, 부활 의식, 광신도 제단.

- `map.gd` 새 `style_standard_story_panel`: 각 이벤트가 이미 표시한 실제 배경·등장 레이어·제목/사건 정보/대사 텍스트를 재배치한다. 해당 사건의 그림을 다른 사건에 잘못 섞지 않는다.
- 이벤트 마무리/선택/나가기 등 직접 자식 `Button`의 기존 연결 `Callable`은 그대로 유지하고 원본의 우측 열에 세로 정렬한다.
- 사건 고유 진행도, 선택, 승패, 영구 사망, 재도전, 보상/저장은 변경하지 않는다.
- 공동묘지 아이 사건은 전용 `graveyard_story_chrome` 유지. 후속 사건/결말 화면의 세부 아트도 다른 개별 검증 대상이다.
- 사용자가 보는 동일 장면의 실제 PC/Android 캡처 비교는 아직 미실시이므로 픽셀 단위 원본 동일성은 주장하지 않는다.

검증 기준: Trigger(기존 사건 분기), Information(기존 텍스트), Interaction(기존 버튼 및 전투 호출), Visual(좌측 이미지/우측 양피지·선택지), Persistence(원본 저장·진행 유지). CI에서 7군 적용 여부, 최대 4개 선택지 간섭·원본 콜백, 광신도 및 공동묘지 실제 분기 회귀를 검사한다.
