## 게임 기본 5원칙

1. **Trigger:** 기존 주사위 도착 또는 저장 사건 흐름이 일반 장소 `show_location()` / `show_home()`을 표시할 때. 새로운 사건/트리거 없음.
2. **Information:** 고정 웹 CSS 레이아웃 수치, 원화 16:9 크기, 현재 장소 타입과 기존 `session`으로 판단한 버튼 활성 상태.
3. **Interaction:** 기존 나가기·행동·계승·순찰 버튼 콜백 그대로. 배경 ColorRect는 투명해도 터치가 뒤 지도에 전달되지 않도록 유지.
4. **Visual:** 원화를 원본 크기로 정렬하고 장소 오른쪽 빈 레일에 버튼 배치, 일반 장소에서 검은 암막 제거. 서사 모달과 보유/편성 모달은 기존 어두운 배경 유지.
5. **Persistence:** 이 단계는 화면 속성만 변경. RNG, 보유 카드, HP, 제단 결과, 보상 영수증, 저장 파일 형식에는 새 상태를 추가하거나 수정하지 않음.
