# 일반 타일 장소: 전장과 동일 프레임·화면 규격 (2026-10-12)

## 요청 및 범위
- 장소 이벤트 그림(마을, 묘지, 제단, 집 외관, 예언자의 막사) 5종을 사용자 승인 1536×864 원화로 교체한다. 집 실내·스토리 캐릭터·보드 타일 아이콘은 유지한다.
- 일반 장소 7종과 집 내·외부의 그림 표시 영역을 실전 중앙 전장의 동일 좌표로 표시한다.
- 기존의 전장 프레임 이미지 `res://assets/map/ui/battle_frame.png`를 같은 NinePatchRect 설정으로 장소 씬에도 적용한다.
- 16:9 원화는 `STRETCH_KEEP_ASPECT_COVERED`를 사용해 그림 형태를 찌그러뜨리지 않고 위아래를 중앙 기준으로 잘라 전장과 같은 화면 비율로 표시한다.

## 배치
- 전장 프레임: `Rect2(128,126,1024,450)`.
- 실제 그림: `Rect2(150,148,980,406)`; 980:406 (전장 실제 표시 영역과 동일).
- 프레임: `scale=0.22`, patch margins `left/right=170`, `top/bottom=150`, `draw_center=false`.
- 그림 아래에 선택 버튼을 가로 배열해서 그림과 겹치지 않게 한다. 스토리용 `TILE_EVENT_SCENE_RECT`는 그대로 16:9 별도 사용.

## 게임 UI 5원칙
1. **Trigger:** 기존 위치 타일 도착, 집 외관·실내 열기. 새 트리거 없음.
2. **Information:** 기존 장소 종류와 사용 가능 행동, 그림·테두리의 위치. 추가 게임 정보 없음.
3. **Interaction:** 버튼의 원래 콜백, 가능 여부, 입장/퇴장·의식·보상 확인 그대로. 새 입력 없음.
4. **Visual:** 전장과 동일한 실제 프레임, 장소 원화는 왜곡 없는 중앙 크롭, 버튼은 프레임 아래. 일반 장소의 뒤 보드·투명 모달을 그대로 유지.
5. **Persistence:** 진행 기록·해금·보상·저장 파일과 RNG 변경 없음.
