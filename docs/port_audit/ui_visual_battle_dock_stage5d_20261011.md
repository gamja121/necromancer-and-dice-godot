# 5단계 D — 원본 전투 하단 마물 카드 도킹/사망 연출

고정 원본: `necromancer-dice-board/reference/html-final@e13d5149fcecc802e5d626f3bef6e5daecd3d66c`.
비교: `v2-auto-battle-practice.css` 2~17,42~45행; `v2-unit-cards.js` 31~113행.

## 확인한 원본·Godot 대응
- 원본 카드 크기 CSS: 높이 `clamp(72px, 16dvh, 118px)` / 카드 비율 `370:540`.
- 원본 카드 고정 위치: 전장 아군·적군의 실제 개별 슬롯 중심, 하단 8px + 준비시 16px 아래.
- 선택 상태: 위로 24px 상승 / 앞쪽 표시, 마물 정보창 활성.
- 행동 단계: 바닥에서 20px만 보이도록 내려가며 클릭 금지. 대기 복귀 후 다시 표시.
- 사망 상태: 카드 그림만 **흑백 + 알파 60%**. 영혼 수확 등으로 사라진 대상은 `removed`에 의해 숨김.

기존 Godot `battlefield.gd`의 720px 카드 크기와 카드 중심/선택 이동은 원본과 거의 동일했지만 530px 임베디드 전장에서도 115.2px 크기를 유지하고, 사망 카드 전체를 단순 짙은 회색으로 처리했다.

## 변경
- 카드 높이를 화면별 16% 기준으로 변경 (720→115.2px, 530→84.8px), 카드 비율·슬롯 중심 유지.
- 준비/선택/행동 카드 좌표 원본 유지; 행동 전환시 UI 선택 상태 초기화.
- `ShaderMaterial`로 사망 카드 텍스처만 흑백/60% 알파 처리. 기존 브랜드·제단 뱃지 자식 아트, 죽은 마물의 게임 상태, 무덤·영구사망 규칙은 수정하지 않는다.
- `visuals.removed`에 들어간 카드 숨김/비활성, 성능 및 저장 영향은 전용/전투 회귀검사로 확인.
