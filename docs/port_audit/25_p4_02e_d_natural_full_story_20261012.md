# P4-02E-D — 원본 지도/주사위 8개 사건 전체 자연 이동 회귀 (2026-10-12)

## 기존 검사와 다른 점

- `P4-02D`: 8개 스토리의 시작·분기/결과는 테스트용 HOME 복귀·타일 교환으로 도달 시간을 줄여 검증.
- `P4-02E-A`: 동일한 자연 맵에서 공동묘지 실제 구출→마을 소문까지.
- `P4-02E-C`: 같은 자연 원정의 기사단장 7장면→마물 사냥꾼 11장면과 저장 재시작까지.
- **본 `P4-02E-D`**: 위 사건을 한 원정에서 그대로 진행하고, 광신도 소문(6장면)→제단(지나간다 선택과 후속 완료)→전이문(저지 선언·원본 출전 덱·실제 주사위 전투 승리·결과 확인·불완전 부활)→마물왕 추적(5장면·봉인된 폐허 확인)을 실제 맵 이동으로 연결. 전투 승/패 **양쪽** 분기는 이미 P4-02D 등의 별도 검사이며, 이 연쇄는 **승리/불완전 부활**만 검사한다.

## 불변식

1. 시작 시 원본 `MapState` 생성 시드 하나를 시험 조건으로 선택한 후, 타일 배열·개수·지도 좌표·주사위 눈금·퀘스트 비트를 테스트에서 인위적으로 조작하지 않는다.
2. 전부 사용자 경로 `Map.roll_move()` 사용. 임의의 HOME 순간이동, 타일 맞교환, 코드에서 사건 상태 사전 완료, 조작된 주사위 결과, 사용자 보상 생성 금지.
3. 기존 UI에서 `계속`, `지나간다`, `마치기`, `저지한다`, 출전 마물 선택, 전투 반환, `부활 확인`을 실제 클릭하고 완료 이전 보상/퀘스트 차단을 검사한다.
4. 공동묘지 구울 및 전이문 저지 전투의 **시험용으로만** 출전 유닛 공격력/속도와 적 HP를 고정한 후, Godot 기존 전장 주사위·공격/결과 흐름으로 승리한다. 실제 전투 규칙은 변경하지 않는다.
5. 광신도 소문/제단/전이문/왕 추적의 중간 비트 및 전투 결과 장면을 실제 씬 제거·`session.reload_world()`·씬 재개로 복원 검증. 이동 중간의 JSON 스냅샷 일치와 집 돌 셔플, 영구 결과 고유성 확인.
6. 각 스토리는 실제 원본 규칙에서 허용되는 `village/event`, `altar/event`, `forest/event`, `unknown/event` 도착 시에만 진행. 최초 구출/그 이후 모든 원정 비트를 한 파일의 단일 저장 상태에서 이어간다.
7. 기존 Godot 게임 소스·원본 이미지·HTML 웹 저장소·PC 로컬 자료를 수정하지 않는다. `user://`의 PID 전용 시험 저장파일만 생성/삭제.

## 판정 경계

`P4-02E-D` 자동 CI 성공은 기존 UI와 Godot 헤드리스 엔진의 **한 건의 실제 맵 자연 이동 일관성 검사**다. 모든 지도 시드, 실전 무보정 전투의 승률, 모든 유닛 그래픽/오디오를 보장하지 않으며 `P4-02E-B` Windows 실기 화면·오디오/사용자 승인과 별도다. P4-02 전체, P5-03/P5-04 및 PC 백업도 완결 처리하지 않는다.

- 고정 시험 지도 시드/전투 능력치 편의를 일반 난이도·모든 지도 시드·실제 육안/가청 승인으로 확대 해석하지 않는다. Windows 실기 검수와 외부 백업은 여전히 별도 대기한다.
