## PC 안전 조치와 동기화 기록

PC 활성 프로젝트는 `C:/Dev/necromancer_and_dice`, 엔진 Godot 4.7.2 Standard Compatibility 렌더러. `D:/Workspace/Games/necromancer-and-dice`는 원본/참조 아카이브다. 원본 웹 저장소 `gamja121/necromancer-dice-board` 및 고정 브랜치 `reference/html-final`은 읽기 전용 보존한다.

PC 담당자가 **직접** 다음을 수행하고 실제 결과와 실측 SHA를 기록한다.

1. PC에서 `git status --short`, `git branch --show-current`, `git rev-parse HEAD`로 작업 위치 및 변경 파일 확인. 완료되지 않은 PC 변경 사항과 개인 `user://` 저장·음향 설정은 별도로 보존한다. `git reset --hard`, 강제 push, 원본 에셋 삭제 금지.
2. `git fetch origin main` 후 PC 미완료 작업을 안전하게 보존/통합하여 최신 공개 `main`을 작업 폴더에 반영한다. `git rev-parse HEAD`와 `git rev-parse origin/main`을 비교하고 실제 파일·에셋도 확인한다. 충돌 시 로컬 작업을 버리지 말고 해결 전까지 동기화는 미완료로 표기한다.
3. Godot 4.7.2 에디터로 프로젝트 열기/import → F5 실행. 소리(기기 출력 포함), 사용자 입력, 창 크기, 글자·레이어·배경·카드 표시를 직접 확인한다. 개인 세이브 대신 사전 백업한 테스트용 원정으로 검사한다.
4. CI 정보: 최신 공개 `main` commit 및 <https://github.com/gamja121/necromancer-and-dice-godot/actions/workflows/story-state-regression.yml>의 성공 기록과 Web 빌드 기록을 함께 첨부한다. **GitHub main 통과만으로 PC 검증 합격이라고 적지 않는다.**
