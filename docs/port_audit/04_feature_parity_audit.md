   - Godot는 단일 프로세스 + tmp→rename 저장이라 웹과 구조가 다르다. 최종 저장 정책에서 동등성 확정 필요.

## 추가 발견

### 마물 데이터
웹 `v2-design-data.js`의 **46종을 파싱해 Godot `data/units.json`과 직접 비교**했다.
- 누락: 0
- 웹 46종의 데이터 차이: 0
- Godot 추가: `dracula` 1종

### 주사위 물리 연출
Godot `systems/dice_animation.gd`는 결과 RNG와 별개의 `visual_rng`를 사용하고 감속, 보드 경계 충돌/반사, 착지 효과를 구현한다. 웹의 “판정과 시각 난수 분리” 원칙을 보존한다.

### 저장 방식
Godot는 저장 전에 상태 snapshot을 잡고, 저장 실패 시 restore하는 패턴을 장소/보상/전투 결과에 사용한다. 웹의 IndexedDB transaction 구현과 코드는 다르지만 원자적 변경 목적은 상당 부분 대응한다.
