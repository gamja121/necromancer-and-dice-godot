## 검수 절차

1. 인증정보나 개인 저장을 건드리지 않고 PC의 실제 활성 프로젝트에서 GitHub `main` 변경을 안전하게 동기화한다. 로컬 변경을 보존하고 두 HEAD SHA를 기록한다.
2. 일반 플레이/디버그 전장으로 카드 및 4마리 편성을 관찰한다. 전체 자동 시연 보조용으로 Windows GUI에서 `godot --path . --script res://scripts/test_p4_all_monster_presentation.gd`를 **`--headless` 없이** 실행할 수 있다. 자동 시연은 마지막에 종료되므로 별도 화면 녹화를 준비한다. 이 명령의 자동 PASS는 육안 검수 대체 불가.
3. 각 47종마다 카드 원본 그림, 상세 정보 이름·초상·수치·낙인, 전장 캐릭터 크기와 좌우 표시, 공격 프레임 연결, 피격 반응, 사망 마지막 프레임과 카드 숨김을 GUI에서 살펴본다.
4. 공통 품질: 투명 배경/검은·흰 사각형 잔류, 캐릭터 잘림, 과도한 확대, 좌우 반전 이상, 프레임 떨림, 공격 타격점과 HP 감소 순서, 영구사망 소멸 효과, 사운드 타이밍/볼륨/중첩 이상을 기록한다.
5. 드라큘라: **기존 보유 개체** 카드/상세/전장 및 영구사망 소멸을 확인하고, 정상 랜덤 조우·상자 보상 신규 출현은 없음을 별도 확인한다. 신규 콘텐츠 추가 승인으로 해석하지 않는다.
6. 각 항목의 실제 시각 관측 증거를 남기고 이상이 있으면 종·모션·프레임 번호·재현 단계·스크린샷을 명시한다. 모두 실기 승인되기 전에는 `P4-04B`, 상위 `P4-04`를 `DONE`으로 표시하지 않는다.
