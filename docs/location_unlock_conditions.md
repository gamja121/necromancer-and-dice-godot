# 장소별 조건부 발견 규칙 — 2026-10-14

## 제단 조기 발견 조정 — 2026-10-25

- 제단이 광신도 소문(오염도 40 이후)을 본 뒤에야 발견 후보가 되던 조건을 앞당겨, **최고 오염도 20 이상**부터 발견 후보로 허용한다. 기존 소문 seen/플래그 조건도 구형 저장 호환을 위해 유지한다.
- 장소 발견 선택은 적격 **세계수 → 제단 → 나머지 기존 순서**로 처리한다. 메인 사건 우선, 발견 40%/루틴 60%, 등록·맵 생성 순서, 안전한 빈 길 변환은 유지한다.
- 장소가 일찍 발견되면 기존 피의 의식 기능을 이용할 수 있다. 광신도 제단 메인 사건은 기존 오염도 50·소문 완료·추적 퀘스트 조건을 그대로 요구하며, 발견만으로 스토리/퀘스트를 지급하지 않는다.
- 현재 오염이 낮아져도 최고 기록과 해금은 유지한다. 이미 발견한 제단은 다시 지급하지 않는다.

- 제단 조정 검증: 장소 발견/20 경계·우선순위·저장 133/0, 다섯 장소 실제 도착 120/0, 기존 루틴 카드/추첨 240/0, 광신도 제단 메인 사건 80/0. UI 검사는 격리된 음소거 프로필을 사용했으며 실제 게임 창을 열지 않았다.

## 세계수 조기 등장 조정 — 2026-10-25

- 사용자 요청에 따라 세계수 발견의 최고 오염도 조건을 20→14로 낮췄다. 기본 완주 증가 +7 기준 후보 진입이 21(3회)에서 14(2회)로 한 번 앞당겨진다. 전투·기도 등 실제 오염도 변화에 따라 시점은 달라진다.
- 메인 사건 우선 처리 뒤, 장소 발견 대상이 선택되면 적격 세계수를 다른 추가 장소보다 먼저 고른다. 발견 40% / 루틴 60%, 실제 사건 타일 도착, 안전한 빈 길 변환, 기존 저장/중복 방지는 그대로다.
- `Discovery.ORDER`는 지도 생성에도 쓰이므로 변경하지 않고 `next_eligible()`의 선택 우선순위만 조정했다. 사냥꾼 사건은 기존 수정대로 세계수 타일 실배치 이후에만 처음 시작한다.
- 정화로 현재 오염이 낮아져도 최고 기록과 세계수 후보/해금은 유지한다. 이미 해금한 저장에 중복 타일을 추가하지 않는다.

- 검증: 장소 카드·14 경계/우선순위/저장 119/0, 실제 다섯 장소 발견 120/0, 루틴 여섯 카드·기존 추첨/저장 240/0, 사냥꾼 등장 순서/재개 302/0, Godot 4.7.2 import 오류 없음. UI 전용 최종 두 검사는 격리된 음소거 프로필로 실행해 오디오 종료 경고와 분리했으며 게임의 오디오 설정은 건드리지 않았다.

## 2026-10-15 단계별 구현 — 실제 Godot 발견 카드와 조건 연결

- **이미 구현된 언덕 1차**를 공통 카드로 재사용하고, 남은 **숙영 / 공동묘지 / 세계수 / 제단** 발견 카드를 Godot 런타임에 연결했다. 모든 카드는 확인 버튼이 없고 한 번 탭/클릭하면 사라지며, 발견과 동시에 보호 길을 제외한 빈 `basic` 한 칸이 해당 지형으로 바뀐다. 현재 맵 변경·장소 해금·집 `NEW`는 함께 저장하며, 저장 실패 시 전부 복구한다.
- **임시 조건 구현안(최종 밸런스 확정 아님):** 숙영은 첫 바퀴 뒤 아군 피해 이력, 공동묘지는 아이 사건 발견 또는 사망 마물 기록, 세계수는 최고 오염도 14 이상 이력, 제단은 최고 오염도 20 이상 또는 기존 광신도 소문 발견 이력. 조건을 만족하더라도 실제 `event` 타일을 밟지 않으면 카드는 나타나지 않는다. 메인 사건 우선은 동일하다.
- 기존 숙영 **집의 수동 해금**은 제거하지 않았다. 이미 수동 해금한 저장은 추가 숙영 발견 카드를 중복으로 받지 않는다. 사건에서 숙영을 발견했다면 무료 숙영 1칸이 생기고, 집에서 추가 선택 가능한 숙영은 2칸으로 제한해 총 최대 3칸을 유지한다.
- 기존 공동묘지 **첫 완주 후 자동 1칸**은 보존하며, 사건을 통한 발견은 *추가* 1칸이다. 언덕도 기존 1칸에 사건 발견 1칸을 더하는 구형 세이브 호환 규칙을 유지한다. 세계수·제단의 이야기 기능도 그대로 사용한다.
- 장소 발견 선택은 적격 세계수(`unknown`) 다음 제단(`altar`)을 우선한다. 그 외에는 기존 `forest → rest → graveyard` 순을 따른다. **발견/루틴 확률은 미확정**이므로 새 랜덤 비율을 만들지 않았고, 발견 후보가 없으면 기존 사건 타일 화면 동작을 유지한다. `routine_event`의 신규 확률형 이벤트/카드 보상은 아직 별도 작업이다.
- 발견 카드 원화는 현재 게임의 실제 장소 그림을 사용한다. `camp.jpg`는 기존 숙영 장면으로, 완성된 별도 발견 원화는 나중에 연결할 수 있다.
- 회귀 테스트: `scripts/test_remaining_discovery_cards.gd`, 기존 `scripts/test_event_discovery_arrival_integration.gd`, `scripts/test_patrol_six_slots_unlocks.gd`.


> 사용자 요구: "장소 발견도 조건으로 달자." 장소 해금 여부는 단순 전체 무작위가 아니라 **장소별 자격 조건(조건식)** 으로 판정한다. 메인 사건은 항상 우선한다. 해당 장소가 **아직 해금되지 않았고**, 조건을 충족하고, 실제 사건 타일에 도착했을 때만 '장소 발견'의 후보가 된다.
> 아래 **장소별 세부 조건은 제안안**이다. 사용자 확정 없이 임의 수치/이벤트 조건을 실제 런타임에 하드코딩하지 않는다. 게임 코드는 아직 이 신규 규칙으로 전환되지 않았다.

## 사건 타일의 판정 순서 — 확정된 방향

1. 주사위/경로 이동으로 **실제 사건(event) 타일에 도착**했을 때만 새로운 사건의 추첨 기회를 만든다. 다른 타일 미리보기, 맵 화면 재열기, 저장 불러오기, 이벤트 대화 재개 등에서는 다시 추첨하지 않는다.
2. **기존 메인 사건/그 재개·선택·전투 결과 표시가 무조건 우선**. 현재 `map.gd:show_tile`의 스토리 가드 순서를 유지한다. 기존 사건의 시작/저장에 오류가 났다면 후순위 발견·루틴 보상으로 우회하지 않고 원래 사건을 복구한다.
3. 진행 가능한 기존 사건이 없으면 **각 장소별 영속 조건식**을 검사한다. `not unlocked(tile)` **AND** `prerequisites_met(tile,world)`를 만족하는 장소만 발견 후보에 포함한다. 발견하지 않은 장소라는 이유만으로 추첨 후보가 되는 것이 아니다.
4. 발견 자격을 만족하는 장소가 **0개이면 루틴 사건 100%**. 후보가 있다면 **장소 발견과 루틴 사건을 섞어서** 이번 방문의 유형을 정한다(시험안: 장소 발견 40%, 루틴 60%). 선정된 장소 발견에는 자격 있는 장소 중 **하나만** 지급한다. 확률은 최종 확정되지 않았다.
5. 사건 선택/결과, RNG와 발견/보상 영수증을 원정에 저장한 뒤 출력한다. 방문당 발견 1개 또는 루틴 1개만 발생한다. 한 장소를 발견한 뒤에는 재발견하지 않는다.
6. 장소 발견 상태는 **원정 지속**: 이후 오염도가 기도 등으로 내려가거나 일시적으로 그 당시 조건을 만족하지 못해도 해금이 취소되지 않는다. 조건 평가에 '한 번 이상 도달'이 필요하면 현재값 대신 별도 영속 기록 또는 사건 완료 플래그를 사용한다.

## 장소별 해금 조건 제안 — 수치/절차 최종 승인 전

| 장소/기존 내부 타일 | 제안하는 **발견 후보 진입 조건** | 예시 발견 대사 | 주의 |
| --- | --- | --- | --- |
| 언덕 `forest` | **첫 순찰을 완료**하고 집을 나섰던 기록(`laps >= 1`), 아직 미발견 | "낡은 길 너머 작은 언덕을 발견했다." | 현재 코드에는 시작부터 언덕 1칸이 있어 신규 기획과 충돌 |
| 숙영 `rest` | 원정에서 **아군이 처음 체력 피해를 입은 기록**(`ever_injured`) 또는 구호 관련 루틴 사건 완료. 최초 발견 이후 편성 가능 | "버려진 숙영지를 발견했다." | 단순 현재 HP 검사 대신 지속 플래그 사용. 기존 '첫 바퀴 후 집에서 해금' 규칙 대체 필요. 기존 최대 3칸 제한은 별도 변경 전 유지 |
| 공동묘지 `graveyard` | **아이/묘지 관련 메인 사건을 발견했거나** 아군 영구사망 기록이 있음 | "성벽 바깥에 오래된 공동묘지가 있었다." | 현재 코드의 1바퀴 이후 묘지 자동 배치 규칙과 충돌. 아이 사건은 일반 사건 타일에서도 시작 가능하므로 선후조건 교착을 만들지 않음 |
| 세계수 `unknown` | **오염도 14 이상에 도달한 적**이 있는 기록(예시 임계 수치, 최종 밸런스 미확정) | "뒤틀린 숲 너머 거대한 세계수의 흔적을 발견했다." | 기존 정화 기도 기능은 묶지 말 것. 현재 오염도가 떨어졌다고 후보 자격이 취소되지 않도록 `max_contamination_reached` 기록 필요 |
| 제단 `altar` | **광신도 관련 메인 사건/소문을 발견한 기록** | "광신도들이 사용하던 제단을 발견했다." | 스토리에서 제단/일반 사건 타일 모두 진입 가능하므로 메인 사건 진행을 막지 않도록 설계 |

- 위 다섯 장소는 **후보 예시이며 최종 잠금 대상 목록이 아직 확정된 것은 아니다**. 등록된 타일의 '해금 대상 여부', 정확한 조건, 수량 제한, 발견 순서, 해금 즉시 보드 변경인지 집 편성 후 반영인지는 별도 확정이 필요하다.
- **집·마을·점술가의 막사 및 사건 타일**은 기본 고정 배치 장소로 남긴다. **보스**는 기존 사용자의 **오염도 20/40/60별 보스 단계 + 최종 보스** 기획과 분리하고 장소 발견 목록에 넣지 않는다. **늪지대**는 기존 오염도 자동 변형과 예약 길 규칙을 따른다.
- 보물상자·워프는 현재 시작 보드에 이미 등장한다. 별도 해금 타일로 옮기라는 요청 전에는 게임에서 임의로 제거하거나 잠그지 않는다.
- 루틴 사건 중 특정 선택지가 조건 플래그(`helped_wounded_soldier` 등)를 남겨 **다른 장소 발견의 조건이 되는 방식**은 가능하다. 하지만 조건 충족 즉시 장소를 지급하지 않고 **다음 실제 사건 타일 방문**에서 후보가 된다.

## 설계·구현 세부 사양

- 데이터를 `tile_unlock_rules` 같은 **선언적 규칙 레지스트리**로 관리한다. 각 장소에 `tile_id`, `requires`, `once`, `discovery_text`, `placement_policy`를 둔다. 조건은 `min_laps`, `historical_contamination`, `story_flag`, `ever_injured`와 같은 **명시적으로 지원한 키**만 허용한다(아직 코드 미구현).
- **조건 평가와 선택/지급을 분리**한다. 예: `eligible_discoveries(world) -> Array` 는 순수 판정, `begin_event_arrival`은 후보 선택 및 방문 결정을 1회만 저장, `claim_discovery`는 발견 플래그와 영수증 저장.
- 사건 슬롯이 기존 기본 1칸이므로 조건을 너무 엄격하게 잡으면 장소를 영영 발견 못 할 수 있다. **첫 발견 지연, 카드 수급, 루틴 사건 빈도**를 플레이 테스트에서 함께 측정하고 조정한다.
- 최초 발생의 자격 조건이 한 번 참이 된 뒤 계속 해금 후보에 남아야 하는 조건은 **최고 오염도/최초 피해 같은 영속 기록**을 별도로 저장. 이미 해금된 장소는 조건 변경·기도·맵 셔플로 다시 잠기면 안 된다.
- 집 편성 이후 다음 맵에 놓는 제안안을 기본으로 삼되 사용자 확정 전 즉시 현 보드 변환을 게임 코드에 추가하지 않는다. 고정 위치 0/8/15, 보스 슬롯, 사건 타일, 오염 늪지 예약 도로 2칸과 24칸 지도 형상을 보호한다.
- 구형 저장 마이그레이션: 새 기록이 없는 기존 `user://map_run_v1.json` 에서도 맵 진입이 정상 동작해야 하며 이전에 이미 보드에 등장했던 장소를 거꾸로 잠그지 않도록 별도 호환 정책을 수립한다.

## 5원칙 및 회귀 검사

- **Trigger**: 실제 사건 타일 도착 + 기존 스토리 불충족 + 특정 장소의 자격 충족.
- **Information**: 스토리 진행 플래그, 최고 오염도, 첫 피해 기록, 해금 여부, 현 방문 영수증, 난수 상태.
- **Interaction**: `map.gd` 메인 사건 라우터 → 발견 조건 레지스트리 → 루틴 사건 추첨/해금 저장 → 집 편성/맵 생성.
- **Visual**: 조건 미충족 장소의 발견 대사는 노출하지 않음. 해금 시 이름·타일 그림·간단 대사, 집 편성 잠금 해제와 다음 보드 타일 전환 표시.
- **Memory**: 재접속/중단/저장 실패에도 단 한번의 선택·해금만 수행. 일시적 조건 하락은 이미 획득한 발견을 회수하지 않음.
