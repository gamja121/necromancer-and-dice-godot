## 사용
세계수: 타일 → 기도. 주사위 1~3은 오염 +1, 4~5는 -3, 6은 -5.
오염도는 0~100으로 제한한다. 방문당 한 번, 판정과 오염을 연출 전에 함께 저장한다.
닫기/재실행으로 다시 굴리지 않으며 사용한 방문은 결과를 보여준다.
기도는 이동이나 제어 카드의 이전 주사위 기록을 바꾸지 않는다. 현재 맵은 재배치하지 않는다.

공동묘지 (2026-10-21 변경): '시체 파헤치기' → 무작위 주사위 제어 카드 1장 발굴. 아군 마물의 사망 시체가 없어도 방문당 1회 이용 가능.
기존 주사위 제어 카드 18종을 균등 무작위로 선택하고, 5장 제한이 차면 원래의 교체/신규 카드 포기 UI로 진입한다.
발굴 보상의 종류·고유 ID·방문 ID를 저장하므로 중간 저장 후 복원할 때 다시 추첨하지 않는다. 교체/포기가 끝난 후에만 발굴 방문을 완료한 것으로 기록한다.
과거 공동묘지에서 낙인을 추출한 방문 기록("grave-extract")은 재사용 불가 상태로 인정하여 중복 획득을 막는다.
전투에서 영구 사망한 아군의 시체 기록은 삭제하지 않지만, 더 이상 공동묘지 보상의 재료가 아니며 낙인 카드가 새로 생성되지 않는다.
공동묘지 스토리/전투 이벤트는 이 변경의 대상이 아니다.

언덕: 전역 정찰 → 남아 있는 일반/희귀/보스 타일의 적 수·등급·군단 정보.
오염 단계별 원본 확률을 사용하며 초반 2바퀴에는 1마리, 이후 최소 2/최대 4마리.
정찰한 수와 해당 등급/군단의 마물 1종 이상을 실제 전투 편성에 보장한다.
정확한 종류는 전투 진입 시 결정하고 같은 편성에서 종 중복을 제거한다.
이미 처치한 타일은 제외한다. 정보는 재접속/재열기에 고정되고 맵 재구성 때 초기화된다.
처치한 뒤에는 목록/타일 표시에서 숨긴다. 미믹은 기존 상자 전용 편성을 따른다.
맵 마물 타일에 '정찰' 표시를 붙인다. 정보 화면은 다시 열어 확인할 수 있다.

집: 들어가기 → 순찰경로 → 현재 경로와 교체판 타일을 하나씩 눌러 교환 → 경로 확정.
현재 6칸: 길 2/공동묘지 1/언덕 1/숙영 1/사건 1.
교체판 5칸: 일반 마물 5. 전체 타일 종류/수 보존을 검증한다.
기본 경로 버튼은 초안만 되돌리고, 취소는 저장된 경로를 바꾸지 않는다.
방문당 한 번 확정. 확정 후 집 실내로 돌아가며 기존 계승 방문 제한과 독립이다.
현재 맵은 유지하고 집에서 나갈 때 다음 맵 배치에 타일 수 차이를 적용한다.
오염도 변환은 남아 있는 길 수만큼만 적용해 길이 음수가 되거나 선택에서 제거한 길이 되살아나지 않는다.
24칸, 점술가(0)/마을(8)/집(15), 오염 80 이상의 보스(23)를 유지한다.
순찰 계획은 원정 저장에 보관하고 새 원정 버튼으로 새 게임을 시작해도 이어 쓴다.
별도 브라우저 localStorage 파일은 만들지 않는다. 원정 저장 삭제 시에는 기본 경로로 돌아간다.

## 파일
신규 systems/route_plan.gd (+ .uid): 기본 경로/재고 검증/개수 차이.
신규 systems/exploration_actions.gd (+ .uid): 기도·추출·정찰·순찰 UI.
수정 run_session.gd: 판정/추출/정찰/순찰 저장, 정찰 전투 진입.
수정 map_state.gd: patrol_plan/scout/prayer_result 저장과 다음 맵 생성.
수정 encounter_generator.gd: 정찰 정보 생성 및 제약 편성.
수정 map.gd: 장소 화면, 집 순찰 버튼, 정찰 표시, 새 원정 계획 유지.
기존 이미지/폰트/주사위/중앙 전장 크기를 유지했다.

Trigger: 타일 열기/기도/시체 및 낙인 선택/정찰/타일 교환/경로 확정.
Information: 오염도/방문/시체/축복/처치 여부/단계/정찰/현재·예비 재고/저장 결과.
Interaction: ExplorationActions ↔ RunSession ↔ MapState/RoutePlan/EncounterGenerator, 기존 주사위.
Visual: 기존 장소 배경, 카드 목록, 주사위, 정찰 정보와 배지, 경로 타일 교환.
Memory: 판정·소모·카드·방문 제한, 맵별 정찰, 저장 순찰 계획. UI 초안은 런타임만 보유.

## 확인
실제 OpenGL 실행과 880개 조건을 확인했다.
기도 1~6·오염 하한·중복 방지·연출·재접속,
6개 오염 경계 × 32개 교환 조합의 24칸/고정 타일/개수 검증,
5개 오염 단계 × 3개 바퀴 × 30회의 정찰/적 편성 보장,
실제 전투 진입과 처치 정보 제거, 맵 재구성 초기화,
전투 사망→추출→시체 소모·축복 카드 저장,
모든 새 동작의 저장 실패 복구를 확인했다.
집 실내→순찰 확정→나가기→새 맵과 새 원정 계획 유지,
추출 카드→기존 집 계승도 별도로 확인했다.
화면 캡처로 카드/안내 간격을 확인했다.
확인용 스크립트는 게임에 넣지 않았고 실행 후 제거했다. 개인 원정 저장은 복원했다.
Godot import, 맵/독립 전장 시작, git diff --check를 통과했다.
모바일 실기기는 미확인이다. Git commit/push는 하지 않았다.
