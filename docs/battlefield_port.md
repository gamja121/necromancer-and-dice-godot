# 전장 이식 현황

기준 웹 버전: origin/main 8512949. 시작 장면: battlefield.tscn.

트리거: 주사위 클릭. 필요한 정보: 편성, 개체 능력치와 낙인, 전투 시작 군단, 라운드 상태. 전달: 상단 턴/주사위 안내, 체력 막대, 개별 행동 안내, 피해/회복 수치. 시각 변화: 원본 공격·피격·사망 프레임, 상태 색상, 사망 카드 감소. 지속 상태: 전장 시험은 세션 내 상태만 사용하며 원정 저장에 쓰지 않음.

battlefield_rules.gd는 기존 코어를 상속하여 준비와 행동을 분리한다. 최신 낙인 정규화/저주 차단을 반영한다. Godot 난수와 사전 동률 추첨을 사용하므로 같은 시드의 웹 결과와 동일하지 않다. 정확한 난수 및 전체 판정 대조는 남은 작업이다.

현재 시험 편성 10종. 원본 12종 중 히드라와 드라큘라의 런타임 프레임 변환은 미구현이다. 소환/치유/타격 시트와 전투 행동 강조는 남았다. 원본과 동일한 전장이 모두 완성되었다고 해석하지 않는다.

카드·정보 UI: 원본 CSS 1280×720 비율, 370/540 카드 비율, 슬롯별 기울기, 선택 카드 상승, 행동 중 카드 하강과 입력 잠금. 마물 정보와 효과 정보가 동시에 열리며 전용 프레임·초상화·시트에서 잘라낸 낙인 아이콘을 사용한다. 최신 원본에서 정보 명칭/설명 데이터를 직접 내보냈다. 효과창은 스크롤을 지원하고 등급·군단·현재 능력치·패시브·축복/저주 눈금·군단 억제·능력치 변화·씨앗 개화를 표시한다. 배경/닫기/ESC로 닫는다. 편성도 원본 보드, 역순 선택 슬롯, 겹친 손패로 구현했으며 네 장일 때만 확인 가능하다. 상단은 활성 군단만 원본 슬롯 프레임에 표시한다. 엔진별 글꼴·스크롤바·블러 렌더링의 작은 차이는 남는다.

트리거: 대기 중 마물 카드 클릭. 정보: 해당 개체의 현재 전투 상태. 전달: 좌측 요약과 우측 효과 설명. 시각 변화: 선택 상승·배경 블러·두 패널. 지속 상태: 정보 열기/닫기는 전투 상태나 저장을 변경하지 않는다.
