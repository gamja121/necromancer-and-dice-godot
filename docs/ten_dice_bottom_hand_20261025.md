# 주사위 카드 하단 손패와 보유 한도 10장

2026-10-25 사용자 요청: 마물 카드처럼 주사위 카드를 화면 아래에 오른쪽부터 왼쪽으로 펼치고, 보유 한도를 5장에서 10장으로 늘린다.

- 맵 오른쪽 덱 버튼과 전투 주사위 손패가 같은 하단 배치를 쓴다. 기존 마물 손패에 맞춘 136×218 크기, 최대 90px 간격으로 오른쪽 덱에서 왼쪽으로 순차 전개한다. 카드가 늘어도 다섯 번째 자리에 겹쳐 쌓이지 않는다.
- 호버/키보드 포커스에서 카드를 26px 올려 읽기 쉽게 한다. 실제 Control 입력 순서와 표시 순서를 함께 올리고 복원한다. 위로 드래그하여 사용, 짧은 드래그 취소, 바깥/닫기/ESC 종료 및 카드 사용 효과음을 유지한다.
- 공유 DICE_CAPACITY=10으로 상점·사건·묘지 지급 및 초과 보상 판정을 통일한다. 맵/전투 숫자와 안내 및 영문 문자열도 상수를 따른다. 마물 편성/보관 규칙은 변경하지 않는다.
- 기존 5장 overflow 저장은 빈칸 수령/포기를 제공한다. 오래된 호출이 기존 카드 ID를 전달해도 그 카드를 버리지 않고 새 카드를 추가한다. 임의 ID는 거부한다. 수령/포기는 저장 실패 시 원자적으로 되돌리며, 포기 저장 실패 후 수령 버튼은 실제 수령으로 재시도한다.
- 저장 형식 변경이나 기존 카드 삭제, 무료 카드 지급은 없다.

## 규칙 검토

Trigger: 덱 버튼·전투 카드창, 카드 획득 시 기존 진입점. Information: 실제 보유 목록·ID, 사용 조건, 화면 높이와 공통 상수. Interaction: 하단 선택/드래그/취소, 가득 찼을 때 교체/포기. Visual: 오른쪽에서 왼쪽 하단 펼침과 올리기. State: 기존 카드 배열과 보상 영수증만 사용하고 기존 저장/실패 rollback을 유지한다.

## 검증

헤드리스 import, 0/1/5/10장 맵·전투·530px 손패, 7번째 네이티브 포인터 선택 및 10번째 드래그, 펼치는 도중 닫기, 실제 맵 덱 버튼 연결을 확인한다. 10번째 지급/11번째 교체, 10장 재시작, 기존 5장 보상 수령·포기·잘못된 ID·저장 실패 재시도를 독립 임시 저장으로 검사한다. 관련 묘지·일반 사건·초과 보상/마물 편성·효과음·영문 UI 회귀도 실행한다. 사용자가 직접 실행하기로 한 상태를 유지하며 GUI 게임 창은 열지 않는다. 헤드리스 검증은 사용자 화면에서의 시각 확인을 대체하지 않는다.

결과: import 오류 0. 손패/정보창 191, 한도·기존 저장·실제 맵 연결 23, 묘지 230, 일반 사건 240, 교체/마물 편성 92, 효과음 26, 언어 88 항목 통과(실패 0). 실제 게임 창을 열어 시각 확인한 결과로 기록하지 않는다.
