# 오염도 HUD — 최종 적용 상태 (2026-10-13)

## 실제 반영 원화와 좌표

- 최종 선택한 원화: `까마귀와_해골_장식_오염_게이지.png` (2172×724 RGBA). 이전 임시 디자인이나 생성한 보드 목업을 실제 UI와 혼동하지 않는다.
- 게임에 **실제 등록된 파일**: `assets/map/ui/contamination_crow_tile_10.webp` (1152×384, alpha 보존). 원본 구형 `contamination_hud.png`는 안전한 fallback/보존용으로 남긴다.
- 렌더링 코드: `systems/contamination_hud.gd`와 `systems/map_presentation.gd`; 메인 보드의 스테이지 좌표계(1280×720)에서 크기 **480×160**, 위치 **(400,395)**. 기존 576×192보다 작고 중앙 정렬이다.
- 사용자 요청에 따라 왼쪽 석판의 유일한 글자는 **「오염도」**(31px)이다. 이전 `12 / 100` 등 **하단 수치와 단계별 텍스트는 표시하지 않는다**. 수치 데이터 자체는 그대로 0~100이며 시각적으로 10칸에만 반영.
- 10개의 실제 알파 구멍에 각각 10점씩 표시. 12점에서는 1칸 전체 + 다음 칸 20%로 채워짐. 원화의 프레임과 돌 장식은 동적 색 위에 놓이며 원화를 변형하지 않는다.
- 장소/사건 모달이 뜰 때 오염도 UI는 숨긴다. 카드 손패/책 UI는 기존 계약대로 유지한다. 입력 이벤트를 가로채지 않는다(`MOUSE_FILTER_IGNORE`).

## 게임 기본 원칙 5가지

1. **Trigger:** `world.contamination` 갱신 시 `MapPresentation.refresh`가 화면 수치에 적용하고, 맵 주사위가 실제로 굴러 오염도 석판 테두리에 닿을 때 반사 처리.
2. **Information:** 저장된 오염도 0~100, 10칸 진행도, 실측한 원화의 알파 구멍 위치, 현재 HUD 표시 여부, 주사위 이동 중심·반지름·속도.
3. **Interaction:** HUD 자체에는 클릭/게임플레이 기능을 부여하지 않는다. 공통 맵 주사위의 **시각적 애니메이션**만 석판을 벽처럼 인식하여 튕긴다.
4. **Visual:** 크기 480×160, 큰 「오염도」 한 줄, 아래 숫자 제거. 주사위가 실제로 굴러가는 동안 왼쪽/오른쪽/위/아래에서 튕기는 것처럼 보이되 주사위에 닿지 않는 투명 까마귀 위쪽 영역은 벽이 아니다.
5. **Persistence:** HUD/주사위 반사 자체는 게임 난수·주사위 눈금·마물·오염도 저장값에 영향을 주지 않는다. 이동 위치를 저장하는 공유 주사위 변경 PR #123에서도 `roll_shared_die`가 동일한 `dice_wall_rect()`를 전달하도록 확인됨(아직 별도 PR이므로 향후 병합 시 회귀 확인 필요).

## 2026-10-13 추가 변경: 자연스러운 색상 변화와 바퀴당 오염도 +7

- 채워진 10칸 게이지의 색상은 **전체 길이를 따라 초록 → 연두 → 노랑 → 주황 → 붉은색 → 보라색**으로 연속 보간한다. 칸마다 단색으로 갑자기 바뀌지 않도록 폭 1.5px 이하의 좁은 띠를 그린다. 기존 색상 앵커, 투명 구멍, 까마귀·해골·석판 원화 및 그 위에 그려지는 테두리는 보존한다.
- 수치 증가 애니메이션은 기존 0.28초 보간을 유지한다. 각 칸은 10점이며, 7점은 첫 칸 70%, 14점은 첫 칸 전체와 둘째 칸 40%, 21점은 셋째 칸 10%만큼 표시한다.
- 집을 떠나 새 바퀴를 시작할 때에만 오염도 증가량을 **기존 코드 +4에서 +7로 변경**했다. 요청 당시의 사용 체감 +5와 구현 상수 +4가 다르므로 실제 게임 상태를 기준으로 통일한다. 100 상한·보스 임계치 20·세이브 포맷·전투 승리 -1·기도 등 다른 변화는 유지한다.
- 기본원칙 5항: Trigger=완주 후 집 나가기 및 수치 변화; Information=저장된 0~100 값과 구간별 비율; Interaction=기존 집 나가기/주사위 액션 그대로; Visual=고정된 석재 장식 아래 부드러운 가로 그라데이션; Persistence=누적 +7만 기존 contamination에 저장, 그라데이션은 표현만.
