- 선택된 사용자 원화: `까마귀와_해골_장식_오염_게이지.png` (2172×724 RGBA). 이전 시안과 인게임 목업 중 사용자가 최종 지정한 디자인.
- 실제 게임 에셋: `assets/map/ui/contamination_crow_tile_10.webp` (1152×384, 투명 WebP). 화면 표시 576×192 대비 2배 폭; 가벼운 별도 파일, 리포지토리에 실제 바이너리 보관.
- 옛 `assets/map/ui/contamination_hud.png` 파일은 삭제하지 않고 복구용으로 보존. 기존 미병합 PR #112의 다른 시안과 혼동하지 않도록 경로 분리.

## 게임 기본원칙 5가지
1. **Trigger:** 실제 저장된 `world.contamination`이 변경될 때 MapPresentation.refresh에서 해당 HUD로 반영.
2. **Information:** 0~100 오염도, `오염도`와 `현재/100` 동적 글자; 10칸이 각각 10점.
3. **Interaction:** HUD 자체는 클릭할 수 없음. 기존 맵/인벤토리/이벤트 입력 영향 없음.
4. **Visual:** 까마귀와 왼쪽 글자용 양피지 석판, 실측한 10개 투명 창, 오른쪽 해골 끝장식. 12점은 첫 칸 완전 채움 + 둘째 칸 20%로 애니메이션, 각 칸 배경은 어둡게. 프레임은 채움 위에 합성.
5. **Persistence:** 수치 및 애니메이션은 화면 전용 상태. 스토리, 주사위 RNG, 마물, 저장 파일, 게임플레이는 변경 없음.

## 점검
- Godot 4.7.2 실제 파일 디코딩/투명도/10슬롯별 보간/0·12·100 검사.
- 새 에셋을 사용하는 실제 24칸 지도 로드, 장소/스토리 팝업 시 HUD 숨김, 저장 상태 불변 확인.
- Windows 그래픽 렌더링 0·12·100 스크린샷과 기존 장소/맵 이동 회귀 검사.
- 화면 미술의 주관적 최종 승인이나 사용자의 로컬 Windows PC 동기화는 CI 결과에 포함하지 않음.
