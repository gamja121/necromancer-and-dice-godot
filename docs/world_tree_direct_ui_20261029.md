# 세계수 기도 화면 통일

사용자 승인: 제단은 기존대로 유지하고, 세계수는 검토한 공통 배치를 적용한다.

- 일반 세계수 도착 시 바로 기존 공유 주사위로 기도하는 화면을 연다. 기존 이야기 우선순위는 그대로다.
- 제목을 제거하고 기존 공통 하단 양피지의 본문/상세 줄을 사용한다. 원화 크기나 양피지 크기를 줄이지 않는다.
- 맵 나가기는 공통 하단 위치 한 개만 둔다. 같은 주사위의 위치·크기·회전·굴림을 유지하며 별도 기도 버튼은 만들지 않는다.
- 기존 `purify` 영수증과 `{visit,face,delta}`를 읽어 완료 결과를 표시한다. 열기/재접속은 재추첨하지 않는다.
- 기도 규칙(1~3:+1, 4~5:-3, 6:-5), RNG, 0~100 제한, 저장 형식, 축복/실패 소리와 원본 숫자 효과, 보스/늪지 후처리는 변경하지 않는다.
- 숫자 효과 파일 `systems/world_tree_prayer_effect.gd`는 기존 blob `dd271bb89f6e314abe21d20ecd4cc5db68953ce3` 그대로다. 숙영 회복 파일 `systems/map_presentation.gd`도 기존 blob `345e34ba9515f0d8da8ad3fac89bc31e798f79ca` 그대로다.
- 직접 기도 화면에는 옛 진입 종이가 없으므로 사용 후 가상의 종이 낙하를 대기시키지 않는다. NEW 안내는 실제 기도가 저장된 뒤 확인하며, 실패하면 재시도가 가능하다.
- 다른 화면으로 바뀌거나 삭제 중인 주인은 입력·비동기 결과 갱신을 하지 않는다. 사용한 주사위는 공통 나가기를 가리지 않는다.

검증: `test_world_tree_direct_flow.gd`, 기존 세계수 공유 주사위·장소 배치·맵 이동·종이 회귀, `test_world_tree_direct_capture.gd`의 실제 준비/원본 효과/완료/재열기 캡처. 모든 실행은 별도 임시 저장 데이터를 사용한다.
