# 아군 영구사망 연출과 오디오 출력

트리거: 전투 계산을 마친 스냅샷에서 alive가 true에서 false로 바뀐 아군 본체. 불사는 damage()에서 먼저 처리되므로 살아남은 개체에는 재생하지 않는다. 공격·반격·중독 선행 피해·라운드 준비의 저주 피해에 모두 같은 판정을 사용한다.

연출: 0.10초 정지, 주변 암전, 사망한 개체의 원본 사망 모션 강조, 영혼 상승과 재 입자, 본체와 카드의 소멸, 전용 합성 사망음. 동시 사망은 한 암전에서 함께 재생한다. 적은 원본 사망 모션으로 짧게 처리하고, 소환체는 영구사망 강조 없이 제거한다. 배속과 일시정지를 따른다.

정보: 마물 이름과 영구사망 표시. 죽은 본체와 카드는 이후 render_units와 라운드 카드 이동에서 다시 표시하지 않는다. 사라진 개체의 바닥 그림자도 제거한다.

지속 상태: 전투 수치, RNG, 부활/불사 및 원정 저장 규칙은 변경하지 않는다. 기존 finish_encounter가 죽은 보유 개체를 제거한다. 독립 전장은 새 전투에서 초기화된다. 연출 상태는 저장하지 않는다.

오디오 조사: Windows 출력 및 게임 세션은 음소거가 아니었지만 기본 출력이 RAC27F/NVIDIA 모니터였다. Realtek 아날로그 스피커는 연결되지 않음 상태였다. 사용자 확인에 따라 게임만 스피커(NOX Bastar-X)로 지정했고 실제 WASAPI 요청/활성 장치 로그에서 적용을 확인했다. Windows 전체 출력은 변경하지 않았다.

전장 오른쪽 위 오디오 버튼에 장치 선택과 음량 설정을 추가했다. 설정은 user://audio_settings.cfg로 원정 저장과 독립적으로 유지된다. 새 환경에서는 시스템 기본 출력이 기본값이다. 기존 캡처의 강제 무음을 제거해 녹화에도 전투 소리가 들어가도록 했다. 정상 실행은 이미 소리를 재생하고 있었으며 이번 문제는 출력 장치 경로였다.

검증: Godot import 및 전장 실행 확인. 실제 렌더러로 4라운드를 진행하고 역병술사·해골 병사의 사망 강조, 소멸 중간 프레임과 이후 카드 소실을 확인했다. 영상 PCM 신호도 확인했다. 초기 녹화 종료 시 오디오 리소스 경고는 종료 전에 스트림을 정리해 해결했으며 최종 녹화에 경고나 스크립트/셰이더 오류가 없었다. 연속 캡처를 위한 임시 반복은 즉시 복원했다. 새 테스트 코드/파일/버튼은 추가하지 않았다.

permanent_death.wav는 이번 작업에서 직접 합성한 저음 하강과 공기·종소리이며 기존 적 사망음과 구분된다.
