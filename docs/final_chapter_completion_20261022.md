# 최종 드래곤 마무리 — 2026-10-22~23

추적: [진단 #271](https://github.com/gamja121/necromancer-and-dice-godot/issues/271), [구현 #272](https://github.com/gamja121/necromancer-and-dice-godot/issues/272).

사용자는 전체 진행 진단 후 기존 스타일에 맞춰 단계별 검증과 수정을 승인했다. 이번 범위는 **현재 최종 보스 경로의 종료·연출 연결**이다. 작업 도중 공개 main `b002c1d`에 추가된 오염도 20/40/60 중간 보스는 해당 구현을 보존해 통합했다. 중간 보스 선정·등장 규칙을 새로 정하지 않았으며, 공유 소스의 최종 오염도 80 + 마지막 추적 장면 확인 조건도 변경하지 않았다.

## 플레이 흐름

1. 실제 최종 드래곤 타일에 도착하면 보존된 책 속 등장 연출을 재생한다. 중간 보스는 기존 일반 편성을 연다. 다른 위치에서 보스 타일을 누르면 도착 안내만 표시한다.
2. 자연 종료 또는 건너뛰기 뒤 글자 선택지 `전투 편성으로`를 누른다. 삼각형과 잉크색으로 마우스/키보드 선택을 표시한다.
3. 연출 확인 저장에 성공해야 기존 편성을 연다. 연출은 RNG·적 생성·전투 결과를 만들지 않는다.
4. 최종 드래곤 승리와 동일한 저장에서 최종 퀘스트 완료, 영구 처치, 종료 기록과 마지막 영혼 수확을 보관한다.
5. 기존 영혼 수확 성공/실패/초과 보관함 교환 처리가 끝나면 아군 카드가 책으로 돌아가고 두 페이지의 엔딩을 표시한다.
6. `책을 덮고 타이틀로`를 누른 뒤 이어하기를 선택하면 같은 클리어 기록이 열린다. 새 원정은 기존 타이틀의 명시적인 새 원정 동작으로 시작한다.

## 저장과 복원

- v1 저장 형식을 유지하며 기존 `event_flags`와 `run_result`를 확장한다.
- `quest:monster_king_final_battle:active=false`, `quest:monster_king_final_battle:complete=true`, `story:final_dragon:defeated=true`.
- 종료 사유 `final_dragon_defeated`와 실제 encounter ID/바퀴/오염도/처치/손실/생존 기록을 저장한다.
- 보스 적으로 표시된 단일 드래곤의 실제 아군 승리만 클리어로 처리한다. 일반 전투 승리나 드래곤 패배는 기존 경로를 따른다.
- 수확이 남았으면 이어하기에서 수확을 먼저 복원한다. 수확 완료 후에는 엔딩만 복원한다. 저장 실패는 RNG·보유 마물·영구 손실·전투·보상을 함께 되돌려 재시도할 수 있다.
- 과거 v1 저장의 23번 타일 정리 기록만으로 클리어를 추정하지 않는다. 기존 저장에는 확실한 최종 승리 기록이 없으므로 임의로 완료시키지 않는다.
- 최종 퀘스트 완료 뒤에도 기존 전이문/왕 추적 사건은 역사적으로 완료 상태를 유지한다.
- 종료한 원정의 이동·장소 행동·새 전투를 막는다. 보드 생성 경로를 직접 호출해도 영구 처치 플래그가 보스 재생성을 막는다.

## 시각과 자산

- 사건용 `final_dragon_presentation.gd`와 28개 프레임은 그대로 재사용한다. 기존 사건용 소스·원화 등 보존 대상 32개 SHA-256이 일치한다.
- 전투용 공격/피격/부패 사망 모션도 변경하지 않았다.
- 엔딩은 기존 원화·배경·한글 폰트에 코드로 종이 질감, 접힌 책등, 잉크 인장, 작은 먼지와 원화 드러남을 추가했다. 새 이미지 생성이나 외부 원화 다운로드는 사용하지 않았다.
- 공유 주사위는 하나다. 실제 드래곤 렌더링 좌표/크기를 지도 좌표로 변환해 전체 동작 캔버스를 피한다. 진입 시 겹친 정지 위치만 이동하며 기존 면·각도·게임 RNG를 보존한다. 굴림 충돌과 정지 위치에도 같은 영역을 적용한다.

## 추가 회귀 검사와 화면 전환 정리

공개 회귀 검사에서 오래된 UI·보스 검사 전제를 바로잡고, 통합 시점의 최신 단계 보스 규칙에 맞춰 다시 검증했다. 첫 지도에는 언덕이 없고, 순찰 편집은 `+/-` 대신 실제 여섯 칸·종류 선택 버튼을 사용한다. 중간 보스는 해당 20/40/60 단계, 최종 드래곤은 완료 이야기 fixture와 현행 최종 게이트를 함께 준비한다. 이 수정은 게임의 등장 수치·타일 규칙·UI를 변경하지 않는다. 이전 main의 MapState로도 순찰 검사의 동일한 9개 실패가 재현됨을 확인했다.

연속으로 두 지도를 닫을 때 자산 정리 신호가 충돌하는 실제 오류도 수정했다. 종료한 화면을 붙잡지 않는 별도 정리 객체가 완료된 요청을 프레임당 하나씩 회수한다. 같은 미완료 경로를 가진 두 화면을 동시에 종료하는 회귀 검사를 추가했다.

최종 화면 전환 수정 및 최신 보스 통합 뒤 Windows 네이티브 UI 74/0을 통과했다. 단계별 1회 처치·추첨·복원 74/0, 보스 후보의 일반 출현 제외 및 목록 호환 666/0도 통과했다. CI는 숫자가 들어간 `P4_...` 성공 결과도 인식하도록 고쳤고, 실제 자산 가져오기가 110초 제한에 걸린 수확 검사에는 다른 검사와 같은 200초 한도를 적용했다. 오류/실패 판정은 유지한다.

공유 main `0d5e52b`의 미사용 낙인 개수별 카드 테두리 제거도 보존해 통합했다. 이 통합본에서 Windows 네이티브 74/0 및 화면 증거를 다시 확인했다. 단계 보스 전용화 이전 명단을 가정하던 광신도/전이문 검사 fixture를 현행 일반 적 명단으로 수정했다. 광신도 전투 153/0, 후속 195/0, 전이문 6종 160/152/178/180/188/235 모두 실패 0, 최종 추적 5종 195/201/165/157/155 모두 실패 0이다. 카드 배치 75/0과 실제 카드 화면 76/0도 통과했다. 카드 화면 검사는 효과음을 재생한 직후 엔진을 종료해 남기던 자원을, 효과음 정지·오디오 처리 대기·장면 해제 후 종료하도록 정리해 경고 없이 통과했다. 게임의 효과음 재생이나 규칙은 변경하지 않았다.

**검증 범위:** 실제 게임 장면·버튼 신호·저장·전투·수확을 사용했다. 이야기 검증에는 경로/오염도 fixture가 있고, 마지막 전투는 아군 공격/속도만 높여 종료 흐름을 검사했다. 보정 없는 난이도의 새 게임 1회 완주나 물리 마우스/실기 휴대전화 조작까지 확인했다는 뜻은 아니다. 전체 미이식 기능이나 난이도 조정 완료를 주장하지 않는다. 중간 보스는 별도 공개 작업을 보존해 통합한 범위다.
