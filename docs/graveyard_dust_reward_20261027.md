# 공동묘지 흙 발굴·보관 연출 — 2026-10-27

승인된 v4 시안을 기존 공동묘지 기능에 적용한다. 카드 원화는 바꾸지 않는다. 처음에는 앞면 전체를 불투명한 흙으로 가리고, 상승·정지·두 번의 짧은 털기 뒤 원래 녹색 카드가 드러난다. 뒤집기나 뒷면은 사용하지 않는다.

- Trigger: 실제 공동묘지의 발굴 버튼을 한 번 누른다. 기존 이야기 우선순위는 유지한다.
- Information: 기존 `dig_graveyard`가 저장한 실제 카드만 보여 준다. 처음에는 종류를 알 수 없고, 약 2.16초 뒤 확인할 수 있다.
- Interaction: 공개 중 중복 입력·나가기를 잠근다. ‘챙기고 나가기’로 보관함에 전달한다. 보유 한도 10장에서의 교체·포기는 기존 저장 API로 먼저 완료한다.
- Visual: 예언자의 막사 원본 창 (340,423,600,150)·글자 배치를 공용 도우미로 공유한다. 버튼은 map의 공통 action/exit RECT와 variant04를 재사용한다. 임의 축소를 하지 않는다. 전달 시 오른쪽 보관함이 열리고 닫히며 정상 획득은 +1, 교체는 교체 완료를 표시한다.
- Memory: 추첨, 방문당 영수증, 보유 한도, 저장 형식, 카드 효과와 이야기 분기는 변경하지 않는다. 정상 발굴은 기존처럼 공개 전에 이미 저장된다. 보관함이 가득 찬 미완료 발굴은 저장된 같은 카드를 바로 확인·교체할 수 있게 복구하며 다시 추첨하지 않는다.

화면 종료는 연출을 취소하고 임시 노드를 정리하며 저장된 결과를 되돌리지 않는다. 원래 예언 창도 같은 공용 팩터리를 사용하므로 크기·위치·색·글자가 유지된다.

검증은 관련 저장/오버플로/한 번 제한 검사, 다중 입력·취소·공용 배치 검사와 실제 GPU 화면으로 수행한다. 작업 이력 #331.
