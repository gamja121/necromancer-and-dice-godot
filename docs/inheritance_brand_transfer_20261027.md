# 계승 낙인 이동 연출 — 2026-10-27

사용자가 승인한 실제 Godot 시안을 본편 `home_inheritance.gd`에 연결한다. 추출 → 이동 → 각인, 총 1.24초. 짙은 선과 옅은 청록/상아색 잔광으로 제단의 붉은 불꽃 시안과 구분한다. 카드·낙인 원화는 기존 것을 사용한다.

- Trigger: 기존 `RunSession.inherit_at_home()`의 저장 성공 후에만 시작.
- Information: 저장된 실제 `result.brand`와 강화 후 카드 `result.receiver`를 사용한다. 원본 후보에 같은 축복 필터를 적용해 출발 문양을 찾으며, 동일 종류의 호환 문양이 여러 개면 첫 동일 문양을 기준으로 삼는다. 별도 추첨은 없다.
- Interaction: 기존 busy 잠금으로 재클릭·닫기를 막고, 저장 실패 시 연출하지 않는다.
- Visual: 재료의 모든 레이어와 손패가 흐려지고 낙인 문양 하나가 중앙 정보창 위를 지난다. 0.88초에 실제 새 낙인 칸이 드러나며 `book_stamp`는 이때 한 번 재생한다.
- Memory: 계승 규칙·축복/저주·RNG·영구 소멸·방문 영수증·저장 형식 변경 없음. 연출 중 종료되어도 이미 저장된 결과를 되돌리지 않는다.

출발과 도착은 효과 자신의 canvas 좌표계로 변환한다. 숨겨진 동일 카드 미리보기에서 추가된 마지막 실제 아이콘 위치를 구하므로 기존 1/2칸과 동일 종류 중복에서도 맞는 새 칸으로 이동한다. 지원되지 않거나 없는 문양 노드는 카드 중앙으로 대체한다. 효과와 임시 미리보기는 완료/장면 종료 시 정리한다.

구현: `systems/inheritance_sacrifice_effect.gd`, `systems/home_inheritance.gd`.
검증: 기존 저장 실패/완료/재접속 검사와 새 다중 후보·필터·세 번째 칸·정리 검사, 실제 Godot GUI 확인. 작업 이력: #327. 완료 증거는 해당 Issue/PR 체크포인트에 기록한다.
