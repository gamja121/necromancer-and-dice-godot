- 새 시트에 없는 기존 4번째 녹아내리는 몸 자세는 이전 파일을 로컬 업스케일하여 유지했다. 이 프레임은 다른 새 프레임보다 부드럽다.

## 처리
- 공식 Real-ESRGAN NCNN Vulkan v0.2.0 + realesrgan-x4plus 모델, GTX 1660 Ti 로컬 실행.
- RGB 4배 추론 후 원본 질감 30%와 혼합; 최종 실제 필요 해상도로 축소.
- 원본 알파를 별도로 리샘플링. 프레임 번호와 강한 마젠타 키 잔여물 제거.
- 기본 자세 몸 높이 약 640px. 모션마다 기본 자세 기준 공통 스케일을 적용하며 프레임별 배율 변경은 하지 않는다.
- 모든 런타임 프레임 1152×768 RGBA, 중심 정렬 및 공통 지면 y=744. 긴 공격/사망 자세를 자르지 않는다.
- 공격 약 2.452배 / 피격 약 2.520배 / 사망 약 3.636배. 새 시트의 행별 기본 몸 크기 차이를 보정한다.
- 18 PNG 합계 8,779,086 bytes (약 8.37 MiB). 이것은 디스크 파일 크기이며 GPU 텍스처 메모리와는 다르다.
