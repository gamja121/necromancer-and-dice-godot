## 근거와 범위

전투 PNG 552개와 실제 사용하는 눈 숲 배경은 웹 참조 사본과 바이트가 동일했다.
텍스처 import 752개는 모두 compress/mode=0(무손실), process/size_limit=0이며 이식 과정의 해상도 축소 제한은 없다.
37종 PNG 마물의 첫 프레임을 표로 점검했다. SVG 및 다른 모션/장면은 이 표에 포함하지 않았다.
표의 위험도는 원본 몸 픽셀 대비 예상 표시 배율을 기준으로 HIGH >=2배, WATCH >1.25배로 임시 분류했다. 실제 화질 점수가 아니다. 표시 배율에는 현재 Godot의 마물별 크기 비율을 사용했다.

## 화면 확인

1920×1080에서 같은 편성의 변경 전/후 화면을 캡처하여 크기 증가를 확인했다.
1600×900 실제 OpenGL 렌더러로 315프레임, 약 10.5초의 전투 한 라운드를 녹화했다. 스크립트/셰이더/실행 오류가 없었다.
기본 편성은 해골 병사·거미 기사·역병술사·세이렌, 적은 고블린 라이더·오크·오우거·미노타우르이다.
큰 마물의 서로 겹치는 정도도 증가하므로 최종 크기를 정할 때 편성별 배치를 함께 확인한다.
모든 마물/정보창/모바일 화면의 확인을 완료한 것은 아니다. 새 테스트 파일이나 버튼은 추가하지 않았다.
