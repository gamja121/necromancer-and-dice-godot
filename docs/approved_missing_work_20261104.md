## 제단 규칙

1. 실제 제단 방문에서 제물을 선택하고 바친다. 카드 영구 소멸과 무작위 결과가 같은 저장에 기록된다.
2. 제물이 타는1.22초의 승인된 불꽃 연출 후 축복이 공개된다.
3. 공개 결과를 보고 강화할 마물을 고른다. 실제 적용에서 강화1회와 방문 영수증을 저장한다.
4. 보류·창 닫기·재시작 시 저장된 같은 결과로 복귀한다. 다시 추첨하거나 제물을 중복 소모하지 않는다.
5. 강화 한도는 기존 마물당3회. 제물을 뺀 유효 대상이 없으면 바칠 수 없다. 저장 실패는 해당 거래의 상태와 RNG를 복구한다. 기존 저장의 고정 강화 결과는 유지된다.
