# 드래곤 실전용 모션 — 2026-10-22

추적: [Issue #266](https://github.com/gamja121/necromancer-and-dice-godot/issues/266)

## 사용자 요청과 보존 범위

사용자: 공격은 머리를 크게 내밀며 입을 벌렸다 다문다. 피격은 머리가 옆으로 젖혀진다. 사망은 점차 부패한다. **이 변경은 전투용이며 기존 사건용 연출은 남긴다.**

책 페이지 컴포넌트, 이전 렌더러/미리보기, 원화 PNG 및 `assets/battle/frames/final-dragon/`의 28장 등 32개 파일을 작업 전 SHA-256과 대조해 보존했다. 새 전투 자산은 `assets/battle/frames/dragon/`에 별도로 둔다. 사건 진입·보스 발생 조건·능력치·불사귀·영입·보상·저장 형식은 변경하지 않는다.

## 결과

- **공격 16장:** 머리 후퇴/입 열기 → 크게 전진 → 아래턱을 닫는 9번째 프레임에서 기존 전투의 타격 표시 → 원래 자세. 전진 끝의 실루엣은 중립보다 약 169px 더 앞으로 나온다(1024px 프레임 기준).
- **피격 8장:** 목과 머리를 최대 38도 뒤로 젖히고 반동을 거쳐 원래 그림으로 돌아온다.
- **사망 20장:** 부패 색과 얼룩 → 날개/몸에 구멍이 확산 → 몸이 낮아짐 → 바닥 잔해. 단순 전체 알파 페이드가 아니다. 총 기본 재생 시간 약 3.2초.
- 원본 PNG에서 아래턱을 마스크로 분리하고 머리/목과 다른 관절로 회전시킨다. 기존 Godot 네이티브 메시 리그를 새로 분리한 작업이며 추가 이미지 생성/API 호출은 사용하지 않았다.
- 원화가 한 시점인 2D이므로 새로운 뒷면을 그리는 3D 회전은 아니다. 고개가 화면 평면에서 크게 젖혀지며, 턱은 독립 회전한다.
- 모든 PNG는 1024×640. 44장 파일 합계 17,592,439바이트(약 16.8 MiB). 전부 디코딩해 보관할 경우 프레임만 110 MiB이며, 기존 전투의 32 MiB 선행 로딩 예산을 전체 런타임 메모리 상한으로 오해하지 않는다.
- 부패·관절 변형은 제작 때 PNG로 굽는다. 실제 전투에서 고밀도 메시/부패 셰이더를 매 프레임 계산하지 않는다.
- 기존 `dragon` slug가 별도 프레임/타이밍 프로필을 사용한다. 실제 `BattleVisuals.play_strike`, 피격 큐, `PermanentDeath.play`에서 재생한다.
- 보스 적은 화면에 맞는 별도 거대 배치를 사용한다. 1280×720과 1280×530 전장 및 960×540, 1920×1080에서 모든 프레임의 가시 영역이 들어오는지 검사한다. 카드/체력바는 단일 적 슬롯이다.
- 기존 별도 카드/정보 초상이 없던 드래곤은 새 중립 전투 그림을 기존 양피지 카드/정보 UI에 재사용한다. 기존 47종 원화/카드는 불변.

## PC에서 확인

```powershell
& '<Godot 실행 파일>' --path '<프로젝트 폴더>' --script res://scripts/render_final_dragon_battle_preview.gd
```

실제 battlefield 장면에 아군 4마리와 드래곤 1마리를 편성한 독립 확인 창이다. 공격·피격·부패 사망·다시 세우기·일시정지·0.5/1/2배속 버튼을 사용한다. 개인 지도/사건을 시작하거나 저장하지 않는다. 같은 프로세스에 이미 개인 RunSession이 활성화되었으면 재설정을 거부한다.

재생 버튼은 애니메이션 확인용 보고서를 만들며 실제 게임 피해/보상이나 보스 발생 조건을 실행하지 않는다. 프레임 재생은 실제 전투 코드와 동일하다. 기존 사건용 창은 `render_final_dragon_preview.gd`로 계속 별도 실행한다.

프레임 재제작(편집용 네이티브 도구, 내보낸 게임용 기능 아님):

```powershell
& '<Godot 실행 파일>' --path '<프로젝트 폴더>' --script res://scripts/render_final_dragon_battle_frames.gd
& '<Godot 실행 파일>' --headless --path '<프로젝트 폴더>' --editor --quit
```

## 검증

- `test_final_dragon_battle_motion.gd`: 127 통과, 0 실패. 실물 44장 해독·여백, 실제 전장 경로, 큰 머리 이동/턱 닫기, 피격 반동, 구멍/잔해, 화면 비율, 공격/피격/사망 정지와 재생, 배속 유지, 카드/초상 해독, 개인 저장 바이트 보존.
- Windows Compatibility/ANGLE에서 실제 장면으로 신규 모션 검사와 키 포즈 캡처를 수행했다. 성능/모바일 실기기 승인으로 확대 해석하지 않는다.
- 기존 사건 연출 139/0, 기존 대기 17/0, 기존 전투 모션 31/0, 전투 진형 73/0, 카드 검사 0 실패.
- 기존 47종 전체 실제 공격·피격·사망 표시 912/0. 기존 커버리지를 줄이지 않고 별도의 드래곤 검사를 추가했다.
- 첫 CI는 신규 전투/기존 사건 검사를 통과했으나 두 기존 fixture가 실패했다. animation-release의 고정43 수치는 원래43종과 별도 드래곤으로 구분하고, 정보창 close 검사는 기존0.14초 닫힘 애니메이션 완료를 최대1.3초 기다리도록 정정한다. 게임 UI/규칙을 검사에 맞춰 바꾸지 않는다.
- CI/PR 통합과 PC 동일 SHA는 완료 확인 뒤 Issue의 최종 체크포인트로 기록한다. 이 문서의 로컬 검사 성공만으로 원격 통합을 완료라고 주장하지 않는다.

## 5원칙

Trigger: 기존 전투의 공격·피격·사망 재생 시점.
Information: 기존 slug/team/slot, 프레임 번호와 전투 결과 보고서.
Interaction: 실전 주사위/전투 입력 불변, 독립 확인 창만 새 조작부.
Visual: 드래곤 전투 그림·타이밍·거대 배치·그림 재사용.
State: 새 게임 상태·저장·RNG 호출 없음. 기존 보스 스탯과 등장 조건도 불변.
