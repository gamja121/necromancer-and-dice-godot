# 보드 맵 이식

원본 기준: 8512949의 v2-map-practice.js/css와 art/v2-style/map-test.

24개 타일의 원본 둘레 좌표, 타입 개수, 집(15)·마을(8)·점술가(0) 고정 배치를 적용. 기본 지역 배경과 원본 타일·주인공 사용. 오염도 80 이상은 23번 보스 배치. 주사위로 둘레를 이동하며 집에 도착하면 이동 종료. 완주 후 집에서 나갈 때 오염도 +4 및 맵 재구성. 워프는 다른 워프로 이동. 늪지는 보유 마물 HP -1, HP 1 보호. 숙영은 전체 HP 회복.

마물 타일에서 현재 보유 마물로 기존 전장 진입. 승패 뒤 살아남은 마물 HP/사망과 처치 타일을 반영하고 맵 복귀. 초기 보유는 해골 병사·궁수. 원정 맵/보유 개체/HP/처치/좌표/난수 상태를 user://map_run_v1.json에 저장. 기존 시험 원정 저장은 별도 유지.

트리거: 주사위 이동 또는 타일 선택. 정보: 타일 타입/현재 위치/보유 마물/처치 여부. 전달: 선택 표시·툴팁·이동 안내·조우창. 시각 변화: 주인공 이동·주사위·처치 타일. 지속 상태: 맵 배치, 위치, 오염도, 현재 HP, 사망, 처치 상태.

사용자 요청에 따라 테스트 버튼·테스트 패널·디버그 기능을 추가하지 않는다. 새 테스트 코드도 추가하지 않는다. 원본의 테스트용 지역 전환·재배치·오염도 조작·디버그 편집은 플레이 UI에 노출하지 않는다.

범위: 보드/타일 구성과 이동·전장 연결. 마을 상점·점술·제단은 2026-10-08에 이식했다 (place_actions_port.md). 세계수/공동묘지/정찰/순찰은 2026-10-08에 이식했다 (exploration_actions_port.md). 사건별 원본 대화는 아직 이식 전이다. 집의 회복·계승과 낙인 카드 적용은 2026-10-08에 이식했다 (home_inheritance_port.md). 주사위 제어 카드 사용과 중단된 이동/전투 복원은 2026-10-08에 이식했다 (dice_control_port.md). 보물 획득·영혼 수확·카드 보관은 2026-10-07에 이식했다 (rewards_dice_port.md). 해당 타일은 원본 장소 화면과 복귀 동작을 제공한다. 오염 단계별 무작위 적 편성과 보물상자 미믹은 2026-10-08에 이식했다 (encounters_mimic_port.md).

## 전투 덱 선택
GitHub main의 v2-map-practice.js renderDeckSelection/toggleDeckUnit 및 원본 CSS 배치를 확인하여 이식. 미처치 마물 조우 시 선택을 비운 원본 보드 창을 열고 보유 개체 ID 기준 1~4명을 선택한다. 클릭 순서대로 왼쪽 슬롯에 배치하며 재클릭으로 해제. 인원별 피격 확률 100 / 35·65 / 20·33·47 / 15·20·27·38을 표시. 카드 0장이면 전투 시작 불가. 보드 내려오기·손패 올라오기 연출을 적용. 선택한 개체의 순서·현재 HP·낙인을 기존 전장에 전달하며 미출전 개체는 유지한다. 빈 보유 상태는 창 대신 안내한다.
새 테스트 UI/코드는 추가하지 않았다. Godot 편집기 불러오기 및 기본 시작 실행에서 오류가 없었다. Windows 화면 캡처 도구 시간 초과로 실제 카드 클릭·배치의 시각 확인은 미완료.
