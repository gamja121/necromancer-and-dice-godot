# 합의한 남은 작업 순서 — 2026-11-04

사용자는 아래 순서를 기억하고 먼저 보스 타일 유지 문제와 보스 편성 규칙을 확인하라고 요청했다. 이 긴급 수정 이후 다음 순서를 이어간다. 원격 브랜치 보존과 본편 완료는 구분한다.

## 현재 먼저 처리하는 요청

등장한 보스가 오염도 하락으로 사라지지 않게 유지한다. 저장·재시작·HOME 재생성·실제 전투 가능 여부와 기존 보스 편성을 확인한다. 작업 [#372](https://github.com/gamja121/necromancer-and-dice-godot/issues/372), [규칙/검증 기록](boss_tile_persistence_20261104.md).

## 이후 유지할 순서

1. 웜홀 진행 기준 정리: 기존 승인안과 최신 시나리오를 맞춰 어떤 경로에서 최종 조우·원정 계속으로 이어지는지 정리.
2. 기존 세이브 호환 수정: 웜홀 작업의 실패한 저장 이전 검사2개와 진행 중 전투·수확·20/40/60 보스 보존.
3. 웜홀 최종 조우 연결: 타일 변화 → 실제 도착 → 조우3장면 → 출전 선택 → 드래곤 전투.
4. 승리 이후 연결: 영혼 수확 → 책 엔딩 → 해당 경로의 원정 계속. 재시작 후 엔딩 반복·보스 재등장 방지.
5. 웜홀 검증 및 본편 반영: 실제 화면/저장/재시작/관련 회귀 → CI → main → PC 동기화. 관련 [#269](https://github.com/gamja121/necromancer-and-dice-godot/pull/269).
6. 마물 카드 원화24종: 원본과 후보를 비교해 사용자에게 보여주고 확정된 그림부터 교체. 관련 [#318](https://github.com/gamja121/necromancer-and-dice-godot/pull/318).
7. 선택형 전투 효과: 실제 전투의 그림체·가독성·성능을 검증하고 적용. 관련 [#164](https://github.com/gamja121/necromancer-and-dice-godot/pull/164).

시간 회귀·마물1마리 계승·새 결말 조건은 아직 필요한 설계를 임의로 확정하지 않는다. 최신 [시나리오 기준서](SCENARIO_MASTER.md)를 먼저 읽는다.
