# 집의 계승과 낙인 카드 적용 (2026-10-08)

## 실제 사용
아래쪽 우리집 타일 → 들어가기 → 낙인 계승.
집 안에 들어가면 보유 마물의 체력을 완전히 회복한다.
마물 계승: 아래 마물 목록에서 재료를 먼저, 받는 마물을 두 번째로 선택한 뒤 '재료 소모 · 계승'을 누른다.
낙인 카드: '낙인 카드' 탭에서 카드를 고른 뒤 '마물' 탭에서 받는 마물을 선택하고 '카드 소모 · 적용'을 누른다.
재료 마물을 다시 누르면 선택을 해제하며, 선택창을 닫으면 집 안으로 돌아온다.
받는 마물의 현재 체력/공격력/속도/최대 체력/개체 ID는 그대로 유지된다.

## 원본 규칙
GitHub gamja121/necromancer-dice-board main의 v2-home-inheritance.js, v2-rules.js, v2-brand-cards.js,
v2-home-inheritance.css와 v2-map-practice.js/html을 직접 비교했다.
참조 blob SHA: 계승 JS 1f6c51647cba24b4006b63f4793579c867ae9d23, 규칙 JS fc0c06214af4971c45550eccdbfddd97c5835066.
- 재료 마물의 낙인 중 하나를 무작위로 골라 축복만 계승하고 재료 마물 전체를 소모한다.
- 재료 마물은 전투 영구사망으로 기록하지 않는다.
- 낙인 카드는 축복만 추가하며 선택한 카드 1장만 소모한다.
- 기본 낙인을 포함해 최대 3칸. 기본 저주 눈금과 겹치는 축복은 제외한다. 같은 종류 낙인은 별도 슬롯으로 쌓을 수 있다.
- 옮길 축복이 전부 제외되면 재료/카드를 소모하지 않고 안내한다. 무작위 선택의 실패 시도는 난수 진행을 저장하여 다음 시도가 가능하다.
- 같은 개체를 재료/결과로 동시에 선택할 수 없다. 낙인 없는 마물은 재료가 될 수 없다.
- 한 방문에 계승/카드 적용을 합해 한 번. 같은 방문에서 닫았다 다시 열거나 재실행해도 제한을 유지한다.

## 화면과 구성
원본 inheritance-board.png와 home-interior.jpg를 재사용했다.
원본 legion-info-window-hd-clean.webp를 assets/map/ui/inheritance_info.webp로 가져왔다 (원본 bytes 유지).
재료/받는 마물 보드, 기존·재료·결과 낙인과 눈금 목록, 완료 표시를 제공한다.
보유 목록은 마물/낙인 카드 탭과 가로 스크롤로 구성했다. 마물 10장과 마지막 카드 클릭을 확인했다.
선택한 낙인 카드에는 축복 눈금을 표시한다.
- systems/brand_inheritance.gd: 낙인 검증, 기본 저주 정규화, 축복 추출.
- systems/home_inheritance.gd: 재료/결과 선택, 카드 적용, 결과 UI.
- systems/run_session.gd: 집 회복 및 계승 원자 저장/복구.
- map.gd: 집 바깥/실내 진입과 계승창 연결, 맵 복귀.

## 상태 관리
새 저장 버전이나 별도 개인 파일은 만들지 않았다.
기존 roster/brand_cards/rng와 reward_receipts에 'inheritance-visit:바퀴:이동번호:집' 기록을 함께 저장한다.
재료 소모·낙인 추가·방문 완료는 한 번에 저장한다. 저장 실패 시 모두 원복한다.
이동·전투·보상 진행 중에는 계승을 막는다. 완료 후 버튼은 비활성화되어 추가 클릭으로 다시 소모되지 않는다.
선택 상태는 런타임에만 보관한다. 실행 중 강제 종료 후 미완료 선택은 다시 고르며, 완료된 계승은 그대로 복원한다.

Trigger: 집 들어가기, 재료/마물/낙인 카드 선택, 계승 확정, 닫기.
Information: 보유 ID, 마물별 기본 낙인/저주/빈 슬롯, 선택 상태, 진행 중 원정 상태, 방문 완료, 저장 성공.
Interaction: Map ↔ HomeInheritance ↔ RunSession ↔ 기존 원정 저장/전투 규칙.
Visual Change: 집 실내, 두 카드 보드, 낙인 눈금 목록, 소모/완료와 짧은 결과 강조.
Memory: 결과 개체의 낙인, 재료·카드 소비, 난수와 방문 완료 저장. 선택창에는 영구 저장 없음.
