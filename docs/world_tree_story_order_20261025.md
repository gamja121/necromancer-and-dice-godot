# 세계수 배치와 사냥꾼 사건 순서 — 2026-10-25

사용자 화면에서 세계수가 한 번도 보드에 등장하지 않았는데 일반 사건이 세계수 배경의 사냥꾼 장면을 먼저 여는 문제가 확인됐다. 사냥꾼은 오염도 30과 기사단장 완료를 보지만 세계수 발견/배치는 보지 않았고, 스토리 우선 디스패치가 장소 발견 경로보다 먼저 실행됐다.

- `monster_hunter_entry.gd`: 최초 `unseen` 진입에 실제 `unknown`(세계수) 보드 타일 존재를 요구한다. 해금 플래그만 있고 타일이 없는 경우도 새 장면을 시작하지 않는다.
- 세계수가 없으면 사냥꾼이 일반 사건을 선점하지 않아 기존 장소 발견/루틴 처리로 내려간다. 세계수 배치 뒤에는 원래 세계수/일반 사건 진입과 오염·기사단장·퀘스트 조건을 그대로 사용한다.
- 기존 `seen` 저장은 일반 사건 위의 중간 대사와 오염도 감소 후에도 이어진다. 진행/완료 기록을 되돌리거나 세계수 타일을 임의로 만들어 저장하지 않는다.
- 장소 발견의 60/40 추첨, 맵 생성, 전투/보스, 원화/책 UI, 한국어/영어 설정은 변경하지 않는다.

검증은 Godot 4.7.2 headless의 격리 저장 폴더에서 진행했다. 실제 게임 창은 열지 않았다.

- 수정 전 기존 검사에 재현 사례를 넣어 9개 실패를 확인했다.
- 사냥꾼 진입: 302 통과 / 0 실패. 세계수 전 차단, 실제 map.show_tile 디스패치의 발견 카드·보드 원화·후속 책, 난수 상태, 구형 중간 대사 재개/완료를 포함한다.
- 사냥꾼 대사: 516 통과 / 0 실패.
- 기존 장소 발견 도착 처리: 35 통과 / 0 실패.
- 스토리 오염도 조건: 78 통과 / 0 실패.
- 최종 진입 검사와 import: 스크립트 오류·종료 리소스 경고 없음. 짧은 지도 fixture는 비동기 원화 준비가 끝난 뒤 정리한다.

5원칙: Trigger=세계수 실배치 이후 첫 사냥꾼 사건; Information=실제 보드와 기존 사건/퀘스트 상태; Interaction=장소 발견 후 원래 대사 선택; Visual=발견 카드/세계수 타일이 책 장면보다 먼저 노출; Memory=첫 진입 조건만 보완하고 기존 seen/완료/저장·RNG를 보존.
