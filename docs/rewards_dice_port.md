# 보상 및 주사위 이식 (2026-10-07)

원본: gamja121/necromancer-dice-board main 689e5064eb0e211beb03a932b3618b9f3a54c97b.
v2-auto-battle-practice.js/CSS, v2-map-practice.js, v2-dice-control.js, v2-brand-cards.js를 직접 확인했다.

## 실제 플레이

- 일반 마물 타일에서 전투를 이기면 중앙 전장이 영혼 수확 화면으로 전환된다. 시체 카드 또는 마물을 선택하고 중앙 주사위를 누른다.
- 소환체를 제외한 처치된 적의 필요 눈금은 2~6. 해당 값 이상이면 신규 개체를 완전한 체력으로 영입한다.
- 기본 시도는 1회, 아군 시체 군단 활성 시 2회. 첫 굴림부터 대상이 고정된다. 성공 또는 시도 소진 뒤 같은 맵으로 복귀한다.
- 보물상자 타일을 누르면 4프레임 개방 뒤 3개 보상이 나타난다. 한 번 선택하고 같은 카드를 다시 눌러 획득한다.
- 일반/희귀/전설 마물, 주사위 제어 카드 18종, 독립 생성 낙인 카드 3개를 섞어 3개를 제시한다. 실제 원본 코드는 낙인 1장 출현을 보장하지 않는다.
- 마물은 최대 10개, 주사위 카드는 5개. 가득 차면 기존 카드와 신규 카드 중 1개를 버린다. 낙인 카드는 별도로 보관한다.
- 왼쪽 책에서 마물/주사위/낙인 목록을, 오른쪽 카드더미에서 주사위 목록을 확인한다.
- 카드 획득은 책/카드더미로 이동하고 도착 아이콘을 짧게 강조한다. 기존 상자 개방 및 책 소리를 연결했다.

## 주사위

dice_animation.gd는 시각 난수만 사용하며 판정 난수를 소비하지 않는다.
전투/수확은 원본처럼 18~22단계, 12프레임 순환, 0.042~0.104초 감속 간격, 짧은 도약/회전 후 결과 표시를 사용한다.
맵은 1.75~2.2초 이동, 감속, 안쪽 경계 반사, 회전, 착지음과 1.04배 착지 강조를 사용한다.
타일 좌표/크기나 전장 크기는 바꾸지 않았다.

## 저장

MapState의 기존 version 1 저장을 유지하고 추가 필드 없는 저장도 읽는다.
추가 필드: dice_cards, brand_cards, graveyard_corpses, pending_reward, reward_receipts, next_serial, move_serial.
후보, 대상/필요 눈금, 남은 시도, 판정 결과와 완료 전장 snapshot을 저장해 재실행 시 보상 화면을 이어 간다.
판정을 저장한 뒤 연출하며, 완료 receipt로 같은 보상을 중복 지급하지 않는다. 동일한 상자 방문의 중복 획득도 차단한다.
저장 실패 시 상태와 RNG를 복원하고 동일한 지급을 다시 시도한다.
2026-10-08에 전투 진행 중 snapshot과 행동 큐 복원을 추가했다 (dice_control_port.md).

## 구성

새 파일: reward_catalog.gd, reward_ui.gd, treasure_reward.gd, corpse_capture.gd, reward_overflow.gd, inventory_panel.gd, dice_animation.gd.
수정: map.gd, battlefield.gd, map_state.gd, run_session.gd.
원본 카드 PNG 18종, 낙인 카드, 시체 선택 화살표를 사용한다.
capture-overflow-panel-bg.jpg는 GitHub 최신 원본도 JPEG 데이터가 손상돼 PIL/Godot 모두 정상 해독하지 못했다. 런타임에 넣지 않고 갈색/금색 Godot 패널로 대체했다. 원본 참조 사본은 보존했다.

Trigger: 승리 확정/시체 선택/수확 굴림/상자 열기/선택 재클릭/버리기 확정.
Information: 시체와 군단, 필요 눈금과 시도, 보유량, pending/receipt/저장 성공.
Interaction: Map ↔ RunSession ↔ Battlefield, 별도 보상 UI, 기존 오디오.
Visual: 카드 선택/흡수/획득 이동, 보관함, 상자/주사위 연출.
Memory: 지급 전후 상태와 판정/난수/고유 ID 저장. 연출 난수는 저장하지 않는다.

## 검증과 남은 범위

실제 OpenGL 실행과 화면 캡처로 상자 3개 종류 획득, 수확 성공/실패와 재시도, 보관함 10+1/5+1, 기존/신규 버리기, 재실행 상태, 저장 실패 복구, 중복 획득 방지, 주사위 판정/크기 복귀를 확인했다.
기본 편성의 실제 승리와 시체 군단 2회 시도, JSON 복원 후 중앙 전장 재개를 확인했다.
검증 스크립트는 작업 폴더에서만 실행한 뒤 제거했다. 게임 테스트 버튼/파일은 추가하지 않았고 개인 저장은 복원했다.
모바일 실기기/세로 화면은 미확인이다.
