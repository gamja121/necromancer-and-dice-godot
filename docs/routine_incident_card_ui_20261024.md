# 일반/루틴 사건 카드 UI — 보상 사전노출 제거 (2026-10-24)

## 사용자 확정 요구
- 일반 사건 선택 전에는 **사건 카드만** 표시한다.
- 사건 카드는 제목, 상황 원화, 사건 설명, 두 가지 선택만 포함한다.
- 하단 보상 **그림·보상 이름·녹색 보상 패널**을 제거한다.
- 보상은 사용자가 선택한 **결과 이후 별도의 화면**에서 보여주는 방향이다. 이 변경은 **사건 카드 UI만** 수정하며 별도 결과 화면의 연출·시점·문구는 아직 제작하지 않는다.

## 구현
- `systems/event_discovery_card.gd`에 `show_reward` 옵션(기본 true)을 추가해 기존 장소 발견 카드와 구별한다.
- `systems/routine_event_card.gd`는 `show_reward=false`로 호출하며, 기존 선택 버튼 및 클릭/중복 잠금 로직을 그대로 유지한다.
- `assets/map/ui/routine_event_card_base.svg`는 보상 전용 패널 없이 기존 양피지 장식·원화창 위치를 유지한 전용 배경이다.
- 루틴 카드의 설명 영역을 확대하고 선택 버튼을 살짝 위로 이동한다.
- 사건별 원화 선택은 그대로 유지한다. 전용 원화 복구 조사 PR #285와 충돌하지 않도록 해당 카탈로그는 수정하지 않는다.

## 유지 사항 및 미완료
- 기존 게임의 루틴 사건 6종, 선택지, 보상 지급/거절, 주사위 제어 카드 5장 상한, 원정 재개/저장/RNG 등은 수정하지 않음.
- 보상을 실제 선택 이후 별도 화면에 어떻게 표시할지는 **후속 UI 작업**이다. 현재 보상 지급 시점/기존 overflow 화면 동작은 변경하지 않는다.
- `scripts/test_six_routine_cards.gd`: 6종 카드에 보상 슬롯·문구 없음, 설명 영역, 원화·선택 버튼 및 기존 보상/저장 회귀.
- `scripts/test_event_discovery_card_ui.gd`: 독립된 장소 발견 카드의 기존 보상 슬롯 유지.
- Godot CI 및 PC/Android 실기 화면 검증 후 본편 반영 상태를 기록한다.

## 개발 기본 5원칙
1. Trigger: 실제 사건 타일 도착 또는 저장된 루틴 사건 재개
2. Information: 사건 제목, 삽화, 상황 설명 및 두 선택지 (선택 전 보상 비공개)
3. Interaction: 기존 수락/거절 버튼과 한 번만 처리하는 잠금, 저장 실패 시 재시도
4. Visual: 보상 구획 없는 한 장의 양피지 카드, 설명 확장, 하단 선택 버튼
5. Memory: 원정 저장과 기존 이벤트 방문/보상 기록 불변
