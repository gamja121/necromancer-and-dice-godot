# 47종 마물 카드 화면 규격화 — 2026-10-21

## 범위
- 기준 가시 카드 틀: 136×218 비율(폭/높이 = 136/218). 보유, 전투 편성, 전투 출전, 영혼 수확 슬롯은 기존 가용 영역·버튼 크기를 유지하고 그 안에 같은 비율의 카드 그림을 가운데 배치한다.
- 모든 47종 원본 WebP와 배경/리본/낙인 데이터는 그대로 둔다. 종별 투명 여백은 최초 로드에서 alpha used rectangle을 캐싱한 뒤 실제 보이는 몸체의 높이(최대 카드 높이 76%)와 발 기준(65%)을 정렬한다. 가로로 넓은 마물은 너비 상한을 더 넉넉히 둬서 체형을 보존한다.
- 캐릭터 TextureRect 비율은 원본 이미지와 같은 비율로만 확장하며 사용자가 허용한 돌출은 crop하지 않는다. 카드 배경은 통일된 틀 비율에 맞춰 정렬한다.
- 타이틀/하단 0~3개 낙인 배치, 선택/hover 확대, 북으로 이동하는 합성 아트 복제 기능은 그대로 유지한다.
- 테스트가 47종 × 4 슬롯에서 틀 비율, 실제 사용 알파 영역의 가로 중심과 발 정렬, 크기 상한, 3낙인 균등배치·오버플로 방지, 리사이즈·복제를 확인한다.

## 별도 검수 필요
- 실제 이미지의 선 끝·희미한 외곽 픽셀 때문에 `get_used_rect()`가 더 넓게 잡히는 마물은 실기에서 추가 조정이 필요할 수 있다.
- Godot headless 테스트 통과는 47종의 PC·휴대폰 실물 시각 품질 합격을 뜻하지 않는다. 런타임 갤러리 캡처와 모바일 터치/가독성 실기 확인 전에는 '육안 검수 완료'라고 표시하지 않는다.
- 기존 오픈 PR #236은 오래된 브랜드 테두리 제거 작업이므로 이 브랜치는 테두리·게임 규칙·세이브를 건드리지 않는다. PC 로컬 동기화 및 Pages SHA 일치도 따로 확인한다.
