## 결정: 11단계로 이 연출 개발 종료

집 **나가기**에서 기존 구름 전환 대신 다음 순서로 동작한다.

1. 타일 21개가 축소되어 중앙의 안쪽 8개 / 바깥쪽 13개 고리로 집결
2. 안쪽 +210° 시계방향, 바깥쪽 -250° 반시계방향 회전
3. 새로운 맵 위치로 흩어진 뒤 타일 앞면 공개
4. 옅은 타일 그림자, 작은 착지 반동 및 중앙 주사위 마력광
5. 집결·회전·착지의 기존 효과음 3개만 각 구간에 1회 재생. 이전 효과음 중복 재생 방지

주사위 눈금과 중앙 위치, 게임 규칙, 낙인·마물 상태, 맵의 집·마을·점술가 막사 고정 위치 및 기존 저장 정책은 변경하지 않았다.

## 개발원칙 확인

1. **Trigger:** 집에 들어간 뒤 `나가기`를 눌렀을 때 시작한다.
2. **Information:** 중앙 고리 움직임과 마력광, 단계별 소리로 맵 재편성을 알려준다.
3. **Interaction:** 셔플 중 맵 입력을 잠그고, 완료/저장 실패 시 반드시 복원한다.
4. **Visual:** 21개 타일·그림자·두 고리·새 타일 전면이 변하며 주사위와 고정 타일은 그대로 둔다.
5. **Persistence:** 맵 저장 성공 뒤 새 그림을 공개하고, 실패 시 기존 맵으로 복구한다.
