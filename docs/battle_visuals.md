# 전투 연출 1차 적용

범위: 대표 마물 해골 병사·궁수·고블린을 중심으로 기존 전장 표현을 강화. 원본 그림과 전투 계산은 유지하며, 영혼 수확·맵 환경 확장은 이번 작업에 포함하지 않는다.

- 전투 결과를 먼저 계산한 뒤 화면에는 공격 5번째 프레임에서 피격·체력 감소·피해 숫자·충격 섬광을 동시에 표시한다. 취소·빗나감은 공격 충격을 표시하지 않는다.
- 공격별 효과음과 화살/마법 투사체를 구분한다. 무거운 공격은 전장 마물 레이어만 약하게 흔들고 배경음을 잠시 낮춘다. UI는 흔들지 않는다.
- 발 아래 부드러운 접지 그림자와 작은 대기 호흡을 추가한다. 빙결 중에는 호흡을 멈춘다.
- 독 기포·빙결 결정·보호막 파동과 짧은 상태 표시를 추가한다. 기존 몸 색상도 유지한다.
- 피해 숫자·투사체·입자·상태 효과·대기 움직임은 같은 전투 배속과 일시정지를 따른다.
- 덱 카드 선택에 광택과 선택음을 추가한다. 출전 시 손패가 내려가고 선택 카드가 전장 방향으로 이동한 뒤 화면을 전환한다.
- 체력바는 각 마물 머리 위에 배치한다.

트리거: 공격/상태 변화/출전 확정. 필요한 정보: 이전·이후 HP, 대상 ID, 상태, 선택 개체 순서. 전달: 숫자·체력바·빛·입자·음향·카드 이동. 지속 상태: 기존 전투/원정 저장을 그대로 사용하고 시각 효과는 저장하지 않는다.

확인: Godot 편집기 import와 맵/전장 시작 실행에서 오류 없음. 실제 OpenGL 렌더러로 전장 정지 화면과 514프레임(8.6초) 한 라운드를 렌더링했고 오류가 없었다. 최종 그림자는 처음보다 부드럽게 조정했다. 전투 중간 프레임을 추출해 시각 확인한다. 덱 출전 전환은 코드/import 확인까지 완료했으며 실제 클릭 흐름과 효과음 청취 확인은 남아 있다.

새 테스트 코드·버튼·패널을 추가하지 않는다. 기존 캡처 기능을 활용하여 렌더링 결과만 작업 폴더에 저장한다.
