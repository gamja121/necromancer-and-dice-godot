## 공통 아트 기준
- 중세 채색 필사본(illuminated manuscript / Book of Hours) 느낌의 손그림. 평면적이고 절제된 채색, 옛 고서 특유의 고급스러운 금색 장식.
- **정사각형 1:1**, 장식 테두리가 캔버스 사방을 꽉 채움. 책이 펼쳐진 배경이나 별도 흰색 바깥 여백 없음.
- **그림 안 주인공/핵심 사물의 외곽선만 굵고 검게, 또렷하게**. 인물과 핵심 사물의 실루엣 우선.
- 성벽/길/숲 등 배경은 윤곽이 상대적으로 얇고 부드러워야 함. **네모 액자 바깥 금박/꽃/새/동물 문양은 특히 가는 선 또는 외곽선 거의 없음**.
- 종이에 지저분한 흑색 빗금, 과도한 스크래치, 입자, 탁한 어두운 잉크, 복잡한 표면 묘사 금지. 배경 디테일은 크게 정리.
- 파란색(울트라마린), 빨강, 금, 초록을 고전적인 채도로 사용. 프레임은 좌우 장식이 균형 잡히고 일러스트보다 눈에 띄지 않게.
- 글자, 룬, 카드 제목, 보상 문구를 **이미지 픽셀에 포함하지 않음**. UI 텍스트는 게임에서 별도 렌더.
- 이벤트 장면에 필요한 주인공/행동이 즉시 인식되도록 구도를 간결하게.
