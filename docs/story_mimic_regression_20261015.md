# 미믹 · 자연 스토리 검사 분리 (2026-10-15)

## 배경 및 증거
- 기존 P4 자연 스토리 검사에서 실제 보물상자의 10% 미믹이 82번째 이동에 나왔다.
- `scripts/test_p4_natural_story_arrival.gd:incidental_overlay`의 미믹 분기는 원래 의도적으로 실패(별도 미믹 전투 검증 필요)하도록 설계돼 있었다.
- 그 전에 교단 소문 완료까지 77번 이동이 소요되어, 85번 이동 내 제단·포털·왕 추적까지 끝낸다는 검증 가정 자체도 불안정했다.
- PR #167과 #168에서 같은 7개가 실패했다. 해금 알림의 신규 원인으로 단정하지 않는다.

## 실행 원칙 5가지
1. **Trigger:** 실제 `open_treasure()`의 기존 10% 확률, 정상 카드 덱 확인, 실제 전투 승리/패배. 자연 스토리에서는 확률적으로 미믹 등장 시 원정 중단이 합법적인 별도 결과다.
2. **Information:** `pending_reward` 의 id/index/count, 실제 `encounter` 정보, 보상 영수증, 오염도, 잃은 마물 및 `run_result`, RNG/맵/스토리 저장 상태.
3. **Interaction:** 미믹 전용 검사는 진짜 보물상자 애니메이션 → 덱 선택 → Godot 전장 → 주사위/공격 순서 → 승리 포획 또는 패배 게임 오버를 호출. 게임 진행 규칙 변경 없음.
4. **Visual:** 전용 테스트가 원래 Godot 미믹 공개, 출전 덱, 전장, 게임 오버 장면을 검증한다. 개발자가 새로운 미믹 아트/UI를 임의로 도입하지 않는다.
5. **Memory:** 미믹 등장 직후 index/count는 저장 전후 정수로 동일해야 한다. 전투 전/후 저장 재개 시 영수증 중복, RNG 변화, 원정 부활이 없어야 한다. 테스트 저장 파일은 별도 `user://` 경로.

## 테스트 역할
- `scripts/test_mimic_encounter_isolated.gd`: **전용 필수 검사**. 미믹이 실제로 발생하는 RNG 시드를 테스트 전용으로 선택해 출현·전투·승리/패배·저장 재개 검증.
- `scripts/test_p4_natural_full_story.gd`: **자연 주사위 이동 탐색 검사**. 미믹을 만나면 정식 미해결 보상/세이브가 올바른지 검증하고 이동을 종료한다. 해당 랜덤 실행에서 끝내지 못한 후속 스토리를 완료했다고 주장하지 않는다.
- `scripts/test_p4_full_source_story_chain.gd`: **필수 전체 스토리 검사**. 실제 사건 UI·주사위·승패/결과 화면으로 원본 모든 스토리 단계와 저장 복구를 검증한다. 해당 테스트의 단축된 초기 접근·대상 타일 변경은 검사 전용이며 게임 런타임에 사용하지 않는다.
- `.github/workflows/mimic-encounter-regression.yml`, `.github/workflows/p4-natural-full-story.yml` 모두 성공해야 이번 수정 완료로 판정한다.

## 변경하지 않는 것
- 미믹 등장률 10%, 오염도별 미믹 수, 전투 패배 즉시 게임 오버, 보스 진행, 15/30 늪지대 규칙, 메인 사건 우선순위, 게임의 RNG/타일 생성.
- 실제 자연 이동 검사에서 돌발 미믹을 몰래 삭제하거나 이긴 것으로 간주하지 않는다.
