# 상점·점술·제단 (2026-10-08)

원본: gamja121/necromancer-dice-board main v2-map-practice.js
(c5c957ec70c13b7ad7eb6528ab95f73be09f4539), v2-altar-ritual.js,
v2-auto-battle-practice.js. 원본의 운영 화면을 참고하고 디버그 편집 UI는 이식하지 않았다.

## 사용
맵에서 마을/점술가 막사/제단 타일을 열면 장소별 기능 화면이 열린다.
기존 타일 미리보기 접근 방식과 돌아가기 동작을 유지한다.

상점: 아래 보유 마물 선택 → 교환품 선택 → 같은 교환품 재클릭.
일반 3개/고급 4개/영웅 5개 후보, 주사위와 낙인 번갈아 배치, 영웅은 낙인부터 시작.
일반은 반복/효과 재발동 제외, 고급은 효과 재발동 제외, 영웅은 전체 주사위 카드 풀을 사용한다.
같은 후보에서 주사위 종류를 중복 추첨하지 않는다.
교환 시 선택한 마물을 소모하고 상품 하나만 지급한다. 마지막 마물은 교환 불가.
주사위 보관량 5장일 때 주사위 상품은 거래 불가, 낙인은 기존 무제한 보관을 따른다.
거래 마물을 공동묘지 시체로 만들지 않는다.
원본의 선택 취소 시 재추첨 대신 같은 방문/개체의 후보를 저장해 재접속·선택 취소로 재추첨하지 않도록 했다.

제단: 재물을 먼저 선택하고 서로 다른 강화 대상 선택 → 의식 실행.
공격력 +1, 최대 HP +2, 현재 HP +2 (새 최대 HP 이하), 개체당 최대 3회, 방문당 1회.
재물은 영구 소모되고 전투 사망 시체로 추가하지 않는다.
강화 횟수와 변경된 능력치는 개체에 저장한다.

점술: 예언 듣기 → 기존 맵 주사위 굴림 연출 → 판정과 누적 효과 표시.
1: 다음 전투 적 공격 +1.
2: 보유 아군 완전 회복 (이전 누적 예언 유지).
3: 다음 전투 아군 속도 +1.
4: 다음 전투 아군 최대/현재 HP +2.
5: 다음 전투 아군 공격 +1.
6: 다음 전투 아군 공격 +1, 최대/현재 HP +2.
방문당 1회이며 여러 방문의 효과를 누적한다.
다음 일반/희귀/보스/미믹 전투 진입 시 효과와 전투 checkpoint를 함께 저장하며 누적 예언을 소비한다.
공격/속도는 전투의 base_attack/base_speed에 추가해 매 턴 refresh 후에도 유지한다.
개체 영구 능력치에는 덧붙이지 않는다. HP는 기존 임시 HP 보너스 정산으로 전투 후 제거한다.
소환체에는 최초 출전 예언을 새로 부여하지 않는다.
점술은 이동 주사위가 아니므로 이동/주사위 카드의 이전 눈금 기록을 변경하지 않는다.

## 저장
world에 prophecy, last_prophecy, shop_trade를 추가했다. 기존 저장은 빈 값 기본값으로 읽는다.
기존 reward_receipts의 바퀴/이동/타일 방문 키로 제단/점술 중복을 막는다.
판정/교환품/소모/능력치/방문 제한을 연출 전에 저장한다.
저장 실패 시 난수·재물·상품·능력치·방문 기록·예언을 함께 복구한다.
UI는 실패 이유를 표시하고 다시 시도할 수 있다. 카드 입력은 기존 Godot 버튼 신호를 사용한다.

## 파일
신규 systems/place_actions.gd (+ .uid): 장소별 카드 선택과 판정 화면.
수정 systems/run_session.gd: 거래·의식·예언·다음 전투 적용.
수정 systems/map_state.gd: 저장/복원, map.gd: 장소 화면 연결.
기존 카드/장소 이미지와 DiceAnimation을 사용하며 맵/전장 크기는 유지한다.

Trigger: 장소 타일 열기, 개체 선택, 상품 재클릭, 의식 실행, 예언 듣기.
Information: 장소·개체 ID·등급·강화 횟수·보관량·방문 기록·누적 예언·저장 결과.
Interaction: PlaceActions ↔ RunSession ↔ MapState/전투 checkpoint, 기존 주사위/음향.
Visual: 카드/후보/선택 강조, 강화/거래 결과, 주사위 및 누적 예언 안내.
Memory: 개체 강화, 방문 제한, 고정 후보와 예언만 원정에 저장. UI 선택은 런타임 상태.

## 확인
실제 OpenGL 화면과 65개 조건으로 UI 카드 선택/재클릭 교환, 강화 1~3회와 한도,
마지막 마물 보호, 주사위 5장 제한, 등급별 후보와 재접속 고정,
예언 1~6/누적/즉시 회복/주사위 연출, 다음 전투 적용과 refresh 유지,
전투 후 영구 능력치 보존, 저장 실패 복구를 확인했다.
화면 캡처에서 카드와 안내 배치를 확인했다.
임시 검증 스크립트는 프로젝트에 넣지 않았고 실행 후 제거했다. 개인 원정은 복원했다.
