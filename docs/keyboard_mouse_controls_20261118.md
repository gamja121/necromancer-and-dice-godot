# 키보드와 마우스 혼합 조작 — 2026-11-18

사용자 승인 및 작업 기록: GitHub Issue #394. 게임 규칙과 원화는 유지하며 기존 행동의 입력 경로를 추가한다.

- 방향키: 현재 화면의 버튼·책·카드더미·카드·타일 사이 이동. 스크롤 안의 선택 카드는 자동으로 표시한다.
- Enter: 현재 행동 실행. 주사위 제어 카드는 기존 클릭과 같은 실제 사용 경로로 사용한다. 문장이 나오는 중인 메인 사건에서는 먼저 문장 표시를 완료한다.
- Space: 현재 보드·전장·공유 주사위를 쓰는 타일에서 굴리기. 다른 창이 열려 있거나 진행/굴림 중이면 실행하지 않는다.
- Esc: 이름 편집 → 정보 → 카드창 등 현재 단계에서 돌아간다. 보드에서는 기존 설정창을 연다. 메인 사건은 취소하지 못하며, 완료 후의 타일 기능 연결을 유지한다.
- 볼륨 슬라이더는 좌우로 조절하고 위아래로 다른 항목으로 이동한다. 언어 목록·문자 입력은 엔진의 원래 입력을 유지한다.
- 마우스 가리키기·클릭·드래그를 계속 지원한다. 입력 방식을 바꾸면 현재 대상을 기준으로 이어가며, 정보창을 닫으면 이전 카드/정보 행동으로 돌아간다.

## 선택 표시

공통 손그림 화살표와 그림 실루엣에 맞는 약한 따뜻한 후광, 각 버튼/카드의 기존 들림 효과를 사용한다. 사각 카드 테두리는 추가하지 않는다. 주사위 카드 손패에는 중복된 개별 설명 대신 기존 안내 띠에 방향키·Enter·마우스 끌기 안내를 함께 표시한다. 키보드로 주사위를 고른 동안에는 기존 3초 지연 화살표와 겹치지 않게 한다.

## 구현과 보존

`KeyboardNavigation`은 현재 장면/최상위 모달에 입력을 제한하고 실제 버튼 신호를 호출한다. 정보·이름 편집·보상 교환창은 별도 범위를 갖는다. Enter/Space의 키 반복은 중복 거래·굴림·확정을 만들지 않는다. 마물 교환에서 신규 카드 포기는 기존의 두 번 확인을 유지한다. 마우스의 실제 카드 끌기 경로를 대체하지 않는다.

카드 정보 열기/닫기의 전체 저장 상태와 RNG 동일성, 실제 지도 이동·주사위 카드 소모·이벤트 분기·출전 편성·전투·영혼 수확, 설정/이름 편집/10장 교환/기존 대형 보관함 스크롤을 별도의 저장 파일로 검사한다. 기존 사용자 저장 자료와 편집기 설정은 게시하지 않는다.

## 검증

- `scripts/test_keyboard_game_controls.gd`: 실제 키/마우스 입력으로 정상 진행 및 메인 사건 잠금, 여러 타일과 전투 후 수확을 검사. Windows 실제 화면 75건 통과.
- `scripts/test_keyboard_modal_controls.gd`: 설정/편집 단계 복귀/이전 선택 복원/기존 두 단계 포기/대형 보관함 자동 스크롤. Windows 실제 화면 52건 통과, 스크립트 오류 없음.
- 실제 Windows 화면 캡처로 화살표·후광·안내 글자 배치를 확인. 관련 카드/발견/종료/타일/전투 복귀 검사, 리소스 가져오기와 실행 기동도 별도로 확인한다.
- `.github/workflows/keyboard-mouse-controls.yml`은 두 실제 입력 검사를 독립된 저장 자료로 반복한다. 머리 없는 실행에서는 화면 저장만 생략한다.

언덕 회귀 검사의 안내 문구 위치/글꼴 기대값은 기존 `f130695` 공통 안내창 정리 이후의 실제 승인 배치 `(430,451,420,45)`, 18px로 갱신했다. 이번 조작 변경에서 언덕 원화나 문구 배치는 변경하지 않았다.

## 새 환경 및 회귀 정리

GitHub의 실제 입력 검사도 통과했다. 최초 가져오기에서 설정 글꼴의 원본만 있고 가져오기 정보가 누락된 사실을 발견하여 `NanumSquareRoundR.ttf.import`를 포함했다. 기존 글꼴은 유지한다. 초기화 중 설정창이 아직 없는 화면도 안전하게 처리하고, 빠르게 원정을 새로 시작할 때 이전 창에 선택이 돌아가지 않게 한다. 선택 표시가 숨겨지면 마지막 그림 참조를 놓고 일반 표시층은 서비스가 소유하게 정리했다.

기존 UI 회귀 중 이전 손패 크기, 이미 제거한 메인 사건 나가기/타일 이동 버튼, 집/상점 버튼의 옛 위치, 숨겨진 닫기 버튼과 덮어쓰기 확인창 생략을 요구하던 기준을 현재 승인된 화면에 맞췄다. 이야기나 원화/거래 규칙을 되돌리지 않았다. 책 완료 이후 실제 타일 기능을 마친 후 다음 굴림으로 이어지는 경로를 확인한다. 첫 가져오기에는 300초를 허용하고 종료 검사는 지연된 장면/연출 정리를 기다린다.

마우스와 키보드 혼합 입력은 실제 GUI가 받은 대상을 기준으로 연결한다. 손패의 표시 깊이와 입력 순서를 함께 정렬하여 겹친 카드/가려진 카드가 선택을 가로채지 않게 한다. 빈 공간으로 마우스를 옮긴 후에도 마지막 대상에서 키보드 조작을 이어간다. 1280×720과 1600×900 창에서 실제 입력과 앞쪽 카드 선택, 스크롤 클리핑, Esc로 조작 전환을 검증했다. 최종 Windows 실제 입력 검사는 75+52건 통과했다.
