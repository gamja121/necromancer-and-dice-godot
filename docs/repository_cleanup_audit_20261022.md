- `.import` 사이드카 1,389개, 약 1.33 MB: 대부분 실존 소스 이미지/음원과 쌍을 이루므로 일괄 삭제 금지. Godot 리소스 UID와 재임포트 영향을 고려한다.
- 소스가 없는 `.import` 2개: `assets/battle/frames/vampire/vampire-motion-sprite.webp.import`, `assets/battle/sfx/permanent-death.wav.import`. 소스 원본 파일이 Git 트리에 없고 관련 경로·UID 코드 검색 결과가 없어 이번 PR에서 사이드카만 삭제한다. 이미지·소리 원본은 건드리지 않으며 게임에서 실제 참조 누락이 없는지는 CI에서 추가 확인해야 한다.
- `.gd.uid` 파일 51개: 대응되는 코드 파일이 모두 존재함. **삭제 금지**.
- 동일 Git blob을 여러 파일명으로 참조한 그룹 53개, 작업 폴더상의 논리적 반복 크기 약 20.9 MB: 주로 몬스터 attack-01, attack-10, death-01, hit-01 등 의도된 애니메이션 프레임 반복. 이름별 프레임 참조가 있으므로 직접 삭제 금지. Git 내부의 동일 blob은 원천적으로 중복 저장을 피한다.
- 전체 실제 이미지 파일은 PNG 1,320개 / 약 407.4 MB, WebP 103개 / 약 42.8 MB. 용량 최적화는 아트 품질·프레임 정합·Godot 임포트·원본 보존을 확인하고 별도 수행해야 한다.
- `web/landscape-lock.css` 및 `web/landscape-lock.js`는 현재 Godot Web 배포 정책과 연결될 가능성이 있어 웹 구형 파일로 단정하거나 자동 삭제하지 않음.
- `archive-frozen-web` 워크플로와 `archive_frozen_web.py`는 웹 참조 원본 보존 목적의 유지 대상. 구형 게임 코드로 분류해 삭제하지 않음.
