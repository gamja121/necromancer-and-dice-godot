# 타이틀 3레이어 패럴랙스

## 목표

기존 동영상 타이틀 대신 손그림 원화 3장을 겹쳐, 마우스/터치 이동에 따라 각 레이어가 서로 다른 속도로 미세하게 움직이는 타이틀을 사용한다.

레이어:
- `background.webp`: 먼 성, 산, 안개. 이동량 최소.
- `board_layer.webp`: 보드/책과 마물 말. 이동량 중간.
- `foreground_layer.webp`: 해골, 촛불, 천, 폐허 장식. 이동량 최대.

게임 메뉴와 로고는 패럴랙스 영향을 받지 않는 고정 UI다.

## 입력

- PC: 마우스 이동 위치에 반응.
- 모바일: 터치/드래그 위치에 반응.
- 입력이 없을 때도 아주 약한 자동 호흡 이동을 유지한다.

움직임은 의도적으로 작게 제한한다. 과한 3D 효과보다 원화가 떠 있는 느낌만 주는 것이 목표다.

## 5가지 변경 점검

1. Trigger: 타이틀 화면에서 마우스 이동 또는 터치/드래그.
2. Information: 현재 포인터 위치, 저장 파일 존재 여부.
3. Interaction: `RunSession`과 통신해 새 원정/이어하기를 선택하고 `map.tscn`으로 이동.
4. Visual change: 배경 4px, 보드 11px, 전경 20px 수준의 미세 패럴랙스 + 느린 자동 호흡.
5. Persistent state: 새 원정만 기존 원정 저장을 새 상태로 덮어쓴다. 이어하기는 저장 파일을 다시 읽을 뿐 상태를 변경하지 않는다.

## 모바일 확인

프로젝트 기준 해상도는 1280×720이고 `canvas_items` stretch를 사용한다. 타이틀도 같은 좌표계를 사용하므로 Android landscape에서 동일 구도를 유지한다. 모바일 실기에서는 터치 드래그 반응과 노치/화면비 여백을 최종 확인한다.
