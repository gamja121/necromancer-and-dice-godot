# 독립 낙인 카드 폐지 (2026-10-21)

## 현행 게임 규칙

- 독립 낙인 카드(축복 카드)는 더 이상 아이템으로 존재하지 않는다. 획득·생성·보유 탭·상점·보물상자·공동묘지·집 직접 적용 UI가 모두 제거됐다.
- 마물 카드에 새겨지는 **낙인**, 낙인의 축복/저주 눈금, 전투 발동과 최대 3칸 제한은 유지한다.
- 집 낙인 계승은 **서로 다른 살아 있는 마물 2장**을 선택하여 한 장을 영구 소모하고, 재료 마물의 무작위 낙인 한 종류에서 축복을 받는 경로만 남는다. 집 방문당 1회 제한과 기본 저주 충돌 규칙은 기존대로 유지한다.
- 보물상자에는 마물과 주사위 제어 카드만, 상점에는 교환용 마물과 주사위 제어 카드만, 공동묘지에서는 무작위 주사위 제어 카드 1장만 등장한다.
- 이 작업은 **낙인 3칸이 찼을 때 교체 허용** 또는 **재료 낙인 직접 선택** 같은 설계안까지 구현한 것은 아니다. 현재는 기존 무작위 계승·3칸 한도 그대로다.

## 구형 저장 보호

- 2026-10-21 추가 정리: v1 저장의 `brand_cards` 및 초기 폐지판의 `legacy_brand_cards`는 이제 게임 상태로 다시 가져오지 않는다. 이전 카드 데이터가 존재하면 최초 불러올 때 원본 저장 파일 전체를 `.before_standalone_brand_cards.bak`로 한 번 복사한다. 현재 원정 JSON 및 메모리에는 두 필드가 모두 없다.
- 구형 보물상자에서 아직 지급받지 못한 `kind=brand` 후보 또는 지급 준비된 브랜드 카드가 있으면, 로드시 무작위 난수를 추가 소비하지 않고 주사위 제어 카드로 결정론적 변환한다. 이미 준비된 지급의 원래 고유 ID는 유지한다.
- 이미 저장된 마을 상점의 낙인 카드 제안은 상점 재진입 시 현재 로직으로 다른 마물 제안으로 변환한다. 실제 거래는 `unit` 또는 `dice`만 허용한다.
- 기존 계승 결과로 마물에 적용된 낙인은 건드리지 않는다. 구형 낙인 카드 원본은 게임 외부의 일회성 `.bak`에서 복구할 수 있지만 플레이·현재 저장에는 존재하지 않는다.

## 변경 구성

- `systems/home_inheritance.gd` · `systems/run_session.gd`: 마물 희생 계승 단일화.
- `systems/inventory_panel.gd` · `systems/reward_catalog.gd` · `map.gd`: 낙인 카드 UI/정보/이미지 경로 삭제.
- `systems/map_state.gd`: 구형 필드 무시, 이전 보상 변환. `systems/run_session.gd`: 기존 카드가 있는 세이브의 최초 로드시 원본 백업.
- `assets/cards/brand-card.png`, `.import`: 런타임의 불필요한 독립 카드 이미지 삭제. 마물 낙인 아이콘 아트는 그대로 둔다.
- `scripts/test_retired_brand_card_economy.gd`: 마물 희생, 세이브, 구형 미수령 보상 전환 회귀검증.
- 이전 낙인 카드 기능을 강제로 호출하던 테스트는 현행 마물·주사위 시스템에 맞춰 수정.

## 5가지 기본 원칙

1. Trigger: 집에서 재료 마물과 받는 마물을 선택하고 계승을 확정한다.
2. Information: 살아 있는 마물의 낙인, 계승 가능 눈금, 수신 마물의 남은 칸, 기존 방문 기록.
3. Interaction: 보유 마물 선택 → 결과 확인 → 영구 희생 확정.
4. Visual: 집의 낙인 카드 팬과 인벤토리 탭 삭제. 마물 카드의 낙인 표시는 유지.
5. Memory: 마물 소모, 수신 축복, 방문 1회 기록. 구형 낙인 카드는 현재 저장에서 제외하고 최초 로드 시 백업 파일로만 보존.
