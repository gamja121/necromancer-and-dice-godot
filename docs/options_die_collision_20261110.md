# 옵션 톱니바퀴 주사위 충돌 — 2026-11-10

작업 #385. 보드 옵션 버튼의 기본 80×80 범위에 사방 8픽셀 여유를 둔 96×96 비가시 충돌 벽을 추가한다. 버튼 부모 좌표를 주사위의 stage 좌표로 변환하며, 호버 크기·회전에는 벽이 흔들리지 않는다. 숨은 옵션에는 벽이 없다.

공유 주사위의 기존 타일 내부 경계와 오염도 프레임(용 전투에서는 기존 용 배제 범위)을 유지하고, 옵션 벽을 추가 충돌로 함께 계산한다. 설정 버튼을 만든 뒤 저장 위치를 복원하고, 굴림 시작과 정지 위치 저장 때도 겹침을 보정한다. 오른쪽·위쪽 보드 경계와 가까운 옵션 안에서 주사위가 끼지 않도록 기존 안전 위치를 사용한다.

충돌벽 자체는 어떤 그림이나 입력 노드도 추가하지 않는다. 옵션 클릭·음향·주사위 결과·게임 RNG·이동·저장 형식·아트는 변경하지 않는다. 위치 보정은 기존 주사위 시각 상태 처리만 사용한다. 기존 벽/공유 주사위/설정 회귀 검사와 실제 네이티브 굴림으로 검증한다.
