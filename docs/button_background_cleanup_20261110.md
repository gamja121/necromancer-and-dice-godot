# 보드 책·카드·설정 아이콘 뒤 사각형 제거 — 2026-11-10

작업 #383. 사용자가 제거할 대상으로 명확히 지정한 것은 보드의 보유 마물 책, 주사위 카드 보관함, 옵션 톱니바퀴 세 아이콘이다. 이들의 투명 원화 뒤에 공통 ButtonContactShadow 사각 Panel이 그려지고 있었다.

공통 효과의 contact_shadow_enabled는 기본 true로 두고 map의 세 아이콘에만 false를 전달한다. _ready 전에 설정하므로 해당 아이콘에는 사각 Panel을 만들지 않는다. 일반 버튼과 장소/사건책/타이틀의 기존 스타일과 그림자·클릭/호버 크기·회전은 그대로 사용한다. 설정 아이콘은 기존 투명 스타일에 hover_pressed도 포함해 누른 상태의 기본 버튼 배경도 방지한다.

아이콘 원화·크기·좌표·클릭 범위·콜백·책 잠금·카드 전달·오디오 설정 기능·게임 규칙과 저장은 바꾸지 않는다. 기존 네이티브 보드 캡처와 책/카드/설정 관련 검사를 격리 프로필에서 실행하고 최종 결과를 Issue에 남긴다. 새 검사 파일은 추가하지 않는다.
