## 유지된 게임 계약

1. **Trigger:** 집에서 `나가기` 한 번만 반영; 이중 탭이나 재진입은 차단한다.
2. **Information:** 미세 저항·관성·낮은 끌림음·회전음·첫 접촉 충격음·돌가루로 석판의 질량감을 전달한다.
3. **Interaction:** 전환 중 보드 및 주사위 입력을 잠그고 완료·저장 실패 시 해제한다. 사용자 Master/Music/SFX 음량·뮤트는 그대로다.
4. **Visual:** 기존 24칸(이동 21/고정 3), 중앙 주사위, 8/13개 역회전 +210°/−250°, 이미지·비율·제자리 착지는 보존한다.
5. **Persistence:** 비주얼/소리/돌가루가 세계 상태를 저장하지 않으며, 맵 변경이 저장된 뒤에만 새 타일 앞면과 착지 효과를 공개한다. 저장 실패 시 RNG·맵·회차·눈금과 입력을 복구한다.

## 코드·용량·성능 인수

- 새로운 이미지나 오디오 바이너리 **없음**; 기존 CC0 음원 재사용.
- 돌가루는 `systems/map_shuffle_gather.gd` 한 CanvasItem에서 그려짐. 새로운 입자 텍스처/입자별 노드 없음.
- 세 `AudioStreamPlayer` 재사용, 타일별 효과음 21개 발생 금지, 음소거 설정 존중.
- 임시 `TextureRect` 21개와 접촉 그림자 21개는 종료 시 정리. 지도·게임 세이브 파일의 별도 구조 변경 없음.
- 여섯 번째 단계에서는 게임 실행 코드를 바꾸지 않고 **테스트, 검증 CI 및 인수 문서만 추가**했다. 이미 게시된 5단계 석판 무게감 구현과 동일하다.

## 자동화의 한계와 직접 점검 항목

헤드리스 CI는 프레임별 상태와 소리 재생 **요청 시점**은 검증하나 실제 스피커 청음이나 브라우저 렌더링의 촉감을 대신하지 못한다. 최종 품질 판단에 필요한 수동 절차:

1. 휴대전화 **가로 화면**으로 웹 게임을 열고 집에 들어갔다가 두세 번 나가 본다. 흔들림·중앙 역회전·착지·돌가루가 자연스러운지 확인한다.
2. 휴대전화 스피커, 가능하다면 이어폰에서도 낮아진 `move` / `magic` / `heavy` 소리의 크기와 지연이 거슬리지 않는지 확인한다.
3. 오디오 설정의 SFX 끄기/켜기, 화면 방향/크기 변경, 반복 시 프레임 저하와 떨림을 확인한다.

자동 검증의 합격은 **석판 무게감 연출 기능 개발 종료(6/6)** 를 의미한다. 위 기기별 감상·성능 평가는 미실시이며, 문제가 발견될 때에만 별도 버그 수정 작업으로 진행한다.
