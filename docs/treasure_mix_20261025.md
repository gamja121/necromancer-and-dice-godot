# 보물상자: 마물 1장 + 주사위 컨트롤 2장

2026-10-25 사용자 요청으로 일반 보물상자 선택지 세 장을 마물 1장과 주사위 컨트롤 카드 2장으로 고정했다. 신규 상자는 기존 적격 마물 목록에서 1종, 기존 주사위 18종 중 중복 없이 2종을 뽑고 세 자리의 순서를 섞는다. 기존 10% 미믹 분기·카드 한 장 선택/별도 확정·보관함 초과 교체/포기는 유지한다.

이미 열린 상자 저장도 1+2로 정리한다. 선택한 슬롯·source와 이미 준비된 reward.item/ID는 그대로 두고 나머지 슬롯만 결정적으로 바꾼다. 복원 시 RNG나 next_serial을 소비하지 않는다. 예전 독립 낙인 보상→주사위 이관도 유지한다. 기존 저장의 주사위 종류까지 다시 뽑지는 않는다. 결과는 이후 선택/확정 저장을 통해 유지되며 재로드로 리롤하지 않는다. 저장 실패 시 기존 원자적 rollback을 따른다.

5원칙: Trigger=일반 보물상자 개방/이전 대기 상자 복원; Information=기존 마물·주사위 후보, 저장된 선택/준비 보상; Interaction=3장 중 1장 선택과 획득 확정; Visual=기존 세 카드 UI에서 유형만 1+2 보장; State=offers만 생성/이관하고 선택·아이템 ID·영수증·미믹 상태를 보존한다.

## 검증

개인 저장과 분리한 헤드리스 검사. 보물 전용 `test_treasure_one_monster_two_dice.gd` 325 통과, 실제 선택·확정·저장 재개 UI 34 통과, 보물→집→다음 바퀴 통합 32 통과(실패 0). 44개 seed에서 구성/서로 다른 신규 주사위/미믹 분기, 기존 3마물·3주사위와 선택 슬롯 0/1/2, 준비 보상 보존, RNG/serial 보존, 저장 실패와 재시도를 확인했다.

기존 상점 통합 검사는 영웅 후보 수·영웅 교환에서 2개 실패했다. 수정 전 origin/main의 검사도 같은 2개 실패를 재현했다. 이번 보물상자 변경에 상점 규칙 수정은 포함하지 않았다. 보물 전용 검사는 상점 케이스를 제외하는 독립 진입점이며, 원래 상점의 실패 검사는 삭제하거나 완화하지 않았다.
