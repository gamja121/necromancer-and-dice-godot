# 등장한 보스 유지 및 편성 확인 — 2026-11-04

사용자 결정: 보스 타일은 한 번 등장하면 순회 도중 오염도가 내려가도 없어지지 않는다. 작업 [#372](https://github.com/gamja121/necromancer-and-dice-godot/issues/372). 기준 main1338599.

## 수정한 동작

- 실제 보스가 놓인 지도 생성과 실제 중간 등장 시 `event_flags["boss:contamination:<stage>:revealed"]`를 같은 저장에 기록한다.
- 현재 등장 조건과 실제 등장 최고 단계를 함께 사용한다. 오염도가0까지 낮아져도 같은 단계와 종이 유지되며 실제 보스전에 진입할 수 있다.
- 재시작·HOME 재생성·순찰 미리보기도 같은 기준을 사용한다. 단계별 기존 처치 기록이 있으면 퇴장하며 다시 나오지 않는다. 더 높은 적격 단계로 올라가는 기존 동작은 유지한다.
- 최종 이야기 잠금으로 미등장 드래곤을 선해금하지 않는다. 과거 오염도80만으로는 등장 기록을 만들지 않는다. 이미 등장한 중간 보스는 최종 이야기 잠금 구간에서도 유지된다.
- 구형 저장의 실제 보스 타일·진행 중 보스 단계에서만 등장 기록을 보완한다. 단순 과거 최고 오염도로 종을 재추첨하거나 최종 보스를 추정하지 않는다.
- 기존 저장 version1, 배정된 종·능력·일반 전투·기도 확률·맵 RNG를 유지한다. 등장 기록·타일·오염도·기도 영수증은 저장 실패 시 함께 복원한다.

## 보스 편성 감사

현재 기본 적1마리는 코드와 [기존 사용자 기준](boss_stages_20261023.md)에 명시된 동작이다. `run_session._start_encounter`는 보스 타일에서 `[world.current_boss_slug()]`를 편성하며 일반 몬스터의1~4마리 증원 규칙을 적용하지 않는다.

- 새 원정마다 데스 나이트·히드라·크라켄·거미 여왕·고블린 족장·해골 소환사6종 중 중복 없이3종을 골라20/40/60에 배정한다. 각 단계에서 각 후보는1/6, 원정의 세 후보에 포함될 확률은1/2다. 재접속·지도 재생성으로 다시 뽑지 않는다.
- 배정값이 없는 옛 저장은20데스 나이트/40히드라/60크라켄을 보존한다. 이번 원정에 배정된3종과 최종 드래곤은 일반 무작위 출현에서 제외되며 미선정 후보는 일반 영웅종으로 나올 수 있다.
- 최종 드래곤도1마리이며 HP70/공격5/속도4, 기존 뼈 덧대기+불사귀를 유지한다.
- 소환 패시브가 있는 보스는 전투 중 소환수를 추가할 수 있다. 별도 호위 편성은 현재 없다.

정찰의 내부 count/grade 데이터는 현재 일반 생성기를 사용해 실제 보스와 다를 수 있으나, 실제 보스 편성은 이를 사용하지 않는다. 이번 타일 유지 수정에서 보스 마릿수나 밸런스를 임의 변경하지 않는다.

## 5원칙 및 검증

Trigger: 실제 보스 등장/오염도 변화/처치/불러오기. Information: 저장된 등장 단계·종과 현재 오염도를 분리한다. Interaction: 같은 타일과 기존 출전 선택으로 진입한다. Visual: 기존 보스 PNG가 하락 후에도 남는다. Memory: 기존 boolean event_flags와 처치 영수증, 저장 실패 원자성.

새 `test_boss_reveal_persistence.gd`는 실제 세계수 기도·일반 저장·HOME 재생성·실제 출전/승리·재접속·실패 저장을 검사한다. `test_boss_reveal_capture.gd`는 실제 한영 지도에서20→15 정화 전후와 재접속, 기존 보스 덱 화면을 촬영한다. 최종 검증 수치·공유 SHA·PC 동기화는 Issue372 체크포인트에 기록한다.
