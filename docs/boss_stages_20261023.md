# 단계 보스 출현 규칙 (2026-10-23)

## 사용자 요청 기준

- 기존 마물 중 **보스로 지정한 개체는 일반 전투·정찰·보물상자·상점 및 광신도/전이문 일반 사건 적에서 제외**한다.
- 보스는 **바퀴 수가 아니라 오염도** 단계로 출현한다. 20/40/60 구간마다 **서로 다른 보스 한 마리**, 한번 처치한 단계는 같은 원정에서 재등장하지 않는다.
- 같은 단계 안에서는 집에서 맵을 몇 번이나 바꾸어도 처치 후 보스 타일이 다시 열리지 않는다. 40/60 기준을 새로 넘으면 해당 단계의 새로운 보스가 등장한다.
- **오염도 80 이상**은 별도의 **최종 드래곤** 규칙. 5장면 「마물의 왕 추적」의 마지막 ‘마치기’ 완료가 있어야 드래곤이 해금된다. 전용 HP70/ATK5/SPD4, 뼈 덧대기+불사귀를 유지하며 신규 기믹은 추가하지 않는다.

## 확정: 6종 후보 중 3종을 원정별 무작위 추첨

새 원정 시작 시 6종에서 **중복 없이 3종**을 뽑아 오염도 20, 40, 60 보스로 순서대로 배정한다. 모든 후보의 확률은 같으며, 별도 난수 발생기를 사용하므로 맵·주사위 RNG의 기존 결과는 영향을 받지 않는다.

| 후보 마물 | slug |
| --- | --- |
| 데스 나이트 | `death-knight` |
| 히드라 | `hydra` |
| 크라켄 | `kraken` |
| 거미 여왕 | `spider-knight` |
| 고블린 족장 | `goblin-chief` |
| 해골 소환사 | `grave-priest` |

| 오염도 구간 | 단계 | 보스 | 재등장 |
| --- | --- | --- | --- |
| 20–39 | 20 | 해당 원정의 첫 번째 랜덤 후보 | 처치 후 없음 |
| 40–59 | 40 | 해당 원정의 두 번째 랜덤 후보 | 처치 후 없음 |
| 60–79 | 60 | 해당 원정의 세 번째 랜덤 후보 | 처치 후 없음 |
| 80–100 | 80 | 종언의 고룡 (`dragon`) 고정 | 최종 사건 완료 시 해금, 처치 후 없음 |

- 보스 후보 6종과 최종 드래곤은 일반 전투·정찰·보물상자·상점·무작위 사건 전투의 일반 출현 후보에서 제외된다. 처치한 보스의 **시체 포획**은 기존 규칙을 유지한다.
- 선택 결과는 새 저장값 `boss_assignments`에 **원정별 1회** 기록한다. 맵 셔플·재시작·불러오기로 다시 추첨하지 않는다.
- 이전 저장 파일에 `boss_assignments`가 없다면 이전 임시 고정 배정(20 데스 나이트 / 40 히드라 / 60 크라켄)을 유지해 진행 중인 보스가 변하지 않도록 한다. 새 원정부터 무작위 선정을 사용한다.

- 스테이지별 영구 완료 기록: `event_flags["boss:contamination:<stage>:defeated"]` (기존 단계 완료 플래그 유지).
- 보스전 시작 시 `active_encounter.boss_stage`를 함께 저장한다. 저장/재시작·오염도 변경이 있더라도 이긴 보스의 **원래 단계**만 완료 처리한다.
- 해당 단계 보스를 이기면 일반 타일로 변경되고, 다른 타일·RNG·스토리 상태는 유지한다. 이미 저장된 죽은 보스는 옛 `cleared` 타일로부터 안전하게 완료 기록을 승격할 수 있다.
- 죽은 보스에 대한 포획 시도/영입 규칙은 기존의 몬스터 카드 규칙을 따른다. 보스 전용 6종이 일반 보상 풀에는 등장하지 않는 것과 처치 보스의 **시체 포획**은 별개다.
- **중요:** 웜홀에서 최종 조우·엔딩과 원정 계속을 연결한 별도 [PR #269](https://github.com/gamja121/necromancer-and-dice-godot/pull/269)은 이 작업의 대상이 아니다. 아직 병합되지 않은 사건/엔딩 변경과 충돌하지 않도록 고정 보스 타일의 기존 최종전 행동을 덮어쓰지 않았다.

## 5원칙

Trigger: 오염도 20·40·60 임계 돌파 + 해당 단계 미처치.
Information: 현재 오염도/보스 단계/저장된 3종 랜덤 배정/완료 기록.
Interaction: 현행 보스 타일 진입 → 1~4마리 편성 → 기존 전투/시체 포획.
Visual: 처치한 단계 타일 소멸, 새 임계 단계 도달 시 다른 보스 타일 등장.
Memory: `boss_assignments` 원정별 배정, `event_flags` 단계별 처치, `active_encounter.boss_stage`, 구버전 저장 호환.
