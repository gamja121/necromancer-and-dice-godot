> **사용자 추가 결정:** 사건 타일에는 메인 사건만 있는 것이 아니라 짧은 **루틴 사건**도 존재한다. 예시: “길에서 쓰러진 병사를 만났다. 도와주니 주사위 제어 카드 한 장을 얻었다.” 현재 주사위 제어 카드 획득 기회가 너무 적으므로 루틴 사건을 반복 가능한 획득처로 사용한다.

- 최초 도착 시 사건 종류/카드/실제 주사위 제어 카드 후보가 **하나의 저장 트랜잭션**으로 확정된다. `map_serial + move_serial + tile index`로 방문 ID를 만들고 재접속/미리보기/버튼 두 번 누르기에서 다시 뽑지 않는다.
- 카드 선택 '지나간다/떠난다/거절한다/물러난다'는 보상 없이 **이번 방문 영수증**을 남긴다.
- 카드 9장→10장은 원본 `create_item("dice")`를 통해 즉시 지급, **10장일 때는 기존 `reward_overflow.gd`로 교체/거절**을 직접 선택한다. 교체 도중 재시작해도 동일 보상/ID를 복원한다.
- 새로운 카드 스킬/재화/플레이어 HP/기존 타일 개수/미믹 등장률/보스 기준을 수정하지 않는다. 힐은 기존 보유 마물 `current_hp/max_hp`, 오염 제거는 기존 `contamination`을 활용한다.
- 실제 버튼을 누르거나 결과를 받는 **후속 트랜잭션 실패 시** 선택/카드 지급을 함께 되돌린다. 구형 저장 파일은 미처리 루틴 기록이 없는 정상 상태로 복원한다.

## 1. 사건 타일의 세 갈래

- **메인 사건**: 선행 조건, 오염도, 진행 단계, 이어보기·결과 대기 등 기존 스토리 시스템이 요구하는 사건. **언제나 최우선**. `map.gd:show_tile`의 기존 가드와 분기·저장·복원을 유지한다.
- **장소 발견 사건**: 기존 메인 사건이 발생/재개할 수 없는 도착에서 **미발견이면서 장소별 선행 조건도 충족한 장소**만 발견하여 영구 해금. 타일 종류/세부 조건/편성 정책은 `docs/event_tile_unlock_design.md`와 [장소 조건 제안](location_unlock_conditions.md) 참조.
- **루틴 사건**: 기존 메인 사건이 없을 때 드물지 않게 나타나는 짧은 선택형 사건. 방문마다 다른 일상 상황과 결과를 제공하며, **주사위 제어 카드의 정상적인 추가 공급 경로**다. 사전에 모두 소진되는 일회성 '메인 스토리'로 취급하지 않는다.

`사건 타일 실제 도착 → (발생 가능한 메인 사건/이어보기) → 없을 때 [장소 발견 또는 루틴 사건] → 선택/결과 저장 → 맵 복귀`.

'기존 사건 진입에 실패/저장 오류'는 '발생할 메인 사건 없음'으로 해석하지 않는다. 새로운 사건이나 보상으로 빠져나가지 않으며 재시도를 제공한다.

## 2. 첫 루틴 사건 예시 (콘텐츠 제안)

- ID 제안: `routine_wounded_soldier`; 제목: '쓰러진 병사'.
- 장면: “무너진 성벽 아래, 피투성이 병사가 쓰러져 있다. 그는 작은 가죽 주머니를 붙잡고 있다.”
- **도와준다** → “병사는 도움에 감사하며 자신이 지니던 주사위 제어 카드를 건넨다.” → 무작위 **주사위 제어 카드 1장** 획득.
- **지나간다** → 별도 보상 없음. 선택 내용을 확정하고 지도에 복귀.
- 구조: 기존 단순 대화창과 카드 보관함/획득 UI 재사용. 새로운 전투·재화·추가 플레이어 HP 등 **사용자가 정하지 않은 시스템을 끼워 넣지 않는다**.
- 최초 기획 단계이므로 병사의 개별 이미지, 부상 비용, 카드 종류 분포 등은 아직 확정되지 않았다. 전용 그림이 없으면 현재 승인된 일반 이벤트 UI만 사용.

다른 후보는 '버려진 마차에서 주사위 카드 발견', '낯선 행상인의 교환 제안', '검은 연기에 뒤덮인 야영지에서 소모품 회수', '길 잃은 행인의 짐 운반' 등이다. **이들은 예시이며 구현 확정 목록이 아님**.

## 3. 카드 부족 해소를 위한 공급 설계

### 현재 코드 확인

- `systems/reward_catalog.gd`: 카드 보유 상한 **10장**.
- `systems/run_session.gd:resolve_owned_card`: 한 번 사용한 카드는 보관함에서 제거되는 **소모형**.
- `systems/run_session.gd:open_treasure`: 보물상자의 3개 보상 후보 중 일부로 제어 카드가 등장할 수 있으나 선택을 보장하지 않음. 미믹 확률 10%도 있음.
- `systems/run_session.gd:shop_offers/shop_trade`: 마을에서 마물 1개를 교환하여 제어 카드를 얻는 경로. 다른 보상과 경쟁하고 대가가 큼.
- `systems/map_state.gd`: 현재 사건 타일은 **초기 기본 1칸**. 메인 사건이 우선이므로 매 바퀴 반드시 루틴 사건을 보거나 카드를 받는 것이 아님.

### 권장 최초 밸런스(제안, 검증 후 조정)

- **메인 사건은 100% 우선**. 그 다음 실제 사건 타일 도착에서 **해금되지 않았고 해당 장소의 선행 조건을 충족한 발견 후보가 있을 때만** 루틴 사건/장소 발견을 **둘 다 후보**로 둔다. 미해금 장소가 남아 있어도 현재 조건을 충족한 대상이 없으면 **루틴 사건만** 일어난다. 기존 기획의 '발견이 우선'이라는 고정 순서를 임의로 확정하지 않는다.
- 일반 상태의 시험 분포: **루틴 60% / 장소 발견 40%**(**조건을 충족한 미발견 후보가 있을 때만**). 아직 미해금이더라도 **현재 자격을 가진 후보가 0개면 루틴 100%**. 이 시험 비중은 확정된 밸런스 수치가 아니다.
- 루틴 사건 안에서는 첫 버전 기준 **약 절반이 주사위 제어 카드 획득과 연결**되게 편성한다. 보상 없는 선택도 플레이어에게 명확히 설명한다.
- 카드 **0~1장**을 가진 상태가 오래 지속되지 않도록, 메인 사건이 없는 사건 타일 방문 **2회 이내**에 카드 획득 기회를 1회 보장하는 완화 규칙(피티)을 검토한다. 이는 **방문 보장**이지 반드시 선택/보상을 강제한다는 뜻이 아님. 카드 보상이 싫으면 선택하지 않을 수 있다.
- 현재 1칸 사건 타일에서 사건 방문 자체가 드문 문제를 먼저 실제 플레이 로그로 측정한다. 필요하면 사건 타일 개수·출현 위치·루틴 확률을 후속 밸런스 조절하되 기존 24칸 지도와 사건 1칸을 **동의 없이 늘리지 않는다**.
- 카드 보유 **10/10**인 경우 획득을 묵살하거나 11장으로 초과하지 않는다. 기존 `reward_overflow.gd`의 **기존 카드 교체 또는 신규 카드 포기** 흐름을 재사용한다.
- 카드 지급은 **기존 `Catalog.dice_cards()` 등록 카드**에서만 선택하고 `RunSession.create_item("dice",...)`로 원정 소유 ID를 생성한다. 임의 새 카드 능력을 추가하지 않는다.

## 4. 무한 반복 및 저장 보호

- 오직 **실제 사건 타일 도착 완료**가 루틴/해금 후보 추첨 트리거다. `select_tile()` 미리보기나 맵 로드·재렌더·사건창 닫았다 열기로 다시 굴려서는 안 된다.
- 각 사건 도착에 고유한 **방문 키**(`map_serial`, `move_serial`, 타일 인덱스)를 사용하고, 추첨 결과/선택 보상 대기를 먼저 원정에 저장해 **카드 무한 복사·리세마라/강제 종료 반복 추첨**을 막는다.
- 획득을 확정할 때 카드 소유·방문 처리·보상 처리 정보를 **한 번에 저장**한다. 저장 실패 시 모두 롤백하고 선택을 재시도한다.
- 보유 한도가 찼다면 기존 overflow UI로 들어가며, 교체/포기 후에도 동일 사건 보상을 2번 받을 수 없다.
- 기존 스토리 중단/전투 보상/장소 발견 보상은 루틴 사건의 추첨이나 재개에 의해 덮어써지지 않는다.
- 구형 `user://map_run_v1.json` 저장 복원 시 새 루틴 이벤트/피티 필드가 없어도 정상 로드된다.

## 5. 5원칙과 테스트

- **Trigger**: 진짜 사건 타일 착지 완료, 메인 스토리 시작/재개 불가.
- **Information**: 원정/스토리 상태, 미발견 장소 목록, 주사위 제어 카드 0~10장, 방문 영수증, RNG 및 이미 결정된 선택지.
- **Interaction**: 사건 엔트리 → 메인 사건 가드 → 장소 발견/루틴 선택 → 선택형 대화창 → 주사위 카드 획득/overflow → 저장 → 지도.
- **Visual change**: 기존 간단한 대화창에 사건 묘사·2개 선택지·주사위 카드 획득 연출, 보관함 수량 즉시 갱신. 과도한 버튼/새 아트는 요구하지 않음.
- **Memory**: 루틴 ID와 방문 결과, 보상 확정 여부, 선택/피티 값은 중단 후 재개 가능.

**필수 회귀:** 메인 사건 조건이 참이면 루틴/발견 절대 실행 안 됨; 메인 사건의 저장 실패로 대체 루틴 지급 안 됨; 화면 미리보기/재로딩 중복 추첨·중복 카드 없음; 카드 4→5 성공, 5→교체/포기 정상, 게임오버/배틀 대기 중 지급 불가; 기존 카드 소비 및 보물상자·상점 동작 유지; 언덕/숙영 해금 상태와 기존 보스 오염도 단계 구상 독립.
